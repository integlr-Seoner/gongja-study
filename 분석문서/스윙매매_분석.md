## 2. 핵심 원칙 (가장 중요한 5가지)

### 2.1 재료가 있는 종목으로만 매매 (p.50~)

> "차트는 우리가 손실폭을 키우지 않게 제한해준다는 장점이 있다면, **재료는 우리가 주식시장에서 매매를 할 때 수급이 유입되지 않는 종목에 묶여서 소외되지 않도록 도와줍니다.**" (p.50)

- **재료 없는 종목 = 수급 없음 = 소외 = 시간만 까먹음**
- 차트만 좋고 재료 없는 종목 = 매수 X
- 재료 + 차트 둘 다 확인

### 2.2 비중 관리 — 분할매수 + 추가매수 (p.70~80)

> "필자가 꼭 지키는 한 가지 원칙이 있습니다. 그 원칙은 바로 **한 번 매수할 때 2% 이상 비중으로 매수하지 않는다는 것**입니다." (p.80)

**핵심 비중 룰**:
| 항목 | 룰 |
|---|---|
| 1회 매수 최대 비중 | **2%** |
| 종목당 최대 비중 | **10%** (재료 큰 종목은 15~20%) |
| 보유 종목 개수 | **소수 정예** (백화점식 매매 금지) |
| 분할 매수 횟수 | **5~10회** (2% × 5~10) |

= **단 한 번에 큰 비중 매수 금지**. 항상 분할.

### 2.3 예수금 보유 (p.90~)

> "예수금을 보유하고 있는 투자자와 보유하고 있지 않는 투자자의 차이는 **국내, 혹은 글로벌 악재가 발생하면서 주가가 큰 폭으로 하락할 때 나타난다**" (p.90)

- 코로나 19 같은 큰 하락 시 = **저점 매수 기회**
- 예수금 100% 매수 상태 = 기회 못 잡음
- 항상 일부 예수금 유지

### 2.4 보유 기간 — 손절라인 기준 (p.95~100)

> "**종목을 보유하는 기간은 '특정 기간'으로 정의할 수 없습니다.**" (p.95)

- 차트 매매: **손절라인 이탈 안 하면 1개월~6개월 보유 가능**
- 재료 매매: **재료 소멸 시점 = 매도** (일정 있는 재료는 일정 1일 전)
- 핵심 = 기간이 아니라 **손절라인 이탈 여부**

**예시 (p.100)**: 영화 미나리 상영 관련주
- 시상식 당일 = 일정 소멸 = 하락 시작
- 단, **시상식 하루 전부터 장대음봉 출현** = 더 일찍 매도해야 함
- = 일정 + 차트 병행 필수

### 2.5 손절 (스탑로스) (p.110~)

> "우리가 매매를 하면서 **-10%를 넘기지 않은 채로 보유 종목들을 적당한 구간에서 손절했다면 지금까지 주식시장에서 잃은 돈의 절반 정도는 잃지 않고 보유하고 있었을 것**입니다." (p.110)

- **-10% 이전 손절** = 손실 절반 줄임
- -20% ~ -50% 손실 종목 = 회복 거의 불가능
- 손절 회피 = 거래정지/상장폐지로 이어짐

## 4. 기준봉 캔들 패턴 (스윙매매 핵심 + 기준봉 추적 3권)

### 4.1 기준봉 정의 (재료매매 + 스윙매매 공통)

**기준봉 = 거래대금/거래량 급증 동반 장대양봉**
- 몸통 비율 70% 이상
- 상승률 +5% 이상
- 거래량 = 직전 20봉 평균의 3배 이상
- 시가 ≈ 저가 (저가에서 출발해서 상승)

### 4.2 기준봉의 의미

> 세력이 매집을 시작한 흔적 = 향후 상승 추세의 첫 번째 신호

### 4.3 기준봉 매매 알고리즘

```
Day 0: 기준봉 발생 (장대양봉 + 거래량 급증)
Day +1 ~ +5: 눌림목 (조정 구간) - 보통 5일선/10일선까지 하락
Day +6 ~ +10: 지지 확인 (저점이 기준봉 시가 위)
            → 매수 (정찰병)
Day +10 ~ +20: 다시 거래량 증가 + 양봉 출현
            → 추가 매수 (비중 확대)
Day +20 ~ +60: 본격 상승 (수익 실현 구간)

손절: 기준봉 시가 하향 이탈
```

### 4.4 시스템 구현 명세

```python
def detect_kijunbong(df_daily, lookback=20):
    """일봉 기준봉 탐지"""
    latest = df_daily.iloc[-1]
    body_ratio = abs(latest['close'] - latest['open']) / (latest['high'] - latest['low'])
    return_rate = (latest['close'] - latest['open']) / latest['open']
    volume_ratio = latest['volume'] / df_daily['volume'].iloc[-lookback-1:-1].mean()
    
    is_kijunbong = (
        body_ratio >= 0.70           # 몸통 70%+
        and return_rate >= 0.05      # 상승률 +5%+
        and volume_ratio >= 3.0      # 거래량 3배+
        and latest['close'] > latest['open']  # 양봉
    )
    return is_kijunbong, {
        'body_ratio': body_ratio,
        'return_rate': return_rate,
        'volume_ratio': volume_ratio,
        'kijunbong_open': latest['open']  # 손절 기준점
    }

def kijunbong_swing_entry(stock_code, kijunbong_info, df_after):
    """기준봉 후 매수 신호"""
    # 1. 눌림목 확인 (5~10일)
    # 2. 저점 > 기준봉 시가
    # 3. 다시 양봉 + 거래량 증가
    if (df_after.iloc[-1]['close'] > df_after.iloc[-1]['open']
        and df_after.iloc[-1]['volume'] > df_after['volume'].mean() * 1.5
        and df_after['low'].min() > kijunbong_info['kijunbong_open']):
        return 'BUY', kijunbong_info['kijunbong_open']  # 매수 + 손절가
    return None
```
