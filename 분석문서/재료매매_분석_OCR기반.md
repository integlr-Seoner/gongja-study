## 1. 핵심 개념 (1권 바이블 기준)

### 1.1 재료의 정의 (p.10)

> "재료를 한 마디로 정의할 수 있다면 필자는 **종목이 등락을 하기 위한 핑계거리** 정도로 정의할 수 있을 것 같습니다."

= **모든 재료가 매매 가능한 것은 아님**. 종목이 움직이는 명분 = "핑계".

### 1.2 재료의 크기 (p.12, 15, 20-22)

**같은 재료라도 크기가 다른 이유**:
1. 시장의 방향성 (지수 강세/약세)
2. 당시 이슈가 되는 다른 테마 (수급 분산)
3. 종목의 세력 자금력
4. 투자자들의 관심도 (관심 = 수급)

**예시**: 동일한 무상증자 공시
- **라온테크** (1.5주 무상증자): 단기 상승 후 윗꼬리
- **랩지노믹스** (1주 무상증자, 코로나 19 테마): 상한가
- 차이 = **테마 + 시장 분위기** (재료 자체보다 시장의 해석)

> "재료는 항상 절대적인 것이 아니라 **상대적으로 그 크기를 투자자들에게 평가**받습니다." (p.21)

### 1.3 재료를 판단하는 것은 투자자 (p.24)

> "주식시장에서 발생하는 뉴스와 공시를 보고 재료의 크기, 호재인지 악재인지를 판단하는 것은 **투자자의 묶**입니다."

- 매매를 하는 투자자들이 동일한 뉴스를 보고 매매 → 재료의 크기는 **시장 참여자가 결정**
- 단순 뉴스 자체가 아닌, **시장이 받아들이는 정도**가 핵심

### 1.4 공개적 재료로만 매매 (p.32)

> "내가 가장 빠르게 보았을 것이라고 생각하는 재료보다는 **이미 다 알고 있는 재료**로 접근하는 것이 중요합니다."

- '나만 아는 재료'는 함정
- DART/네이버/카톡방/유튜브 등에서 **이미 공유된 재료**가 안전
- 정보 확산 = 수급 유입 = 상승

### 1.5 재료 + 차트 병행 (p.37)

> "재료가 우리에게 매매를 할 수 있는 근거, 매매를 할 수 있는 기간, 비중 등을 설명해 준다면 **차트는 그 재료 안에서 조금 더 디테일하게 매매를 할 수 있는 기회를 제공**해준다고 생각합니다."

- 재료 = WHEN/HOW BIG (매수 명분, 보유 기간, 비중)
- 차트 = WHERE (지지/저항 = 매수/매도 정밀 타점)
- 호재 뉴스 + 매수 직후 하락 시 → 차트 보고 분할매수 평단 조정 가능

## 2. 재료의 종류 (1권 + 3권)

### 2.1 재료 분류 체계

```
재료 = 공시 + 뉴스
재료 = 호재 + 악재
재료 = 모멘텀 있는 재료 + 일정 있는 재료
일정 있는 재료 = 새로운 일정 부각 + 매년 반복 일정
모멘텀 있는 재료 = 신선한 재료 + 반복적 재료
```

### 2.2 모멘텀 있는 재료 vs 일정 있는 재료 (p.61, 3권 p.12)

| | 모멘텀 있는 재료 | 일정 있는 재료 |
|---|---|---|
| **정의** | 지속적으로 동일 주제 뉴스 보도 | 일정이 시작/끝나는 날짜 정해짐 |
| **상승 폭** | 100~200% (장기) | 10~30% (이벤트까지) |
| **매매 난이도** | 높음 (시점 판단) | 낮음 (날짜 명확) |
| **소멸 시점** | 모멘텀 약화 시 | 일정 당일 |
| **예시** | 로봇 테마, 2차전지, AI | 신규상장, 게임 출시, 정치인 재판 |

### 2.3 재료 발생 후 종목 움직임 패턴 (1권 p.83~94)

**3가지 패턴**:
1. **모멘텀 재료 + 즉시 상승**: '세계최초', '세계유일' 키워드 → 매수 직후 수익권
2. **모멘텀 재료 + 분할매수**: 1~3개월 모멘텀 지속, 기대감 차트 매수
3. **일정 재료 + 일정 당일 매도**: 일정 직전까지 보유, 당일 익절

## 3. 매매 전략 (1권 p.4 밑그림 + 본문 확장)

### 3.1 핵심 5원칙

1. **계획적 매매** — 차트 흐름 분석으로 진입 사전 준비
2. **분할매수 + 정찰병** — 불안 시 작은 비중부터 ("정찰병")
3. **재료 크기 + 매매 기간 매칭** — 단타 재료 vs 스윙 재료 구분
4. **매도 근거 무시 X** — 손절/익절 기준 도달 시 무조건 실행
5. **기대감에 배팅** — 결과(이벤트 당일)보다 기대감(이벤트 직전)에 매수

### 3.2 정찰병 = 분할매수 1차 (p.4)

> "불안하다면 분할매수! **정찰병을 보내자!**"

- 1차 매수 = 정찰병 (소액)
- 차트가 예상대로 → 2차 추가매수
- 차트가 예상과 다름 → 정찰병만 손절 (큰 손실 X)

### 3.3 종가배팅 (p.5 목차 + 6권 p.56, 147, 168)

> "재료를 보고 종가배팅을 할 때 고려해야 하는 점"

**조건**:
- 호재 뉴스 + 차트 지지 확인 + 종가 부근 매수
- 일정 있는 재료에서 이벤트 직전 종가 매수
- 다음날 시초가 갭상승 노림

**예시 (6권 p.56)**: 75 트릴리온 (이재명 후보 탈모 정책 관련주)
- 안철수-윤석열 단일화 결렬 뉴스 → 매일 소폭 상승
- "**종가배팅으로만 접근했어도 굉장히 좋은 수익이 매일 발생했던 흐름**"

### 3.4 비중배팅 + 겹재료 (p.5)

> "겹재료가 있다면 **비중배팅이 가능**할 수도 있다"

- 단일 재료 = 1배 비중
- **2개 이상 재료 겹침** (예: 대기업 관련 + 신규상장 + 정책 호재) = 비중 확대 가능

### 3.5 실망매물 인식 (p.5)

> "재료의 기대감이 사라진 경우에는 **실망매물**이 나온다"

- 일정 당일/이벤트 당일 = 기대감 소멸 = **실망매물 출현 = 하락**
- 매도 신호: 일정 당일 시초가 강세 → 장중 음전 → 종가 음봉

## 4. 6권의 핵심 정수 — 정치인 재판 사례 (6권 p.34~51)

이 부분은 **시스템 구현 가능한 가장 명확한 규칙**.

### 4.1 핵심 명제

> "**정치인 재판이 열렸을 때는 재판의 결과와 관계없이 관련 종목들의 주가는 재판일에 하락하는 흐름이 나타납니다.**"

= **정치인 재판 = 일정 있는 재료** → 결과 무관, 재판 당일 하락 확정

### 4.2 매매 시뮬레이션 (이재명 도지사 재판, 2020-09~10)

| 단계 | 시점 | 행동 |
|---|---|---|
| 1 | 재판 뉴스 보도 (선고기일 9/21 ~ 10/16 확인) | 모니터링 시작 |
| 2 | 1개월 전부터 분할 매수 | 에이텍, 에이텍티앤 |
| 3 | 재판 전날 (10/15) 까지 | 상승 흐름 즐기기 |
| 4 | 재판 당일 (10/16) | **무조건 매도** (결과 무관) |

### 4.3 시스템 구현 가능성

- DART 공시 + 키워드 매칭 ("재판", "선고기일", "공판") → 정치인 관련주 자동 식별
