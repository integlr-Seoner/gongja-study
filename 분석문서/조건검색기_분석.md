## 2. 기준선 매매 검색기 (스윙 매매 가이드북 검색기 소개 p.6~13)

### 2.1 검색기 정의

> **40일 이동평균선과 60일 이동평균선을 기준선으로 설정한 채 매매할 만한 종목을 필터링하는 검색기**

### 2.2 핵심 매매 명제 (p.11)

> "주가가 상승할 만한 근거인 재료가 발생했고, 유의미한 수급이 유입되면서 **1차 상승 파동이 나타난 종목의 주가가 40일 ~ 60일 이동평균선 부근까지 하락하면 높은 확률로 2차 상승 흐름이 나타난다**"

= **검색기의 본질 = "1차 상승 후 40~60일선 부근까지 하락한 종목" 자동 추출**

### 2.3 5가지 표준 조건식 (실제 키움 검색식)

#### 조건식 1: 상세이평돌파 (p.7)
```
키워드: 상세이평돌파
설정: [일][0봉전] (종가1)이평(종가40)이평을 10봉이내 데드크로스 1회이상
의미: 10일 이내 40일 이동평균선을 1번 이상 하향이탈한 종목
```

#### 조건식 2: 20일 평균 거래대금 (p.8)
```
키워드: 평균거래대금
설정: [금일제외] 20일 평균 100억 이상 (단위: 백만 = 10000 이상)
본문 인용: "1개월(20일) 평균 거래대금을 2000억으로 설정한 이유는 
기준선 매매를 할 때 최소한 이정도의 거래대금은 발생해야 
스윙 관점으로 매매할 만한 주가 변동성이 나타난다"
실제 적용 권고: 200~300억 이상 거래대금 종목 선호
```

#### 조건식 3: 주가 등락률 = 양봉 캔들 (p.9)
```
키워드: 주가등락률
설정: [일][0봉전](종)시가대비 0봉전 종가등락률 0% 이상
의미: 0봉전(=당일) 양봉 캔들 출현
본문 인용: "주가가 하락하고 있는 종목을 매매할 때 
양봉 캔들이 출현하면서 바닥이 잡히는 것을 확인하고 매수해야 
손실 발생 확률을 줄일 수 있다"
```

#### 조건식 4: 주가 이평 돌파 = 골든크로스 (p.10)
```
키워드: 주가이평돌파
설정: [일][0봉전] (종가1)이평(종가40)이평 골든크로스
의미: 주가가 40일 이동평균선을 상향 돌파 (골든크로스)
조건식 1과 결합: "10일 이내 40일 이평선을 하향 이탈했지만 
당일 40일 이평선을 다시 상향 돌파했다"
```

#### 조건식 5: 기간내 주가 변동폭 (p.10)
```
키워드: 기간내주가변동폭
설정: [일][0봉전까지 10봉간 최고최저폭 30% 이상]
의미: 10일 이내 주가 변동폭이 30% 이상인 종목
이유: "변동성이 작은 종목들은 주가가 지지부진하게 움직일 확률이 높다"
```

### 2.4 통합 조건식 (5가지 모두 AND 결합)

```
검색 조건 (모두 만족):
1. 10일 이내 40일 이평선 하향 이탈 1회 이상
2. 20일 평균 거래대금 ≥ 100억 (단, 200~300억 권장)
3. 당일 양봉 (시가 < 종가)
4. 당일 40일 이평선 상향 돌파 (골든크로스)
5. 10일 이내 주가 변동폭 ≥ 30%
```

= **"1차 상승 + 40일선 하향이탈 + 당일 골든크로스 + 양봉 + 충분한 변동성"** 5중 조건

### 3.1 정의

> "몇 가지 보조지표를 기준선으로 설정한 뒤 **눌림목을 공략하는 매매법**"

### 3.2 조건식 6가지

```
1. 기간내 주가 변동폭: [일][0봉전까지 40봉간 최고최저폭 100% 이상]
   (40일 이내 두배 이상 변동성 종목)
2. 10일 평균 거래대금: [백만 단위 10000 이상 = 100억]
3. 주가이평배열(3): [일][0봉전] 20이평 > 40이평 > 60이평
   (이평선 정배열)
4. 상세이평돌파: [일][0봉전](종가1)이평(저가20)이평 ...
5. 상세이평돌파: [일][0봉전](종가1)이평(저가40)이평 ...
6. 상세이평돌파: [일][0봉전](종가1)이평(저가60)이평 ...
7. 주가이평비교: [일][0봉전](종가1)이평 > (종가60)이평 1회이상
```

= **"40일 100%↑ 변동 + 100억 거래대금 + 20/40/60일선 정배열 + 종가가 60일선 위"** 조건

## 5. 볼린저밴드 하한선 매매 검색기 (p.36~41)

### 5.1 정의

> "보조지표를 활용하여 스윙 관점으로 매매할 때 사용했던 검색기"

### 5.2 매매 원칙 10가지 (p.41)

```
1. 주가가 일목균형표 구름대 위에 있는지 확인
2. 재료의 모멘텀이 유지되고 있는지 확인
3. 60일, 120일, 240일 이동평균선이 정배열되어 있는지 확인
4. 화살표가 포착되었는지 확인
5. 종가 혹은 저가가 볼린저밴드 하한선을 이탈했는지 확인
6. 볼린저밴드 하한선을 이탈한 다음 날 바로 바닥이 잡히는지 확인 후 매수
7. 바닥이 잡힌 양봉의 시가를 손절라인으로 설정 (장대양봉은 유동적 대응)
8. 5% ~ 10% 사이에서 분할매도 시작 (2차, 3차 상승은 짧은 수익부터 매도)
9. 재료 소멸로 볼린저밴드 하한선 이탈 시 절대 매수 금지
10. 추세 눌림 + 거래대금 + 재료 모멘텀 유지 시 화살표 없는 구간도 매매 가능
```

**핵심 손절 룰**:
- **양봉의 시가 = 손절 라인** (기준봉 매매와 동일 원리)

## 6. 기준봉 패턴 매매 검색기 (p.59~)

### 6.1 정의

> "**큰 거래대금이 발생하면서 큰 장대양봉 캔들이 출현한 종목**의 흐름을 모니터링하다가 매매 기회가 만들어졌다고 판단될 때부터 분할매수로 접근"

### 6.2 매매 진입

1. 기준봉 (큰 거래대금 + 장대양봉) 출현 시 **모니터링만**
2. 가격 조정 (눌림목) 형성 후
3. **기준봉의 중심 ~ 시가 부근**에서 분할매수 시작

### 6.3 손절

- 기준봉 시가 하향 이탈 시 손절

## 7. 고점 횡보 패턴 매매 검색기 (p.79~)

### 7.1 정의

> "기준봉이 출현하고 주가가 **가격 조정 없이 기간 조정만 보이면서 횡보할 때 기준봉의 종가 부근에서 분할 매수**하는 포지션"

### 7.2 기준봉 vs 고점 횡보 비교

| 패턴 | 매수 가격대 |
|---|---|
| 기준봉 패턴 | 기준봉의 **중심 ~ 시가** (눌림목 깊음) |
| 고점 횡보 패턴 | 기준봉의 **종가 부근** (눌림 없이 횡보) |

### 7.3 주의사항

> "고점에서 횡보하다가 추가적으로 상승하지 못한 채 기준봉의 중심 ~ 시가 부근까지 하락하는 경우도 있기 때문에 **'지금 매매하고 있는 종목이 기준봉 패턴 매매로 연결될 수도 있다'**는 것을 어느 정도 생각하고 매매"

## 8. 검색기 vs 관심종목 (p.90~98) — 매우 중요

### 8.1 결정적 명제 (p.90)

> "기준봉 패턴 매매, 고점 횡보 패턴 매매를 할 때만큼은 **검색기보다 관심종목에 무게를 두고 매매할 만한 종목을 필터링**할 것을 권해드립니다."

> "필자는 현 시점에 매매할 만한 종목의 **90% 이상을 검색기가 아닌 관심종목에서 찾고 필터링**하고 있습니다."

### 8.2 검색기의 한계 (p.90)

검색기 = "순간순간 나타나는 변동성 (주가 등락 및 거래대금 발생) 으로 종목을 필터링하는 도구"

검색기에 포착 안 되는 종목:
- **거래대금 없이 횡보하는 종목**
- **주가 변동성 없이 박스권 안에서 천천히 횡보하는 종목**

= 기준봉 후 눌림목 횡보 = 검색기 포착 안 됨 = 관심종목 활용 필요

### 8.3 관심종목 정리 작업 (p.98) — 매일 반복 작업

```
필자의 매일 작업 (장 마감 후):
1. '전일대비 등락률 상위' + '특정일자 상한가/하한가' 메뉴 켜기
2. 거래대금 300억 이상 + 주가 10~15% 이상 상승 종목 추출
3. 종목의 상승 이유를 종목 메모에 기록
4. 출처 우선순위: 텔레그램 채널 → 블로그 포스팅 → 종합 시황 → 네이버 검색
5. 시장 분위기 너무 좋을 때: 거래대금 기준을 500억으로 상향
```

= **매일 종목 메모 기록 = 시스템 구현 가능한 핵심 자동화 영역**

```python
    # 2. 시장 분위기 좋을 때 (BULL) 거래대금 기준 상향
    if get_market_state() == 'BULL_BROAD':
        candidates = scan_kiwoom(money_volume_min=50_000_000_000, ...)
    
    # 3. 각 종목 상승 이유 자동 수집 (DART + 뉴스)
    for stock in candidates:
        reasons = collect_news_reasons(stock)
        save_to_watchlist(stock, reasons, date=today)
    
    # 4. 텔레그램 알림 (관심종목 발견)
    send_telegram_alert(candidates)
```

### 9.3 현재 시스템과의 차이

| 항목 | 책 | 현재 시스템 |
|---|---|---|
| 검색식 우선 | **관심종목 90% > 검색기 10%** | 검색식 100% |
| 매일 관심종목 정리 | 매일 작업 | 없음 |
| 거래대금 게이트 | 100억~300억 | 일부만 |
| 이평선 정배열 게이트 | 필수 | 일부만 (PluginAnalysis) |
| 시장 분위기에 따른 검색기 변경 | 상승장/하락장 다른 검색기 | 일률 |

### 9.4 음의 알파 진단

**현재 41개 전략 중 책 본질과 불일치**:
- **Pivot, ABCSwing, ModernSniper, CandlePattern** = 책의 6가지 검색기에 포함 안 됨
- = 책에 없는 자체 전략 = 검증 없음 = 음의 알파 합리적

**책에 있는 검색기 = 현재 시스템에 부분 구현된 것**:
- 기준봉 매매 = `kijunbong_tracker.py` (현재 0건, 미작동)
- 이평선 매매 = `unified_ranking.py` 일부 사용
- 246 매매, 장기이평 매매, 볼린저 매매, 고점 횡보 매매 = **모두 미구현**
