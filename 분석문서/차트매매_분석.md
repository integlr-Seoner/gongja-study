## 2. 갭하락을 이용한 단타매매 (3권 p.14~35)

### 2.1 매매 대상 종목 6가지 (p.15)

| # | 조건 | 의미 |
|---|---|---|
| A | 하한가 캔들 | 어제 -30% 도달 |
| B | 하한가급 장대음봉 (-20% 이상) | 어제 큰 폭 하락 |
| C | 상한가 이후 다음날 갭락 | 차익실현 매물 |
| D | 악재 발생으로 다음날 하락 | 재료 소멸/악재 발생 |
| E | 시간외 단일가 하한가 | 장 마감 후 악재 |
| F | 장중에 하한가가 풀릴 때 | 매수세 유입 신호 |

### 2.2 매매 회피 조건 (p.16)

| 회피 조건 | 이유 |
|---|---|
| 시장 전체 하락으로 인한 하락 | 시장 약세 = 반등 실패 가능성↑ |
| 재료 소멸로 인한 하한가 | 모멘텀 소멸 = 추가 하락 |
| 1~4% 갭락 (5% 미만) | 충분한 기술적 반등 모멘텀 없음 |

= **5% 이상 갭락만 매매**.

### 2.3 매매 원칙 (p.27~35)

> "**갭락 단타는 빠르게 대응해야 한다.**"

- **5초~1분 이내 매도**가 일반적
- 매수 후 수익권 진입 시 즉시 분할매도
- 수익 발생 안 함 → -3% ~ -5% 손절 (절대 버티지 X)
- **1% ~ 2% 짧은 수익**이라도 챙기는 것이 정답

### 2.4 사례 (p.29~32)
- **중앙디앤엠**: 시초가 5초 만에 윗꼬리 → 5초 안에 매도해야 수익
- **모아데이타**: 20초간 +9% 후 급락 → 빠른 매도 안 하면 손실

= 갭락 단타 = **초단타 (5초~3분 매매)**, 일반 단타가 아님.

### 2.5 시스템 구현 가능성

```python
def 갭락_단타_검색():
    조건1 = 전일종가_대비_시초가_-5%_이하
    조건2 = 어제_-20%_이상_하락_or_시간외_하한가
    조건3 = NOT 재료_소멸_or_시장_전체_하락
    return matched_stocks

def 갭락_단타_매수_매도():
    매수시점 = 시초가 (open price)
    매도시점 = 5초~1분 내 +1~2% 수익 시 즉시
    손절시점 = -3% ~ -5%
```

**현재 시스템과의 차이**:
- 현재 `Fallen` 전략은 **D~F등급 종목 매수** (재료 소멸 + 약세)
- 책은 **5% 이상 갭락 + 재료 유지 종목만** 매매
- **결정적 차이**: 보유 기간 (책=초단타 5초~1분 / 현재=20~30일)

## 3. 캔들 패턴 매매 (3권 p.36~)

### 3.1 핵심 명제 (p.38)

> "모든 패턴이 반드시 수익을 가져다주는 것은 아니다. 캔들패턴은 **수익을 보장해주는 매매 방법이 아니라 추가적인 상승 가능성이 높다는 과거 통계를 바탕**으로 매매하는 것."

= 패턴 = 확률 우위만 제공, 손절 필수.

### 3.2 패턴 종류

| 패턴 | 예시 | 정의 |
|---|---|---|
| **쌍바닥 (W)** | 신풍제약 | 두 번의 바닥을 잡고 상승 |
| **다중 바닥** | 대성에너지 | 2~3회 이상 바닥 |
| **고점 횡보** | (이후 p.) | 고점에서 박스 |
| **기준봉** | (이후 p.) | 큰 양봉 = 매집 흔적 |
| **음봉 시가 회복** | (이후 p.) | 음봉 후 다음날 시가 돌파 |
| **2중 봉우리 (M)** | - | 천장 패턴 (매도 신호) |

### 3.3 매매 원칙 (p.42~45)

#### 쌍바닥 패턴 매매
1. **2회 바닥 확인** (이전 저점 이탈 X)
2. **이전 고점 돌파 시 매수** = 신뢰성 높은 진입
3. **손절라인** = 이전 두 바닥 가격대
4. **거래량 + 고점 돌파** 동시 충족 시 진입 확률 ↑

#### 다중봉의 분봉 공통성
- **1분/3분/5분봉 동일 패턴 출현** = 신뢰도 ↑
- 1분봉에 쌍바닥 나타나면 3분/5분봉도 동일 패턴 확인

### 4.2 적정 거래대금의 개념

- **종목의 시가총액 대비 거래대금 비율**

## 5. 이동평균선 + 기준봉 (중장기, 스윙)

### 5.1 기준봉 정의 (재료매매 + 차트매매 공통)

> **기준봉 = 거래량/거래대금 급증을 동반한 장대양봉**

= 세력의 매집 흔적 = 향후 상승 추세 시작점

### 5.2 기준봉 매매 (3권)

1. 일봉 차트에서 거래대금 급증 + 장대양봉 출현
2. 이후 1~5일 눌림목 (조정)
3. 눌림목 지지 확인 시 매수
4. 다시 거래량 증가 + 양봉 출현 → 추가 매수
5. 손절 = 기준봉 시작가 (장대양봉 시가)
