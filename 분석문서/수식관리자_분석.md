## 2. 핵심 함수 레시피 (코드 예시)

### 2.1 산술연산자 (p.7~9)

```
종가/고가/저가/시가의 합:
O + H + L + C
또는: C(0) + C(1) + C(2) + C(3) + C(4)
의미: 당일~4일전 종가 합

H - L (고가와 저가 차이값)
V - V(1) (금일 거래량과 전일 거래량 차이값)

V(1) * 10 (전일 발생 거래량의 10배)
C(1) * 1.1 (전일 종가보다 10% 상승)
DAYOPEN * 1.1 (당일 시가보다 10% 상승)

5일 평균 거래량:
(V + V(1) + V(2) + V(3) + V(4)) / 5

캔들의 중심:
(O + C) / 2

5일 이동평균선:
(C + C(1) + C(2) + C(3) + C(4)) / 5
```

### 2.2 관계연산자 (p.12~)

```
양봉/음봉 판단:
A = V > V_AVG (V_AVG = 5일평균거래량)
A_DOWN = O > C  (음봉 캔들)
A_UP = O < C    (양봉 캔들)

도지 캔들:
O == C
또는 (C - O) / C * 100 < 0.5

상한가 캔들:
H == L  (점 상한가, 점 하한가, 거래정지)

가격 변동:
C != C(1) (금일 종가와 전일 종가가 다름 = 주가 변동)
```

### 2.3 가격함수 응용 (p.22~)

```
장대양봉 정의:
(C - O) / O > 0.05  (상승률 +5% 이상)
AND (C - O) / (H - L) > 0.7  (몸통 비율 70% 이상)

기준봉 정의 (책의 핵심):
장대양봉 + V > V_AVG_20 * 3  (20일 평균 거래량 3배 이상)

신고가:
H == HIGHEST(H, 20)  (20일 최고가)

신저가:
L == LOWEST(L, 20)  (20일 최저가)
```

## 3. 이평선 배열 함수 (Ch.11, p.80~92)

### 3.1 정배열 정의

```
이평선 정배열:
MA5 > MA20 > MA60 > MA120

조건식:
A = (CLOSE_AVG(5) > CLOSE_AVG(20)) AND
    (CLOSE_AVG(20) > CLOSE_AVG(60)) AND
    (CLOSE_AVG(60) > CLOSE_AVG(120))
```

### 3.2 5일선 위치 확인 (단타매매 책 권고)

```
A = C > CLOSE_AVG(5)  (현재 종가가 5일선 위)
```

### 3.3 골든크로스 / 데드크로스

```
골든크로스 (단기선 > 장기선, 1봉 전 반대):
CLOSE_AVG(5) > CLOSE_AVG(20) AND
CLOSE_AVG(5)(1) < CLOSE_AVG(20)(1)

데드크로스 (단기선 < 장기선, 1봉 전 반대):
CLOSE_AVG(5) < CLOSE_AVG(20) AND
CLOSE_AVG(5)(1) > CLOSE_AVG(20)(1)
```

## 4. 돌파이탈 함수 (Ch.12, p.93~110)

### 4.1 저항선 돌파

```
저항선 = 최근 N일 최고가
A = C > HIGHEST(H, 20)(1)  (오늘 종가 > 어제까지 20일 최고가)
= 신고가 돌파
```

### 4.2 지지선 이탈

```
지지선 = 최근 N일 최저가
A = C < LOWEST(L, 20)(1)  (오늘 종가 < 어제까지 20일 최저가)
= 신저가 이탈 = 손절 신호
```

### 4.3 기준봉 돌파

```
기준봉 시가 = 기준봉이 발생한 날의 시가 (저장)
A = C < KIJUNBONG_OPEN  (종가가 기준봉 시가 이탈) = 손절 신호
```

## 8. 시스템 구현 매핑 (수식관리자 → StockAnalyst Pro v2.0)

### 8.1 핵심 함수 Python 변환

```python
# korean_indicators.py — 수식관리자 함수 Python 구현
import numpy as np
import pandas as pd

def is_jangdae_yangbong(df, idx=-1):
    """장대양봉 (몸통 70%+, 상승률 +5%+)"""
    row = df.iloc[idx]
    body_ratio = abs(row['close'] - row['open']) / (row['high'] - row['low'])
    return_rate = (row['close'] - row['open']) / row['open']
    return body_ratio > 0.7 and return_rate > 0.05

def is_kijunbong(df, idx=-1, vol_lookback=20):
    """기준봉 = 장대양봉 + 거래량 3배"""
    if not is_jangdae_yangbong(df, idx):
        return False
    vol_avg = df['volume'].iloc[idx-vol_lookback:idx].mean()
    return df['volume'].iloc[idx] >= vol_avg * 3.0

def is_doji(df, idx=-1, threshold=0.005):
    """도지 캔들 (시가 ≈ 종가)"""
    row = df.iloc[idx]
    return abs(row['close'] - row['open']) / row['close'] < threshold

def is_ma_aligned_bullish(df, idx=-1, periods=(5, 20, 60, 120)):
    """이평선 정배열 (MA5 > MA20 > MA60 > MA120)"""
    mas = [df['close'].rolling(p).mean().iloc[idx] for p in periods]
    return all(mas[i] > mas[i+1] for i in range(len(mas)-1))

def is_above_ma5(df, idx=-1):
    """종가가 5일선 위"""
    ma5 = df['close'].rolling(5).mean().iloc[idx]
    return df['close'].iloc[idx] > ma5

def is_golden_cross(df, idx=-1, short=5, long=20):
    """골든크로스 (단기선이 장기선을 위로 돌파)"""
    short_today = df['close'].rolling(short).mean().iloc[idx]
    long_today = df['close'].rolling(long).mean().iloc[idx]
    short_yest = df['close'].rolling(short).mean().iloc[idx-1]
    long_yest = df['close'].rolling(long).mean().iloc[idx-1]
    return short_today > long_today and short_yest <= long_yest

def is_new_high(df, idx=-1, lookback=20):
    """N일 신고가"""
    return df['high'].iloc[idx] >= df['high'].iloc[idx-lookback:idx].max()

def price_range_pct(df, idx=-1, lookback=10):
    """N일 진폭 (변동성)"""
    high_max = df['high'].iloc[idx-lookback:idx+1].max()
    low_min = df['low'].iloc[idx-lookback:idx+1].min()
    return (high_max - low_min) / low_min

def is_above_ichimoku_cloud(df, idx=-1):
    """일목균형표 구름대 위"""
    # 전환선 (9봉 평균)
    conversion = (df['high'].rolling(9).max() + df['low'].rolling(9).min()) / 2
    # 기준선 (26봉 평균)
    base = (df['high'].rolling(26).max() + df['low'].rolling(26).min()) / 2
    # 선행스팬 1 (26봉 후 이동)
    span_a = (conversion + base) / 2
    # 선행스팬 2 (52봉 평균, 26봉 후 이동)
    span_b = (df['high'].rolling(52).max() + df['low'].rolling(52).min()) / 2
    return df['close'].iloc[idx] > span_a.iloc[idx-26] and df['close'].iloc[idx] > span_b.iloc[idx-26]

def money_volume_check(df, idx=-1, threshold_won=10_000_000_000):
    """거래대금 체크 (기본 100억)"""
    money = df['close'].iloc[idx] * df['volume'].iloc[idx]
    return money >= threshold_won
```

### 8.2 종합 매수 게이트 (모든 매수 신호에 적용)

```python
def korean_buy_gate(df, idx=-1):
    """책의 핵심 게이트 — 모든 매수 신호에 통과 필수"""
    gates = {
        'ma_aligned': is_ma_aligned_bullish(df, idx),
        'above_ma5': is_above_ma5(df, idx),
        'volume_money_ok': money_volume_check(df, idx, threshold_won=10_000_000_000),
        'price_range_ok': price_range_pct(df, idx, lookback=10) >= 0.30,
        'above_cloud': is_above_ichimoku_cloud(df, idx),
        'not_doji_today': not is_doji(df, idx),
    }
    passed = sum(gates.values())
    return passed >= 5, gates  # 6개 중 5개 이상 만족 시 BUY
```

### 10.3 핵심 함수 (기본편 + 심화편 OCR 직접 추출)

#### 10.3.1 산술/관계/논리 (p.7~13)
```
O, H, L, C = 시가, 고가, 저가, 종가
V = 거래량
V_AVG = (V + V(1) + V(2) + V(3) + V(4)) / 5  (5일평균거래량)

양봉:   C > O
음봉:   C < O
도지:   C == O
상한가: H == L
거래정지: V == 0
```

#### 10.3.2 이동평균선 (기본편 p.71~74)
```
이평선 5일:    MA(C, 5)        = (C+C(1)+C(2)+C(3)+C(4))/5
이평선 정배열: MA(C,5) > MA(C,10) AND MA(C,10) > MA(C,20)
              AND MA(C,20) > MA(C,60) AND MA(C,60) > MA(C,120)

골든크로스 (5/120): 
A = MA(C, 5)
B = MA(C, 120)
CrossUp(A, B) = A > B AND A(1) < B(1)

데드크로스:
CrossDown(A, B) = A < B AND A(1) > B(1)

# 핵심 규칙: 이평선 정배열 검증은 인접 이평선 2개씩 묶어서 비교
# (5,10) (10,20) (20,60) (60,120) — 꼬임 현상 거름
```

#### 10.3.3 일목균형표 (기본편 p.79~82)
```
선행스팬 1 = (전환선 + 기준선) / 2
            = ((MA(H,9) + MA(L,9))/2 + (MA(H,26) + MA(L,26))/2) / 2 (26봉 후 이동)

선행스팬 2 = (MA(H, 52) + MA(L, 52)) / 2 (26봉 후 이동)

구름대 위 (주가 강세):
A = 선행스팬 1
B = 선행스팬 2
C > A AND C > B AND A > B  # 양의 구름대 + 주가 위

구름대 아래 (주가 약세):
C < A AND C < B AND A < B  # 음의 구름대 + 주가 아래
```

#### 10.3.4 볼린저밴드 (기본편 p.79~82, p.140~152)
```
중심선   = MA(C, 20)
상한선   = MA(C, 20) + 2 * STD(C, 20)
하한선   = MA(C, 20) - 2 * STD(C, 20)

볼린저 상한선 돌파 (단타 강세 신호):
A = BollingerBandUp(C, 20, 2)
CrossUp(C, A)

# 책의 핵심 통계 (기본편 p.140~141):
# 볼린저밴드 상한선 아래에서 주가 형성 확률 = 90%+
# 볼린저밴드 상한선 돌파 확률 = 10% 미만
# → 상한선 돌파 = 강세 신호 = 단기 매매 가능
```

### 10.6 핵심 발견 — 일목균형표 구름대 게이트 (기본편 p.131)

> "**일목균형표 구름대 위에 주가가 형성되어야 하며 구름대 위에 있는 종목들만 매매하는 것이 계좌를 지킬 수 있는 방법** 중 하나"

> "100 종목 ~ 1000 종목의 과거 차트를 돌려보시면 주가가 구름대 아래로 하방 이탈을 한 이후부터는 힘을 쓰지 못하고 하락을 지속하는 경우가 많으며 **상장폐지나 거래정지가 된 종목들도 대부분은 구름대 아래에서 그런 현상**이 나타나는 것을 쉽게 확인"

= **일목균형표 구름대 위 = 매수 가능 종목의 게이트**.

### 10.7 시스템 구현 (신규)

```python
# korean_indicators_v2.py — 책의 모든 함수 Python 변환

def 일목구름대_위(df, idx=-1):
    """일목균형표 구름대 위에 주가가 있는지 (책의 가장 강한 게이트)"""
    # 선행스팬 1 = (전환선 + 기준선) / 2, 26봉 후 이동
    tenkan = (df['high'].rolling(9).max() + df['low'].rolling(9).min()) / 2
    kijun = (df['high'].rolling(26).max() + df['low'].rolling(26).min()) / 2
    span_a_today = (tenkan.iloc[idx-26] + kijun.iloc[idx-26]) / 2  # 26봉 전 데이터로
    # 선행스팬 2 = 52봉 평균
    span_b_today = (df['high'].rolling(52).max().iloc[idx-26] + df['low'].rolling(52).min().iloc[idx-26]) / 2
    
    return df['close'].iloc[idx] > span_a_today and df['close'].iloc[idx] > span_b_today

def 볼린저_상한선_돌파(df, idx=-1, period=20, std=2):
    """볼린저밴드 상한선 돌파 (10% 미만 확률 = 강세 신호)"""
    ma = df['close'].rolling(period).mean()
    sd = df['close'].rolling(period).std()
    upper = ma + std * sd
    return (df['close'].iloc[idx] > upper.iloc[idx]
            and df['close'].iloc[idx-1] <= upper.iloc[idx-1])

def 신고가_240일(df, idx=-1, lookback=240):
    """52주 (240일) 신고가 갱신"""
    return df['close'].iloc[idx] >= df['close'].iloc[idx-lookback:idx].max()

def 낙주매매_엔벨로프_반등(df, idx=-1):
    """엔벨로프 (5, 10) 지지선 상향 돌파 + 양봉"""
    ma5 = df['close'].rolling(5).mean()
    envelope_lower = ma5 * 0.9
    return (df['close'].iloc[idx] > envelope_lower.iloc[idx]
            and df['close'].iloc[idx-1] <= envelope_lower.iloc[idx-1]
            and df['close'].iloc[idx] > df['open'].iloc[idx])

def 3음봉_조정후_반등(df, idx=-1):
    """3음봉 조정 후 반등 (심화편 p.173)"""
    c = df['close']
    return (c.iloc[idx-3] < c.iloc[idx-4]
            and c.iloc[idx-2] < c.iloc[idx-3]
            and c.iloc[idx-1] < c.iloc[idx-2]
            and c.iloc[idx] > c.iloc[idx-1])  # 4번째날 반등
```
