## 이 코퍼스의 큰 그림 (한 문장)

개인 투자자는 주가를 만들 수 없으므로, **재료로 관심이 몰려(수급) 큰 거래대금이 터진 장대양봉(기준봉)** 을 세력의 흔적으로 보고, 그 흔적이 만든 **지지 구조(기준봉 시가·중심선)에서 조정 시 분할 매수**하여 **추세 유지되는 동안 분할 매도**한다. 재료가 소멸하면 즉시 판다. — 6개 트랙(차트·일봉수급·재료·단타·수식관리자·스윙·조건검색기)이 이 한 문장의 서로 다른 각도다.

## Part A. 핵심 개념 카드

### 1. 기준봉 ★최우선 `[G4764·G4810·G4841~4849·G4920~4935]` `[CASE 65건]`
- **정의**: 평소와 다른 큰 거래대금이 발생하며 세워진 장대양봉(보통 +10~15%↑). "추세 자체를 바꾸는(횡보/하락→상승) 기준 캔들".
- **핵심 판별**: 거래량(수급) 동반 여부. 거래대금은 절대값이 아니라 **그 종목의 출현 전 대비 상대적**으로 커야 함. 재료 동반 시 신뢰도↑. 보조지표(볼밴·이평) 미사용 — 거래량·거래대금이 메인 지표.
- **매매법**: 기준봉 3영역 = 시가(매수세 시작=지지)·중심선(단기 저항↔지지 전환)·종가. 타점 = 하락 깊이별 ①종가 부근(얕은 조정) ②중심선 부근(시초 -4.5%↓) ③시가 부근(고점 대비 -20%). **손절 = 기준봉 시가 이탈**. 2~3회 분할, 비중 보수 5%.
- **정량화**: 가능 = 손절 라인(시가), 분할 횟수·비중 / 조건검색식 화살표 = `거래대금 > Avg(거래대금(1),240)×N && C>O && H>Highest(H(1),40) && C>C(1)×1.15` (N=×10~×20, 매매법별 조정). 불가(수동) = "장대양봉·거래량 발생"의 절대 임계.
- **연결 CASE**: 대표 CASE-0218 안랩(2023-01-25)·0242 일동제약·0252 KCC / 성공 64·실패 1(0091 NPC 지수역상관 손절). 전체 §D.
- **주의**: 저자 방법론의 본진(스윙 기준봉 예시집 565p). "물려도 되는 구간(중심선~시가)"은 손절 회피 합리화로 오용 금지.

### 2. 적정 거래대금 `[G4820·G1170·G1182·G4917~4919·G4941]` `[데이트레이딩 계열 CASE 71건]`
- **정의**: "주가가 상승하기 위해 **발생해야 하는 최소한의 거래대금**"(종목별 최소 상승 임계). 수치로 딱 정의 불가 — 차트 흐름 눈대중.

- **매매법**: 개인 원칙 = "거래대금 200억↑ + 재료 있는 종목만 매매". 9~10시 거래대금 ×2 ≈ 종가 거래대금(장중 예측).

- **연결 CASE**: 데이트레이딩 실전 다수 — 0022 WI·0024 경동인베스트·0084~0088(1번→2번 재상승). 전체 §D.
- **충돌 참조**: 정의의 "분위수 vs 중심값"은 §B C01 참조(→ "최소 임계"가 저자 원본).

### 4. 낙폭과대(낙주) `[G4789·G4894~4912·G4900]` `[낙폭과대·갭하락 계열 CASE 59건]`

## Part B. 트랙 간 충돌·경계 (원본 `92_트랙간_충돌.md`)

- **C01 — 적정 거래대금의 정의**: 재료 트랙 = 재료일 거래대금의 40분위(하단, α≈0.32) / 차트 트랙 = 상승일 중심값. **판정(부분 해소)**: 저자 원본(스윙 2권 G4820) = "**최소 상승 임계**"가 정답 → 40분위 "하단"과 일치. 잔여 = 정확한 분위수-임계 수치 대응은 종목별 눈대중.
- **C02 — 시간프레임 "합리화 도피" 금지**: 단타로 산 종목을 손절 못 해 "스윙으로 보겠다→중장기로 보겠다"로 하향 전환하는 것은 **비자발적 물림**(저자 명시 금지, G4752). 각 트랙 진입은 그 트랙 손절로 닫는다. **충돌 아님 = 경계 규칙**.
- **C03 — 낙폭과대 단타 vs 스윙**: 핵심 명제(단기 급락→반등 확률↑)는 **양 트랙 동일**(G1799↔G4895). 단 시간축 상이 — 단타=분봉(1분 -2%)·데이트레이딩 청산 / 스윙=일봉 장대음봉(-15%)·며칠 반등. **교차 오용 금지**(단타 낙주를 스윙 낙주로 넘기지 말 것).

## Part C. 오답지점 — 판독·해석 교훈 (원본 `93_오답지점.md`)

정독·데이터 검증 시 재발 방지용. Stage 1 사례의 신뢰도가 이 교훈들 위에 서 있다.

- **E01 — "구간 최고" ≠ 일봉 고가**: 차트 헤더의 "구간 최고/최저"는 표시 윈도 종속값 → KRX 일봉 OHLC로 등치 금지.
- **E02 — 헤더 4값 동일 = 커서 아티팩트**: O/H/L/C가 완전 동일하면 실제 봉이 아니라 크로스헤어 리드아웃 의심 → 캔들 몸통/꼬리로 재확인.
- **E03 — "리스크 예시" ≠ 결과 실패**: 저자가 whipsaw 리스크로 든 종목이 실측은 상한가 마감(CASE-0006~0010). 장중 변동성 경고 ≠ 종가 실패. 종가까지 확인 후 해석.
- **E04 — 조건식 수치 자릿수 오독**: 숫자+한글 붙여쓰기 시 뒤 한글 첫 자음 ㅇ(이상/이평/억)을 0으로 오인해 10배 부풀림("20이평"→"200이평"). **입력 필드(숫자 박스) 또는 저자 프로즈(억 단위)로 교차 확인**, 리스트 표시로 확정 금지. 도메인 상식과 어긋나면(2400일 이평) 오독 신호.

> ★ 종합 교훈: **차트 라벨·리스트 표시로 수치 확정 금지, KRX 실측·입력 필드가 최종 근거.** 사례대장 전 건이 이 원칙으로 KRX 대조됨.
