## 🔴🔴🔴 DB 저장/로드 규칙 (절대 위반 금지!) 🔴🔴🔴

### 스캔 결과 저장 규칙

| 항목 | 규칙 | 위반 시 문제 |
|------|------|-------------|
| **date 컬럼** | `get_last_business_day()` 사용 | 날짜 불일치 |
| **created_at 컬럼** | `datetime.now()` 사용 (필수) | 최신 데이터 판별 불가 |
| **저장 위치** | 자체 _v2 테이블 + strategy_results 둘 다 저장 | 로드 시 데이터 없음 |

### 스캔 결과 로드 규칙

```python
# ✅ 올바른 쿼리 - created_at DESC 사용
SELECT * FROM rs_targets_v2 ORDER BY created_at DESC LIMIT 50

# ❌ 잘못된 쿼리 - date DESC 사용 금지!
SELECT * FROM rs_targets_v2 ORDER BY date DESC LIMIT 50
```

**이유**: 장 시작 전 스캔 시 `date`는 전일이지만 `created_at`은 오늘 → `date DESC`로 조회하면 최신 스캔 결과가 아닌 오래된 데이터 반환

### 저장/로드 경로 일치 필수

```
저장: trading_system.db → rs_targets_v2
로드: trading_system.db → rs_targets_v2  ✅ 일치

저장: closing_bet.db → strategy_results
로드: trading_system.db → smc_structure_v2  ❌ 불일치 → 데이터 없음!
```
