## 2. 확정된 데이터 소스 우선순위

- **KRX Open API 제외 근거**: 공식 서비스 목록에 NXT 카테고리 없음 + endpoint 패턴 8종 실측 404. 확정적
- **키움 OpenAPI+ 선택 근거**: 2025-02-20 공식 업데이트로 NXT 완전 지원 (조회/주문/조건검색). Seoner 계정의 모듈은 2025년 연말 신청이므로 NXT 반영 버전 확정
- **네이버 API 유지 근거**: 현재 운영 중 + 백업 소스로 가치. 단, 정책 변경 시 재검토 필요 명시
- **DART 유지 근거**: 저녁 catalyst의 본질인 공시·뉴스 이벤트 수집에 필수

### 40-B. 실측한 핵심 사실
- `trade_log` 스키마: 21컬럼, 1,033행 (2025-12-29~2026-04-06, 128종목)
- `trade_log.date` YYYYMMDD 포맷 → `v4_observations.date` 와 직접 JOIN 가능
- `trade_log.action` 'BUY'/'SELL' 대소문자 혼용 → `UPPER(action)` 필수

### 40-C. 본 세션의 결정 — 데이터 대기 중 준비 작업
Seoner 원칙 ("데이터 근거 + 원칙 준수 시 일일이 문의 불필요") 에 따라:
- 분석·백필은 데이터 없으면 공허 → 단순 준비만
- 두 스크립트 모두 **빈 테이블 감지 → 우아한 종료** 구현
- Phase 3A 관찰 데이터 쌓이면 즉시 실행 가능

### 40-D. v4_actual_return_backfill.py 로직
```
1) actually_bought 백필:
   FOR 각 obs 레코드 (actually_bought=0):
     MATCH trade_log.date = obs.date AND code = obs.code AND UPPER(action)='BUY'
     IF 매칭 건 > 0: UPDATE actually_bought = 1

2) actual_return 백필:
   FOR 각 obs 레코드 (actual_return IS NULL, date < today):
     KRX get_market_ohlcv_by_date(obs.date, obs.date+7일) 조회
     t0_close = 첫 행 종가, t1_open = 두 번째 행 시가
     actual_return = (t1_open / t0_close - 1) * 100
     time.sleep(0.5)  # rate limit
```
