### 1.3 왜 ps=0.05 인가 (Seoner 5억 기준)

### 2.2 Phase B 로직

```python
def get_v4_params(regime_state):
    """
    regime_state: str — 'BULL', 'SIDEWAYS', 'BEAR'
    (KOSPI 20일 수익률 기반 분류)
    """
    if regime_state == 'BULL':
        # 공격 — §34 검증 (CAGR +5.24%p 기여)
        return {'working_ratio': 0.50, 'per_stock': 0.10}
    else:
        # SIDEWAYS / BEAR — 표준 유지
        # 특히 BEAR 에서 축소는 가치 없음 (V4 자체 양수)
        return {'working_ratio': 0.30, 'per_stock': 0.05}
```

## 3. 과적합 검증 통과 (§35)

| 방식 | 결과 | 판정 |
|------|------|------|
| A1 시점 분할 (P1→P2+P3) | P1 Top 5 중 4/5 가 P2+P3 Top 15 이내 | ✅ 기각 |
| A2 앞뒤 분할 (74+74) | 전반 Top 5 중 3/5 가 후반 Top 15 이내 | ✅ 기각 |
| A3 롤링 윈도우 (60→12 × 7회) | 7/7 윈도우 양수 | ✅ 기각 |

### 3.1 파라미터 안정성 (7개 윈도우)

| 파라미터 | 값 | 선택 빈도 |
|---------|-----|----------|
| wr=0.15 | 매우 보수적 | 5/7 (71%) |
| ps=0.10 | 슬리피지 무시 시 최적 | 6/7 (86%) |

§35 는 슬리피지 무시 조건 — ps=0.10 이 수학적 최적. §36 슬리피지 반영하면 자본별 최적값 달라짐 (§36 표).

## 9. 미해결 사항 (투명성, v2 §10 보완)

### 9.1 ETF/ATS 거래 슬리피지 모델
§36 은 일반 주식만 측정. ATS (대체거래소) 또는 ETF 는 모델링 안 됨.

### 9.2 체결 실패율
상한가/하한가 근접 시 T+1 시초가 매수 체결 실패 가능성 미반영. §36 모델에서는 항상 체결 성공 가정.

### 9.3 T+1 시초가 매도 슬리피지
§36 모델은 T0 종가 매수와 T+1 시초가 매도 슬리피지를 대칭 가정. 실제 T+1 시초가는 변동성 클 수 있음 → 슬리피지 1.5~2배 각오 권장.

### 9.4 시장 급변기 파라미터 유효성
2020-03 코로나 급락, 2022 하락장 같은 극단 시기 샘플 부족. Phase B 적용 시 이런 시기 특별 규칙 필요 가능.
