## v6 최종 규칙 (이중 지수 기반)

### Layer 0: 이중 지수 국면 판단

```python
def classify_dual(kospi_20d, kosdaq_20d):
    # 양쪽 모두 -5% 이하: 최대 기회 (실측 승률 77~90%)
    if kospi_20d <= -5 and kosdaq_20d <= -5:
        return 'S5_강약세'  # ★★ 적극 매수
    
    # 한쪽만 -5% 이하: 부분 약세 (상대적 강세 쪽 찾기)
    if kospi_20d <= -5 or kosdaq_20d <= -5:
        return 'S5_부분약세'
    
    # 양쪽 모두 0~5%: 방향성 없는 함정 구간
    if 0 <= kospi_20d < 5 and 0 <= kosdaq_20d < 5:
        return 'S3_함정'  # 🚫 매매 중단
    
    # 양쪽 모두 5% 이상: 동반 강세 (진짜 강세장)
    if kospi_20d >= 5 and kosdaq_20d >= 5:
        return 'S2_동반강세'
    
    # 양쪽 모두 10% 이상: 급등 과열
    if kospi_20d >= 10 and kosdaq_20d >= 10:
        return 'S1_과열'
    
    return '혼조'
```
