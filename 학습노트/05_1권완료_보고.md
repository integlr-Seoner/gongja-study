## 2. 책의 결정적 매매 룰 종합 (Top 20)

### 2.1 재료 매매의 본질 ⭐⭐⭐⭐⭐
1. **"내가 아는 뉴스는 누구나 다 알고 있다"** — 공개 재료 분석 능력이 핵심 (p.226)
2. **재료 매매 = 실적과 무관한 상승** — 매년 적자 종목도 재료 부각 시 상승 (p.110)
3. **"홀짝보다는 기대감에 배팅"** — 방향성 모르는 매매 X (p.161)

### 2.2 기준봉 룰 ⭐⭐⭐⭐⭐
4. **기준봉의 시가 = 투자자들이 호재로 인식한 시점에 상승 시작된 가격** (p.96)
5. **기준봉 시가 이탈 X = 모멘텀 살아있음 = 언제든 재상승 가능** (p.167)
6. **기준봉 등락률 15~30% 이상**, 3/5/10 분할 매수 (p.100)
7. **재료 있어도 기준봉 시가 이탈 → 손절, 회복 시 재차 매수** (p.226)

### 2.3 매매 시점 룰 ⭐⭐⭐⭐⭐
8. **5거래일 이내 뉴스 + 큰 상승 이끌어낸 재료** = 우선순위 1번 (p.111)
9. **종가배팅 시간: 15:20~15:30 (동시호가) + 16:00~18:00 (시간외)** (p.171)
10. **일정 재료 매매**: 1개월 이내 → 즉시 3분할 / 2~3개월 → 1개월 전 1차 매수 (p.190~191)
11. **선반영 시**: 일주일 또는 3~4일 전 미리 매도 (p.191)

### 2.4 호재/악재 매매 룰 ⭐⭐⭐⭐⭐
12. **호재 발생 시 = 조정/눌림 공략, 악재 발생 시 = 갭하락 후 반등 공략** (p.56)
13. **유상증자**: 3자 배정(호재) vs 주주배정/실권주(악재) (p.52)
14. **무상증자**: 1:1 비율 이상 권장 (p.126)

### 2.5 시장 분석 룰 ⭐⭐⭐⭐⭐
15. **대장주 > 2/3등주 변동성 위계** — 대장주 매매 권장 (p.97)
16. **대기업 + 국제 이슈 = 큰 상승, 중소기업 = 큰 상승 X** (p.93)
17. **시장 주도 테마 확인 필수** — 같은 날 상승 종목 분석 (p.88)

### 2.6 리스크 관리 룰 ⭐⭐⭐⭐⭐
18. **"반드시 매도해야 하는 근거 = 재료 소멸"** — 망설이지 않고 매도 (p.156)
19. **물타기 (X) vs 계획적 분할 매수 (○)** — 재료/기준봉 기반 평단 관리 (p.159)
20. **"100% 확률 없다"** — 정찰병 + 분할 매수 + 빠른 손절 (p.142~146)
