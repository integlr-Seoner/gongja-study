## G549. [자료집 개요] 주가 흐름 추적 자료집 — '직접 활용' 실습 (머리말·INDEX)
- **성격**: 일방적 정보 전달 X → **독자가 직접 활용**하는 자료집. 큰 거래대금+급등+재료 발생 흐름을 직접 종가~고가 가격/등락률 체크하며 역추적.
- **핵심 명제**: '수급과 재료 & 차트를 함께 보면 매매 기회가 보인다.'
- **INDEX(3부)**: ① 주가의 흐름 추적 ② 엑셀 자료 활용 방법 ③ 엑셀 & PPT 활용.
- **위상**: 적정거래대금 이론(G458~548)의 **실습판** — 이론을 눈으로 읽는 대신 직접 데이터를 수집·역추적해 '본인만의 매매 관점'을 형성하는 것이 목적.

## G550. Part 01 주가 흐름 추적 ①② — 얻는 데이터 + 포스코DX 복기 (거래대금·재료)
- **추적 목적**: 단순 과거 회고 X → 상승 종목의 **공통 특징·흐름** 파악(과거≠미래 100%지만 패턴 반복 多).
- **얻는 데이터(9종)**: 장대양봉 평균 거래대금 / 적정거래대금 / 기준봉 패턴 구간 / 1→2차 파동 거래대금 변화 / 재부각 재상승 거래대금 / 꾸준 상승 재료 / 고점 돌파 시 거래대금 증가 이유 / 관심 재료·테마 / 단타~스윙 포지션 복기.
- **포스코DX 복기**:
  - 일봉: 네모/동그라미 구간부터 **강한 수급 유입 → 상승 시작**. 그 지점 거래대금 기준, 비슷/더 큰 거래대금 붙은 캔들 집중 추적.
  - 데이터 표: 일자/주가등락률/고가등락률/거래대금/종가/재료. **8,640원(23-03-28)→44,400원(23-08-25)**.
  - **종가등락률 vs 고가등락률** 관계 → 당일 단타 vs 데이트레이딩~스윙 가능 여부 판단.
  - **재료 연속성**: 테마 타고 **동일 뉴스 주기적 반복** 多 → 관심 재료 파악 + '꾸준히 오르는 종목엔 재료가 주기적 발생'(재료 연속성·모멘텀).

## G551. Part 01 주가 흐름 추적 ③ — 매매 가능 구간(적정거래대금·기준봉·파동)
- **데이터①(적정거래대금)**: 장대양봉 시 거래대금 = **'상승에 필요한 최소한의 거래대금' = 적정거래대금**. 포스코DX = **최소 4850억**.
- **데이터②(장중 예측)**: **오전 9~10시 거래대금으로 종가 거래대금 예측** → 종가까지 4850억↑ 예상 시 단타~데이트레이딩(예: **10시 전 2000~2500억**). ※G541(지니너스) '오전×배수≈종가' 재확인.
- **데이터③(기준봉/고점횡보)**: 스윙 구간 = 기준봉 중심·시가·고점 횡보 패턴. 기준봉 출현/조정/재슈팅 거래대금을 보며 매매 가능 구간 체크.
- **데이터④(1~2~3차 파동)**: 1→2차=하락 후 재부각, 2→3차=눌림 후 추가 상승. **파동 시작 공통점 = 적정거래대금 발생 + 꾸준한 수급 유입**. ※G498·G501 재확인.
- **결론**: 정리된 자료를 눈으로 보는 것보다 **직접 역추적**이 가장 효율적 공부.


## G552. Part 02 엑셀 자료 활용 방법 — 스키마·입력규칙·수집절차
- **폰트**: 에스코어 드림(SCDream1~9) 설치 후 파일 열기(파일 연 채로 설치하면 미적용).
- **★엑셀 컬럼 스키마(6열)**: 일자 / 주가 등락률 / 고가 등락률 / **거래대금(억)** / **종가 가격(원)** / 재료(뉴스&공시). 수치값만 입력 → 단위 자동(등락률 소수점 2자리, 거래대금 OOOO→억, 종가 OOOO→원). **장대음봉 날만 파란 네모박스**(선택).
- **★데이터 원칙**: **타인 자료 보고 옮겨적기 금지** → 네이버/구글 직접 검색 + HTS/MTS로 직접 차트 확인. 종목 추가 = 시트 우클릭 **이동/복사(복사본 만들기)**.
- **★자료 입력·추적 순서**: ① **의미있는 수급+장대양봉 날 먼저** 찾기 → ② 그 날 등락률·거래대금 입력, 재료는 **네이버 뉴스 날짜 변경 후 검색** → ③ 차트에서 네모/동그라미 구간부터 상승 시작 확인 + **처음 거래대금보다 큰 거래대금으로 증가** 확인 → ④ 의미있는 구간부터 **역으로** 추적하며 관점 형성.

## G553. Part 03 엑셀&PPT 활용 + ★개인 매매 원칙 3가지
- **엑셀&PPT 활용**: PPT엔 중요 정보 없음(레이아웃만) → 독자가 역추적 정리하면 의미있는 자료집 완성. 정답 없음, 본인 기준으로 순서·규격 설정.
- **PPT 노트 구조**: 표지(**개인 매매 원칙 3가지**) → INDEX(종목/날짜) → 종목별 노트(종목명·특징날짜[없으면 장대양봉 날]·차트에서 알게 된 내용 요약·차트 이미지).
- **★★개인 매매 원칙 3가지(SOMs)**:
  1. **재료가 발생한 종목으로만 매매** (투자자 관심 재료가 무엇인지 파악 노력).
  2. **거래대금 200억 이상 발생한 종목으로만 매매** (상승엔 수급 필수).
  3. **손실 복구용 당일 뇌동매매 금지** (손실은 천천히, 여유 있게 접근해야 수익).
- ※원칙②의 '200억'은 자료집 제시 **보편 최소 하한**(매매 대상 진입 스크리닝 기준) ↔ 종목별 동적 적정거래대금(G462/CP-03)과 구분해 **이중 필터**로 활용 가능.
