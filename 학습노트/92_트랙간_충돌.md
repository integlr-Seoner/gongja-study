# ⚔️ 트랙 간 충돌·불일치 기록

> **목적**: 같은 개념·수치·규칙이 **트랙(또는 권)마다 다르게 기술**될 때 그 차이를 기록. 어느 쪽이 최신/우선인지 저자 근거로 판정하되, 판정 불가 시 "미해결"로 남긴다.
> **기입 형식**: 각 항목 = `## C##. <쟁점>` + [트랙A 기술 ←G] / [트랙B 기술 ←G] / [판정 or 미해결].
> **주의**: 단순 심화(같은 논지의 상세화)는 충돌 아님 — **실제 상충**만 기록. G번호는 실제 수록 헤더([[g-note-reference-precision]]).

---

## C01. "적정 거래대금"의 통계적 정의 — 분위수 vs 상승일 중심값
- **[재료 트랙 44차 자료집 기술]** 적정 거래대금 α = 재료일 거래대금의 **40분위(하단)**, 실측 α≈0.32 ←G943·G1018
- **[차트 트랙 주가추적노트 기술]** 적정 거래대금 = "큰 폭 상승할 때 발생한 거래대금의 **대표값(≈중심 경향)**", 포스코DX 4,850억 = 상승일 중심값 ←G1170·G1182
- **[판정 — ★부분 해소(스윙 2권 G4820)]** 스윙 2권 소제목⑮서 저자 **원본 정의 확정 = "주가가 상승하기 위해 발생해야 하는 최소한의 거래대금"(하한 임계)** ←G4820. → **44차 자료집 α(40분위 "하단" G943)의 하한 성격과 일치**(둘 다 최소 임계). G1182 "상승일 중심값"은 저자 원본과 미묘히 다른 나의 관측 서술이었음 → 원본은 "최소 상승 임계"가 정답. **잔여 미해결**: 44차 α의 정확한 분위수(0.32)와 "최소 임계"의 수치적 대응은 여전히 종목별 눈대중(수치 정의 불가, 저자 명시). 아세아텍=300억 미만, 초과 시 20~30%+ 상승. (개념카드 [[91_개념인덱스]] 「적정 거래대금」 [정의]·[정량화] 확정)

## C02. 시간프레임 경계 — 단타↔스윙↔중장기 "합리화 도피" 금지
- **[단타 트랙 기술]** 단타 진입은 단타 규칙(-3%대 손절, 당일/데이트레이딩)으로 청산. 시간프레임은 진입 시 확정.
- **[스윙 트랙 기술]** 스윙 = 일봉 파동 매매(별도 진입 자리·기준) ←G4747·G4751. 저자 명시 경계: **단타로 산 종목을 손절 못 해 "스윙 관점으로 보겠다"→"중장기로 보겠다"로 시간프레임을 하향 도피하는 것은 비자발적 물림**(원칙 부재의 전형) ←G4752
- **[판정 — 충돌 아님, 경계 규칙]** 트랙 간 모순이 아니라 **저자가 명시적으로 금지한 교차 오용**. 각 트랙의 진입은 그 트랙의 손절로 닫아야 하며, 손절 회피를 위한 사후 시간프레임 전환은 금지. → 개념카드 [[91_개념인덱스]] 「종가 관리」·「과거 수급」 [매매법]의 손절 규칙과 연결. (단타 5-3권 손절=기준봉 시가 / 스윙 손절 기준은 소제목⑫서 확정 후 양쪽 병기)

## C03. 낙폭과대(낙주) 매매 — 단타 vs 스윙, 핵심 명제 동일·시간축 상이
- **[단타 트랙 기술]** 낙주 단타 = **분봉/데이트레이딩, 종가 부근 변동성** 이용 ←G1799. 조건식 「낙주 단타 5분」 = `B and C or (D and E)`, 지표 C = **[1분] -2% 이하** ←G1800. 핵심 명제 = *"주가가 단기적으로 가파르게 하락한 종목은 반등할 확률이 높다"* ←G1799. ※5-2권 대주제20 「낙폭과대를 이용한 데이트레이딩 매매 이론」(35p)의 **1~10분 -6~-16% 급락 기준**은 사용자 제공(원본 미대조, 00_INDEX상 해당 자료집 정독 상태 확인 필요).
- **[스윙 트랙 기술]** 낙주 스윙(3권 챕터06) = **일봉, 장대음봉 -15%↓**(C<H*0.85 ←G4900), 단기 큰 폭 하락 후 **며칠~몇 주 기술적 반등** ←G4895. 매수=단기 바닥 확인 후, 목표=**장대음봉 중심선(1차)·시가(2차)** ←G4907. 계단식 하락(숏바디 음봉 연속)은 매매 불가·낙폭과대(장대음봉)만 매매 ←G4895~G4896.
- **[판정 — 충돌 아님, 시간축 차이(교차 오용 금지)]** ★**핵심 명제(단기 가파른 하락→반등 확률↑)는 양 트랙 동일**(G1799 ↔ G4895) = 개념 충돌 아님. 단 **시간축·진입 기준·손절·목표가가 완전히 상이**: 단타=분봉(1분 -2%)·종가 부근 변동성·데이트레이딩 청산 / 스윙=일봉 장대음봉(-15%)·단기 바닥 후 매수·중심선/시가 목표. → C02(시간프레임 교차 오용 금지)의 낙폭과대 실물: **단타 낙주로 산 것을 스윙 낙주로 넘기지 말 것**. 개념카드 [[91_개념인덱스]] 낙폭과대 [트랙별 차이] 반영(단타 S12/5-2권 vs 스윙 3권).
