# ⚠️ 오답지점 — 실증으로 정정된 판독·해석 오류

> **목적**: 정독 중 내가 내린 판독/추론이 **KRX·차트 실측으로 반증**된 지점을 기록해 재발 방지. 저자 원문의 오류가 아니라 **나의 해석 오류** 위주(원문 오타는 노트 본문에 1줄 기록).
> **기입 형식**: `## E##. <정정 대상>` + [내가 틀리게 본 것] / [실측 근거] / [교훈]. G번호·CASE번호 연결.
> **관련 메모리**: [[g-note-reference-precision]](인용 정밀도), [[rerender-budget-policy]](고배율 재렌더링 한도).

---

## E01. "구간 최고" ≠ 일봉 고가 (헤더 라벨 오독)
- **[틀린 판독]** 차트 헤더/축의 "구간 최고" 라벨 수치를 그 종목의 **일봉 고가**로 등치해 인용.
- **[실측 근거]** 구간 최고값은 표시 구간 내 최고이지 일봉 실제 고가가 아님 — 삼성제약 2,575 · 서남 7,930 · 강스템바이오텍 1,886 3종에서 "구간 최고" 라벨과 KRX 일봉 고가가 불일치 확인.
- **[교훈]** 차트 라벨의 "구간 최고/최저"는 **표시 윈도 종속값** → 일봉 OHLC로 등치 금지. 수치 인용 시 라벨의 정확한 의미를 먼저 확정.

## E02. 헤더 4값(시/고/저/종) 동일 = 데이터 아님, 커서 아티팩트
- **[틀린 판독]** 차트 상단 헤더의 O/H/L/C가 네 값 모두 동일하게 표시된 것을 "쩜상한가/도지" 등 실제 캔들로 해석하려 함.
- **[실측 근거]** 대유플러스 205 · 씨씨에스 2,100에서 4값 동일 = **마우스 커서 위치의 크로스헤어 리드아웃**(빈 구간/커서 hover)이 만든 표시 아티팩트이지 실제 봉 데이터 아님.
- **[교훈]** 헤더 4값이 완전 동일하면 먼저 **커서 아티팩트 의심** → 실제 봉은 캔들 몸통/꼬리로 재확인. ([[rerender-budget-policy]]: 이런 판독은 고배율 재렌더링 대상 아님, [판독불가] 처리 가능)

## E03. whipsaw "리스크 예시" 종목이 실측은 상한가 마감
- **[틀린 판독]** 저자가 whipsaw(속임수 등락) **리스크 사례**로 든 종목을 "손절/실패 흐름"으로 해석.
- **[실측 근거]** 해당 예시 종목 5건 전부(CASE-0006·0007·0008·0009·0010) KRX 실측은 **당일 상한가 마감** — 저자의 예시는 "장중 whipsaw는 있었으나 결과는 상승"이라는 맥락이었음.
- **[교훈]** 저자의 "리스크 예시"를 결과 실패로 단정 금지 — **장중 변동성 경고 ≠ 종가 실패**. 예시 종목은 실측 종가까지 확인 후 해석.

## E04. 조건검색식 수치 오독 — 숫자+한글 붙여쓰기 시 "이/억"의 ㅇ을 0으로 오인 (근본 원인)
- **[틀린 판독]** G4844 조건식(기준봉 바닥 매매)의 리스트 표시만 보고 **F 이평 "200/600/1200/2400"**, **E 평균거래대금 "100000이상"→1,000억**으로 판독하고 "9x 재렌더링 확정"이라 단언.
- **[근본 원인 — 사용자 진단]** ★**숫자와 한글이 띄어쓰기 없이 붙은 경우, 뒤 한글의 첫 자음 ㅇ(이상/이하/이평/억 등)을 숫자 0으로 오인**한다. 그래서 "20이평"→"200이평"(이평의 ㅇ=0), "10000이상"→"100000이상"(이상의 ㅇ=0)처럼 값이 10배씩 부풀려진다. 리스트 표시는 이 착시 때문에 실입력값보다 한 자리 크게 보인다.
- **[최종 정정 근거 = 입력 필드]** p.065 조건 **입력 필드**(리스트 아님)로 확정: **F = 종가 > 20 > 60 > 120 > 240** / **E = 10000(백만) = 100억** (상한 999999999). [B] 40일이평매매(p.023)도 입력필드 10000=100억, 저자 프로즈 "100억"으로 일치. ★★판독 3자 대조: CC 원판독 1,000억 / 사용자 정정 10억 / **입력필드 100억(정답)** — CC도 사용자도 자릿수에서 빗나갔고 **입력 필드가 최종 근거**였다.
- **[교훈]** ①**리스트 표시로 조건식 수치 확정 금지** — 반드시 **입력 필드**(숫자 박스, 한글과 분리됨) 또는 **저자 프로즈(억 단위)**로 교차 확인. ②고배율 재렌더링도 자릿수 오독을 못 막는다([[rerender-budget-policy]] 보완) → "확정" 단언 금지. ③숫자+한글 붙여쓰기(N이상/N이평/N억/N원)는 이 오류의 상습 지점. ④값이 도메인 상식과 어긋나면(2400일 이평) 오독 신호. ([[g-note-reference-precision]])
