## G67. Vision Analysis 15차 (p.131~140) — Ch 07 게임 테마 공략 본론 + 사례1 데브시스터즈(쿠키런 킹덤)

> ※ 정독 방식 주: 이미지(vision) 채널 장애 지속 → 동일 페이지 JPEG를 Windows 내장 OCR(ko 엔진)로 텍스트 추출 정독. 본문 프로즈 고정확, 차트 축/수치는 부분 인식(보조 참고).

### G67.1 사전 예약자 기준의 유연성 (p.131) ⭐⭐⭐⭐⭐
- 사전 예약자 50만 명이어도 상한가 기록 / 거래량 터지며 장대양봉 출현 → 예약자 수는 적어도 **뉴스·재료 크기는 상대적으로 크다**고 보고 매매 가능
- **절대적 기준 없음** → 그때그때 상황 판단
- 100만 명 = 베이스(기준선), 그 위에서 **시장 분위기 + 종목 수급 집중 모니터링**
- → G66 "100만 명 = 필자 참고 기준"의 보충: 베이스라인이지 절대선이 아님

### G67.2 게임 테마 공략법 2번째: 출시 후 흥행 매매 (p.131~132) ⭐⭐⭐⭐⭐
[일정 재료 → 모멘텀 재료 전환 구조]
- 출시 전: 출시 기대감 + 사전 예약자 증가 뉴스 = **일정 있는 재료** → 게임 출시일까지 매매
- 출시일 도달 = 첫 번째 접근의 '게임 출시일' 재료 소멸
- **일정 있는 재료의 핵심 개념: 일정 당일은 보통 주가 하락 가능성 높음** ⭐⭐⭐⭐⭐
  (G56 "재료 소멸 시점 -10~-20%/일"과 동일 원리)
- 일정 다가오는 동안 기대감 반영 → 상승 → 일정 당일 하락 가능성 → **일부 물량 수익 실현 + 다시 매매 계획**

[출시 후 흥행 체크 + 모멘텀 매매]
- 출시 후 체크: PC/모바일 게임이 얼마나 인기/흥행했는지
- 구글 플레이스토어 / 애플 앱스토어 다운로드 횟수·매출 순위 1위 → 한 번 더 상승 가능
- 이때부터 일정 재료 아님 → 차트 보며 매도 기준 판단
- 출시 후 매매 = **모멘텀 있는 재료 관점**: 흥행 뉴스 보도 시 출현 장대양봉 = **기준봉**
  → 기준봉 시가~종가 사이 매수 → 시장 분위기·심리 보며 **분할 매도**로 마무리
  (G56 기준봉 패턴 1/2 개념을 게임 출시 흥행에 적용)

### G67.3 게임 테마 사례 학습 원칙 (p.133, 136~137) ⭐⭐⭐⭐⭐
- 게임 출시 재료 = **매년 발생 가능** → 한 번만 잘 공부해두면 반복 활용 가능
- 게임 테마 재료 ≠ '1+1=2'처럼 정답 100% 정해진 것 → 흐름에 무게 두고 공부
- **정답을 정해두거나 규칙을 정해서 매매하면 큰 리스크 노출** (뉴스 크기·지수 상황·투자 심리에 따라 모두 달라짐)
- → 항상 변수가 나타날 수 있다고 가정하며 접근
- 게임 테마 뉴스 = 특징주 뉴스로도, 일반 뉴스로도 보도됨 → 본인이 특정 게임을 재료로 본다면 관련 뉴스 직접 검색해 참고


### G67.4 사례1: 데브시스터즈 쿠키런 킹덤 - 출시 전 (일정 재료) (p.136~138) ⭐⭐⭐⭐⭐

## G70. Vision Analysis 18차 (p.161~170) — 자발적 보유 정의 + 사례3 룽투코리아(열혈강호) 악재 대응

### G70.1 자발적 보유의 정의 + 통계 확률 매매 (p.161) ⭐⭐⭐⭐⭐
[자발적 vs 비자발적 보유]
- 비자발적 보유 = 손절 못해 어쩔 수 없이 보유 (근거 없음)
- **자발적 보유 = 매수에 대한 근거 + 보유할 분명한 이유가 있는 보유** (= 일정 재료의 일정까지 상승 확률)
