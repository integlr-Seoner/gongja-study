# 과거수급을이용한데이트레이딩매매이론

- 필자는최소 200 ~ 300 억이상의거래대금이발생한종목들로만단타 ~ 데이트레이딩, 스윙관점으로매매합니다. 평소에는 500 억 ~ 1000 억, 록은그보다큰거래대금이발생한종목으로매매하며매매할종목이없을때는 200 억 ~ 300 억정도의거래대금이발생한종목으로매매한다는의미입니다.
(200 억 ~ 300 억정도의거래대금이발생한종목으로만매매한다는의미가아닙니다.)

- 필자는특정종목에 ' 눈에띄는수급이유입되면서주가가가파르게상승 ' 하면해당종목은이루에 ' 높은확률로 2 차상승흐름이나타난다.' 라고판단합니다. 그런데주식시장에서매매를하다보면 ' 눈에띄는수급이유입되면서주가가가파르게상승한뒤 2 차상승흐름이나타나는종목 ' 도있고,
- 눈에띄는수급이유입되면서주가가가파르게상승했지만한참동안조정받나가상승하거나아예상승하지못한채죽어버리는종목 ' 도있습니다.

- 이때필자가 ' 지금매수하는종목이 2 차상승흐름을기대할수있는종목인가?' 를판단할수있는기준은 ' 매매하려고하는종목의주가가상승할때재료가발생했는지, 어떤재료가발생했는지 ' 를살펴보는것입니다.

- 주식시장에서매매를하고있는다수의투자자들이관심을가질수있는재료가발생하면주가가잠깐동안조정받는흐름이나타나더라도시간이지난뒤에높은확률로 2 차상승흐름이나타납니다. 이때문에재료를분석하여매매하려고하는종목의주가가추가적으로상승할가능성이있는지를판단해보는것입니다.

즉, '2 차상승흐름이나다나지않은채바로죽어버리는종목 ' 을최대한피한채로매매하기위해서재료를분석하여매매한다는의미입니다.

## 뉴스는특징주뉴스만?
- 주식시장에서투자자들이뉴스와공시를통해발생하는재료를제크할때자주활용하는키워드는 ' 특징주 ' 입니다.

- 그런데우리가매매를하다보면간록특징주뉴스가보도되지않았는데주가가가파르게상승하는종목을발견하게될때도있습니다. 이런경우에는우리가직접네이버검색을통해관련된내용을찾아보거나 ' 종합시황뉴스에서특징주를지운뒤종목에관련된뉴스 ' 가있는지찾아봐야합니다.

2. 처음기준봉이출현했을때는단타 ~ 데이트레이딩관점으로매매하며그이후부터는스윙관점으로매매합니다.
- 필자가 ' 주가가고점까지상승한종목 ' 을스윙관점으로매매하는이유는 ' 주가가어느정도상승한뒤부터는이론적으로설명되지않는흐름이자주나타나기때문 ' 입니다.

- 주가가고점까지상승한종목들은주가가언제든추가적으로상승할수있는구간이기도하지만동시에 ' 언제든하락할수도있는구간 ' 이기도합니다.
이때문에그리스크를최소화하기위해스윙관점으로매매하는것입니다. ' 주가가고점까지상승했을때도매매를할수있는것아닌가요?' 라고질문해주시는분들이계실것같다고판단되어위와같은개인적인매매성향을말씀드린것입니다.

- 필자는재료가발생하면서주가가가파르게상승하는종목이나타나면단기적인관점으로수익을내고, 그이루부터는 ' 재료의모멘팀이지속되고있다는가정 ' 하에주가가하락했을때 ' 기준봉의중심 ~ 시가패턴을활용하여스윙관점으로매매 ' 합니다.
