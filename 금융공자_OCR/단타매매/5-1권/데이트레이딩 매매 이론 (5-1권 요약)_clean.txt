# 데이트레이딩매매이론

' 데이트레이딩매매이론 ' 요약집에서는데이트레이딩관점으로매매하는방법을공부하기전에 ' 기본적으로알고있어야하는내용 ' 을요약정리해드릴것입니다.

특정매매법이나흐름에집중해서매매할경우 ' 기본적으로체크해야하는것들을무시한채 ' 매매를하게될수도있기때문에 ' 우리가단기적인관점에서매매를할때꼭체크해야하는기본적인내용 ' 부터설명드리려고합니다.

단타나데이트레이딩을포함하여어떤포지션으로매매하든우리가수익을내기위해서는 ' 내가관심을가지고있는종목이아니라다수의투사자들이관심을가지고있는종목 ' 으로매매를해야합니다.

내가아무리좋은종목이라고생각해도다수의투자자들이관심을가지고매수하지않으면주가가상승하지않기때문에단기적인관점으로매매를해도수익을내기가어렵습니다.

우리가 ' 다수의투자자들이관심을가지고있는종목 ' 으로매매하기위해서는 ' 투자자들이관심을가지고있는재료 ' 를분석할수있어야하고,

' 언제든투자자들의기대감이반영되면서언제든주가가상승할수있는차트흐름 ' 이어떤것인지를이해하고, 이두가지조건이만족된종목으로매매를해야합니다.

# 준비된데이트레이딩매매란?

＊ 준비된데이트레이딩매매란?
준비된데이트레이딩매매는 ' 재료가발생하여투자자들에게관심을받고, 수급이유입된뒤 2 차적인상승흐름이나타날만한종목 ' 을골라둔다음기회가왔다고판단될때부터매수하여상승시에수익을내는매매법 ' 을의미하는것입니다.

주가가상승하는흐름에서중동적으로매수하지않고, 천천히횡보하는흐름이나타날때까지 ' 재료와차트흐름, 당일지수의흐름 ' 등을분석한뒤천천히매수하여 2 차상승흐름을기대해보는것입니다.

스캘핑매매, 단타매매는 ' 주가가큰폭으로변동하는흐름 ' 에서호가창과차트를빠르게분석한뒤매매타점을설정해야하지만데이트레이딩매매는
_ 변동성이작은시점에천천히매수하여당일이나며칠이내로추가적인상승흐름을기대하는매매 ' 라고생각해주시면됩니다. 또이것이필자가가장선호하는단기매매입니다.

그럼데이트레이딩매매관점에대한내용을설명드리기전에 ' 준비된데이트레이딩매매가무엇인지?' 를확인하실수있는몇가지예시를소개해드리겠습니다.

지금부터소개해드리는예시들은이미단타매매가이드북을통해서공부하셨던것들이기때문에 ' 차트의흐름 ' 과 ' 발생했던재료 ' 만나열해드릴것입니다. 필자가 ' 어떤재료를보고종목을선택했는지, 또어떤흐름에서부터분할로매수했는지 ' 에집중하면서예시를살펴보시기바랍니다.
( 독자분들이전체적인흐름을한눈에보실수있도록차트를확대시켜둔것이화질이조금깨지더라도양해부탁드립니다.)

# 이통평굴선을활용하는기준

- 이동평균선은 ' 타점을설정하는용도가아니라추세를판단하는용도 ' 로사용하는보조지표입니다.

- 필자는 ' 이동평균선이정배열된상태에서 5 일선위에있는종목만데이트레이딩관점으로매수 ' 하며 '10 일선을이탈하면스윙관점으로연결하거나손절을고민 ' 합니다.

- 필자가이동평균선을위와같은관점으로해석하는이유는 ' 이동평균선과주가의위치관계가투자자들의심리에영향을미칠가능성이높나.' 라고생각하기때문입니다. 더해서필자가위와같이생각하는이유는 ' 시장에서매매하는대부분의투자자들이차트를보면서매수타점과손절라인을설정하기때문 ' 입니다.

즉, 차트의흐름이망가져있으면투자자들이보수적인관점으로매매하려고할것이고, 차트의흐름이우상향하면서좋은모습을보여주고있다면투자자들도적극적으로매매하게될것이라는의미입니다. 이에필자는주가와이동평균선의관계에따라 ' 우리가종목을보유하게되는기간이달라질수도있다.' 라고말씀드립니다.

- 추가로 ' 이동평균선이정배열되어있고, 주가가 5 일 ~ 10 일이동평균선위에위치한종목 ' 들은주가가어디까지상승할지는알수없으나다수의투자자들이관심을가지고지켜보고있기때문에 ' 재료가있고, 큰거래대금이발생했다.' 라는것만확인된다면데이트레이딩관점으로매매할수있다고말씀드립니다.

# 손절라인을정해두고매수하기 & 포지션을설정하고매수하기
- 데이트레이딩매매는 " 수급의유입과주가가상승하는흐름을분석해서매매하는것 ' 이기때문에매수타점및손절라인은독자분들께서직접설정해주셔야하며 ' 특별한보조지표나가격을보고대응하는것이아니라전체적인흐름을보면서유동적으로대응 ' 해주셔야합니다.

예를들어 ' 수급이유입되기시작한것을보고매수했으면수급이유입되기시작한가격을이탈할때손절로대응 ' 해야하고, ' 주가가하락한뒤횡보하는흐름에서매수했다면그추세가깨질때손절로대응 ' 해야한다는의미입니다. 더해서만약 ' 수급이유입되기시작한가격을이탈했는데그가격아래까지버티면서스윙관점으로매매 ' 하려면처음매수를할때부터스윙포지션까지연결할생각을갖고, 비중을확실하게조절해주셔야합니다.

- 중요한것은 ' 수학적인공식과이론은존재하지않는다.' 라는것이며수학적인공식과이론이존재하지않기때문에 ' 흐름을보면서유동적으로대응해야한다.' 라는것입니다.
