# 겁상단타매매 (요약집)

갱단타매매요약집에서는갱단타에대한이론, 매매종목을고르는방법, 각매매법에대한디테일한내용, 또필자의실전매매사례등물정리해드릴것입니다.

단타매매가이드북에서는전체적인흐름을설명해드렸다면이번요약집에서는필자가정리해드린내용을세부적으로하나씩보기쉽게나열했다고생각해주시면됩니다. 추가로단타매매가이드북 4-2 권에서설명드리지않았던내용을몇가지추가했으며필자가전자책을마무리하던시점에독자분들이공부하시기좋다고판단되는사례가나와서그부분도급하게추가해두었습니다.

요약을목적으로제작하게된자료집인데작성하다보니분량이생각보다많아졌습니다. 다만, 그만큼보기쉽게정리해두었다고생각되니여러번반복적으로읽으면서공부를해보셨으면좋겠습니다.

전자책몇권 , 몇페이지만으로필자의모든경험을전달해드리기는어렵겠지만최대한많은경험을전달해드리기위해다양한관점의내용을담아두었습니다. 공부를하시면서궁금하신내용이있다면그부분도부담없이메시지를통해문의남겨주시기바랍니다.

# 상단타매매 (이론)

＊ 상단타매매의정의

- 상단타는기크게떠서출발한종목의흐름을지켜보다가매매할수있는기회가만들어졌을때단기관점으로매매하는방법입니다.

- 갱단타라는매매법은원래존재하지않으며딱히부를만한이름이없어서필자가임의적으로붙여둔명칭입니다. 독자분들이편하신대로바꿔서불러주셔도됩니다. ( 필자에게질문을해주실때만소통이될수있도록상단타라고언급해주세요.)

- ( 패턴으로정형화한) 갱단타매매는크게세가지로나눌수있습니다.

(1) 종가배팅 (보통 1 거래일내로손익결정)

(2) 시가배팅 (보통 1 거래일내로손익결정)

- 종가배팅과시가배팅은 ' 필자가주식시장의분위기와흐름을실시간으로모니더링할수없는날이많기때문 ' 에그런상황에맞춰서주가의흐름을지켜보다가매매할수있는방법을고민하다가만들어진매매법입니다.

- 종가배팅은보통 2 시 40 분 ~ 3 시 20 분사이에종목을매수하며매매환경이그와맞지않는분들은동시호가나시간외단일가거래시간을활용해주시면됩니다. 추가로시가배팅은다음날시초가 9 시에바로매수하는것이아니라시초흐름을살피면서필자가소개해드린패턴이나타났을때그것을확인하고매매하는것을의미합니다.

# 상단타매매 (이론)

(3) 데이트레이딩 ( 종목을보유하는기간이 2 거래일까지늘어날수도있는매매)

- 세번째로소개해드리는데이트레이딩매매의경우종목을보유하는기간이 2 거래일까지늘어날수도있습니다. 이에본인의투자금이묶이는게싫으시거나단기매매를선호하시는분들이라면매매를보류해주실것을권해드립니다. 매매를하다가 "다른종목의주가가상승하는모습 ' 을보고해당종목을매매하기위해손절라인이이탈되기도전에매도할경우손실 0| 발생할수도있습니다.

- 데이트레이딩매매는단타매매가이드북 5 권에서설명드리는내용을 ' 패턴으로정형화한매매법 ' 이며필자가개인적으로생각했을때매매확률이가장높다고판단되는한가지의데이트레이딩매매법만소개해드렸습니다.

다른관점의매매들은패턴으로정형화하기도어렵고, 패턴으로정형화하여설명드렸을경우오히려손실이발생할수도있다고판단되어 ' 단타매매가이드북 5 권에서부터자세하게설명 ' 드리려고합니다.

만약단타매매가이드북 4-2 권에서소개해드린데이트레이딩관점의매매가어렵게느껴지신다면억지로해당관점을활용해서매매하려고하시기보다종가배팅, 시가배팅관점으로매매를하시다가단타매매가이드북 5 권이후에설명드리는내용까지공부하신후매매에활용해보시기바랍니다.

# 상단타매매 (이론)

＊ 상단타패턴을활용하여매매하는이유 ( 필자가개크게종목을단기관점으로매매하려는이유)

- 기큰폭으로떠서상승출발했다는것은다수의투자자들이관심을가질만한재료가발생했으며투자자들이그재료에많은관심을가지고있다는의미로해석해볼수있습니다. 만약투자자들이관심을가지지않았다면개 | 큰폭으로떠서상승출발하는흐름이나타나지도않았을것입니다.

- 개큰폭으로떠서상승출발한종목들은보통큰거래대금이발생하는경우가많고, 주가도큰폭으로상승하거나하락하기때문에단타관점으로매매할수있는기회도자주만들어집니다. 물론 20% ~ 25% 상의으로상승출발한뒤바로상한가에도달한종목들은 ' 거래된시간자체가너무짧기때문 ' 에작은거래대금이발생할수도있습니다.

- 주가가고점에서큰폭으로하락하지않은채횡보하거나우상향하면 ' 재료에대한투자자들의기대감이계속유지되고있다 .' 라고판단할수있기때문에주가가언제든지가파르게상승할수있다는생각을가지고매매를해볼수있습니다.

- 상단타종목은다수의투자자들이모니터링을하고있는종목이기때문에세력들이평소보다작은수급만유입시켜도 ' 신고가매매 ', ' 단기매매 ' 등과같은관점으로매매하는투자자들의후속매수세가강하게유입되면서주가가가파르게상승하는흐름이나타납니다.

- 필자는이러한이유들때문에기크게떠서출발한종목들중고점에서횡보하고있는종목들은따로관심종목에정리해두고모니터링을하면서기회가만들어질때마다단기관점으로매매를하고있습니다. (종가배팅, 시가배팅, 데이트레이딩 , 단타매매등) + 고점기준봉패턴매매 (스윙)

# 상단타매매 (이론)

- 필자가지금까지소개해드린종목들의차트흐름을살펴보시면 ' 주가가큰폭의으로상승출발한뒤고점에서하락하지않은채횡보하고있는모습 ' 이나타나고있다는것을확인하실수있습니다. 이런흐름이나타나고있는종목들이바로상단타관점으로매매를할수있는종목들입니다.

- 상단타관점으로매매할수있는종목들은 ' 매매할종목을찾은당일에매매하는것 ' 이아니라매매할종목을미리찾아두고 ' 그다음날부터의르름을시켜보다가원하는흐름이나타났을때매매 ' 하는것입니다.

- 필자가공유해드린조건검색기를활용하여매매할종목을찾으신다음주가가상승했던이유와함께관심종목에정리해두시고, 이후의흐름을시켜보다가우리가원하는흐름이나타났을때만매매한다는의미입니다. 여기서중요한포인트는 ' 주가가상승했던이유와함께관심종목에정리 ' 를해두셔야한다는것입니다.

- 필자는차트의흐름이아무리좋아도주가가상승할수있는근거인재료가소멸된다면주가가하락할확률이매우높기때문에매매를하지않으려고합니다. 물론차트의흐름이좋은경우에는차트매매투자자들의수급으로인해기술적으로반등할수도있지만그런확률에기대서매매하는것을선로하지는않기때문에재료가소멸된종목으로는매매를하지않으려고하는것입니다. ( 재료가소멸된종목의차트가좋아서기술적반등을기대하고매수했는데 -5% 씩 2 거래일연속하락한다면부담스러울정도로큰손실이발생하게되는것입니다.

이에대한사례는뒤에서 ' 시가배팅 ' 예시주제에서관련된내용을자세하게설명드리겠습니다. ( 필자가전자책작업을마무리하던기간에좋은사례가하나발생하여기존사례를삭제하고, 다른사례를급하게추가편입하게되었습니다.)

# 상단타매매 (이론)

- 그럼이번에는강단다관점으로매매할수있는종목의기준을조금더자세하게설명드리겠습니다. 앞서필자는갱단타관점으로매매할수있는종목을 ' 개큰폭으로떠서상승출발하여양봉으로마감한종목 ' 미라고정의했습니다.

- 여기서랩이크게것의기준은 10% ~ 25% 정도의상승을의미합니다.

(다만, 필자가 10% ~ 25% 가고하여의기준을 100% 여기다가맞추실필요는없습니다. 재료에따라서혹은시장분위기에따라서 8% 의캡으로매매할수도있고, 25.1% 의개로매매를할수도있는것입니다. 해당기준은정답이아니라유동적으로바낄수있는기준입니다. 이메 10% ~ 25%
정도의상승이라고설명드린것입니다.)
