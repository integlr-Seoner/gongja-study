# 상한가단타매매 (요약집)
상한가단타매매요약집에서는상한가에도달한종목을 ' 패턴을활용하여매매하는두가지방법 ' 을소개해드릴것입니다. 단타매매가이드북에서설명드린내용이대부분이지만각각의내용을조금더보기쉽게정리해두었으며단타매매가이드북에서기본적인내용이라고판단되어설명드리지않았던내용들도몇가지추가해두었습니다.
상한가에도달한종목들은보통다음날큰변동성이나타나기때문에다양한방법으로매매를할수있지만필자는그중현재 ' 패턴을활용하여매매할수있는방법은두가지정도이며나머지는모두수급과주가의흐름을보고매매해야한다.' 라고말씀드립니다.
단타매매가이드북에서소개해드리는매매법은상한가에도달한종목을매매하는방법중에서가장확률이높은매매법이며이외나머지매매법들은모두단타매매가이드북 5 권이후에서부터설명드릴것입니다.
모든매매를패턴으로정형화시켜서설명드릴수있으면좋겠지만그런방식으로매매법을소개해드렸을때손실로이어질수있다고판단되어가장확률이높다고생각되는것들만패턴으로정형화시켜서소개해드리는것이니이외나머지매매법들은단타매매가이드북
5 권에서부터공부해주시고, 지금은확률이높다고설명드린부분에대해서만공부해주시기바랍니다.

# 상한가단타매매 (이론)

* 삼한가메도달한종목으로매매하는관점을따로설명드리는이유

- 필자가 ' 수급이유입된종목으로매매하는관점 ' 이라는주페에서해당내용을설명드리지않고,

' 상한가에도달한종목을매매하는관점 ' 미라는주제를따로나뉘서설명드리는이유는두가지입니다.

- 그중첫번패는 ' 상한가에도달한종목은해당종목에수급이유입되었다는것을명확하게확인할수있기때문 ' 입니다.

만약큰거래대금이발생하면서주가가가파르게상승했는데종가기준으로봤을때긴윗꼬리캔들이출현했거나혹은큰거래대금이발생하면서주가가가파르게상승했는데그상승흐름이장중에 2 ~ 3 번연속반복적으로나다났다면종가기준으로장대양봉이출현했다고해도 ' 당일에유입된수급이유지된채로추가매집이이루어진것인지, 아니면당일에유입된수급이당일에모두이탈한것인지를명확하게구분하기어려울때 ' 도있습니다.

(이와관련된차트는뒤에서보여드릴것입니다.)

- 하지만주가가상한가까지상승한흐름은 ' 누군가의도적으로큰수급을유입시키면서주가를상슴시킨것이기때문에해당종목에수급 0 유입된것이다.' 라는명확한해석과함께이후흐름에집중해서매매를해볼수있습니다.

주가가상한가까지상승하는흐름에서는기존에물려있던투자자들의본전매도물량, 손절물량이쏟아지고, 저점에서매수한투자자들의차익실현물량도중간중간쏟아집니다. 이런물량들이모두주가상승을방해하기때문에주가가상한가까지상승했다는것은누군가의도적으로 ' 그런매물들을전부소화할수있을만큼큰수급을유입시킨것이라고봐야합니다. 만약의도적으로큰수급을유입시키지않았다면주가가삼한가까지삼승하지못할것입니다.

보통일반적인종목들은개장직후 30 분 ~ 1 시간정도까지만강한수급이유입되기때문에그시간메만패턴을활용한매매를할수가있습니다. 하지만전날상한가메도달한종목들은예외적으로 ' 하루종일감한흐름이나타날수도있기때문에주가가손절라인만이탈하지않으면오후 ~ 종가부근메서도패턴을활용하여매매 ' 를할수있습니다.

물론대부분은 9 시 ~ 10 시사이에주가가가파르게상승하지만간혹 12 시, 2 시정도에상승하는경우도있기에위와같이설명드린것입니다.

# 상한가단타매매 (이론)

상한가에도달한종목들은다음날큰변동성이나타나고, 주가가움직이는모습도굉장히다양하기때문에여러가지관점으로매매를할수있습니다.
하지만필자는그런여러가지방법중에서이번에는두가지매매방법만소개해드릴것입니다. (그이유는필자의모든매매를패턴으로정형화하여설명해드릴수가없기때문입니다.)

- 주가가상한가에도달했다는것은 ' 특정집단이원하는목적을달성시키기위해 ' 주가를상승시키면서까지주식을대량으로매수했다는의미로해석해볼수있습니다. 여기서특정집단원하는목적은 ' 주가를원하는가격까지상슴시키는것, 록은보유하고있는물량을원하는가격에서매도하는것 '
등이라고할수있습니다.

필자는 ' 세력들이보유하고있던물량을개인투자자들에게넘기면서정리할때, 또원하는목적을달성하는과정에서나타나는흐름 ' 을이용하여단타매매를하고있습니다.

( 세력들이보유하고있던물량을개인투자자들에게넘기면서정리할때는보통큰거래대금이발생하면서주가가가파르게상승하는흐름이나타납니다.
세력들 0 주가가상승할것같은분위기를연출시키면그뒤로개인투자자들의후속매수세가유입되면서주가가가파르게상승하게되고, 세력들은그때부터개인투자자들에게물량을넘기면서정리하는것입니다. - 필자의해석관점입니다.)

# 상한가단타매매 (이론)
＊ 주가가상승하는이유 & 매매원리
- 특정집단이원하는목적을달성하기위해서주식을대량으로매수하면큰거래대금이발생하면서주가가가파르게상승합니다.
이렇게주식을매수하면서주가가가파르게상승했을때 " 세력들이매수했던물량을한번에시장가로매도 ' 하면주가가다시큰폭으로하락하기때문에이들은보유하고있는물량을시장가로정리할수가없습니다.
그럼이들이매수한주식은어떤방식으로정리해야할까요?
이들은다른투자집단의수급이대량으로유입될수있는분위기를만든다음 ' 그들에게물량을넘기는방식으로정리 ' 를해야합니다.
이러한이유때문에필자는특정집단의강한수급 | 유입된종목의주가는 "이루높은확률로추가적인상슴흐름이나다난다.' 라고말씀드립니다. 물론주가가언제, 어느가격까지상승할지는알수없습니다.
하지만주식을대량으로매수한특정집단이보유하고있는물량을수익권에정리하려면다른투자집단이유입될수있는분위기를만들기위해서 ' 한번이상은큰변동성을만들면서주가를상슴시켜야하기때문 ' 에우리는그특징을이용해서매매를해볼수있다는것입니다.

# 상한가단타매매 (종목선정)

* 종목선정조건

- 가장이상적인흐름 : 전날큰거래대금이발생하면서한번에상한가까지상승한뒤상한가가풀리지않은채로마감한종목매매하지않는상한가종목의기본적인조건

(1) 주가가삼승할때발생한재료가소멸되어캡으로하락출발한종목

> 재료는주가가상승할수있는근거입니다. 즉, 주가가상승할수있는근거가사라졌다면 ' 캡으로하락출발한뒤반등할확률보다추가적으로하락할확률이더높다.' 라는해석과함께매매를보류해주셔야합니다.

(2) (대장주 ~ 2 등주, 3 등주가모두상한가에도달했을때) 대장주가보합출발하여 2 ~ 3 등주가그로하락출발한종목

> 대장주의주가가보합에서출발한뒤하락하면당연히 2 ~ 3 등주의주가가전일상한가에도달했다고해도반등하지않은채하락할확률이높습니다.

# 상한가단타매매 (매매방법)

- 매도가 :

주가가 -5% 정도의으로하락출발했을경우에는전일상한가가격에서부터분할매도를시작해주시면됩니다. 만약 3% 미만의상승흐름에서부터매수를시작하셨거나음봉시가돌파흐름에서부터매수를하셨다면 2 ~ 4% 정도의수익구간에서부터 1 차매도를하실수있을것입니다.

다만, 주가가항상전일상한가가격까지반등하는것은아니기때문에흐름을보면서유동적으로대응을해주셔야합니다. 주가가전일상한가가격을터치했다가하락하거나터치하지못한채하락할수도있기때문에그런흐름이나타나면빠르게시장가로매도를해주셔야합니다.

또흐름을지켜보다가강한수급이유입되면서상한가를돌파할것같은흐름이나타나면 ' 전일상한가부근에서일부를매도 ' 하고큰수익을기대해볼수도있지만상한가부근까지가파르게상승했다가그부근에서상승이꺼는듯한흐름이나타나면빠르게정리를해주셔야합니다.

추가로주가가 -10% ~ -15% 이상의개로하락출발했을경우에는전일상한가가격까지의거리가 10% 이상이기때문에이때는 2 ~ 5% 사이의수익권에서부터조금씩수익을챙겨주셔야합니다.

10% 이상의큰수익을기대하시는것도좋지만주가가원하는가격에도달하지못한채다시하락할수도있기때문에큰폭의으로하락했을경우에는어느정도수익을챙기면서대응해주시는게좋습니다.

## 주가가종가까지평균단가대비 -1% ~ 3% 사이에서횡보할때

매수를시작한당일종가대비 -3% 를손절라인으로설정한뒤 ' 다음날오전 10 시정도 ' 까지흐름을지켜보다가주가가상승할때본전 ~ 약수익구간에서부터천천히매도를해주시면됩니다. 주가가가파르게상승하여바로수익이발생하면수익으로매도를해주시면되고, 주가가천천히상승한다면본전 ~ 약수익구간에서전부매도하고매매를마무리해주시면됩니다.

다만, 주가가전일종가대비 -3% 이상하락한다면그때는과감하게손절로정리하고매매를마무리해주셔야합니다.
