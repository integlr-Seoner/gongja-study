# 음봉시가돌파패턴매매 (요약집)

음봉시가돌파패턴매매요약집은필자가단타매매가이드북에서설명드린내용을보기쉽게정리하면서동시에 ' 부족하다고생각되는내용들을조금더추가 ' 해둔자료집입니다.

음봉시가돌파패턴매매는이미많은분들이잘알고있는매매중하나이지만필자가소개해드리는관점의매매를처음공부하시는분들도어느정도계실것이라판단되어관련된내용을최대한자세하게정리해두었습니다. 이미공부하신내용이라면복습한다는마음으로가법게읽어주시고, 처음공부하시는분들이라면여러번읽으면서눈에익혀주시기바랍니다.

이번요약자료집을공부하신다음예시자료집까지공부해보시면음봉시가돌파패턴매매에대한기본적인이론과매매방법은어느정도정리가될것이라생각합니다. 공부를하시면서궁금하신점이있다면언제든편하게문의를남겨주시기바랍니다.

※ 으로하락출발한종목을음봉시가돌파패턴관점으로매매하는방법은 "상한가단타주제 ' 에서더자세하게설명드릴예정이니그부분까지공부하신뒤매매에활용해주시면됩니다.

# 음봉시가돌파패턴매매 (이론)

＊ 음봉시가돌파패턴매매의정의

- 시초가에매물이쏟아지면서주가가하락했는데이후그매물이소화되면서주가가다시상승할때나타나는패턴을활용한단타매매법입니다.

- 음봉시가돌파패턴매매는이미시장에널리알려진시초가단타매매법중하나이기때문에단타매매에대한이론을공부해보신분들이라면음봉시가돌파패턴매매법에대한내용도공부해보셨을가능성이높습니다.

- 필자도과거부터지금까지시초가에매매할수있는기회가보일때마다음봉시가돌파패턴을활용하여단타매매를하고있습니다.

다만, 과거에는차트만을분석해서단타매매를했다면현재는차트와호가창을함께분석하여매매를하고있습니다.

- 음봉시가돌파패턴매매법에대한내용을설명해주시는투자자분들마다이론적인내용, 타점을설정하는방법, 손절라인을설정하는방법등이모두다르기때문에필자가소개해드리는내용을공부해보신후도움이될것같다고판단되는내용이있다면독자분들의매매에활용해보시기바랍니다.

* 음봉시가돌파패턴을활용하여매매하는이유

- 주식시장이개장한직후 ' 실망매물, 손절물량, 차익실현물량등 ' 이쏟아지면서주가가하락했는데누군가큰거래대금을발생시키면서그물량을소화했고, 주가를다시상승시켰다면 ' ㅅ | 초에쏟아지는악성매물을소화한투자집단 0 주가를추가적으로상슴시킬목적을가지고있다 .' 라는해석과함께매매를해볼수있습니다.

- 특정투자집단이시초에쏟아지는악성매물을소화했다는것은개장직후해당종목의주가가하락하는흐름에서 ' 주식을대량으로매수했다 .' 라는의미라고해석해볼수있습니다. 또이들이주식을매수한이유는 ' 주가를상슴시겨서기존에주식을매수한가격보다더높은가격에매도하기위한것이다 .' 라고해석을해볼수있습니다.

즉 , 특정투자집단이주가를추가적으로상승시킨뒤차의실현을할목적으로 ' 시초에쏟아지는매물을소화했다 ' 라는판단과함께매매를해볼수있다는의미입니다.

- 더해서음봉시가돌파패턴매매는이미많은투자자들에게알려진매매법중하나이기때문에 ' 투자자들의수급이대부분비슷한가격에서유입 ' 됩니다.
즉 , 타점이라고판단되는구간에서부터는다수투자자들의수급이동시에유입되기때문에주가가상승할때그탄력이굉장히강하다고볼수있습니다.
이에시초가부터음봉시가돌파패턴이나타나면해당패턴을활용하여단타매매를해볼수있다고설명드린것입니다.

(다만, 다수투자자들의매수타점이비슷한것처럼손절라인도비숫하기때문에빠르게대응하지않으면큰손실발생할수도있습니다.)

＊ 음봉시가돌파패턴이차트에나타나는원리 ( 암기보다는이해하는것이중요)

- 음봉시가돌파패턴은차트위에서여러가지모습으로표현됩니다. 단순하게음봉캔들하나, 양봉캔들하나가출현하면 ' 이것이음봉시가돌파패턴이구나. 이때매수하면되겠다 .' 라는해석과함께매매를할수있겠지만주가의흐름은우리가원하는방향으로흘러가지않는경우가더많습니다.
- 매매를하시다보면우리가공부한것과비슷해보이지만조금씩다른흐름도자주보시게될것이고, 완전히응용된모습이라서 ' 이론을적용해보면음봉시가돌파패턴매매 ' 에서공부했던내용인데캔들모양은망치형으로만표현된경우도있을것입니다. (0| 부분은뒤에서설명드릴것입니다.)

주식시장에서종목들의주가가움직이는흐름은하나씩나열하기어려울정도로그경우의수가너무많습니다. 이때문에차트에서 ' 불규칙적인흐름이론적으로공부하지않은흐름, 필자가소개해드리지않은흐름 ' 이나타나도 ' 해당흐름이음봉시가돌파패턴이다 .' 라는것을파악한뒤매매를할수있으려면패턴을암기하려고하시기보다원리자체를이해 ' 하려고해주셔야합니다.

- 당연히처음에는공부한내용들이익숙하지않기때문에공부했던패턴이나타난것만보고매매를해야합니다. 하지만어느정도매매가익숙해지고주가의흐름이눈에보이기시작할때부터는 ' 패턴보다는주가의전체적인흐름 ' 을보고매매할수있도록노력해주셔야합니다.

주가의전체적인흐름을보고매매할수있게되면 ' 음봉시가돌파패턴이다른모습으로응용돼서표현 ' 되어도 "이게음봉시가돌파패턴이구나 ' 라는것을알수있습니다. 그럼관련된내용을그림과함께한번더설명해드리겠습니다.

# 음봉시가돌파패턴매매 (이론)
＊ 음봉시가돌파패턴이차트에나타나는흐름 ( 암기보다는이하하는것이중요)

# 음봉시가돌파패턴매매 (종목선정)

＊ 종목선정지금까지설명드린내용은필자가음봉시가돌파패턴관점으로매매할때종목을정리하는방법입니다. 지금부터는랩으로상승출발한종목을매매할때어떤종목를주로모니터링하는지, 또캡으로하락출발한종목을매매할때주로어떤종목을모니더링하는지에대해설명드릴것입니다.

각매매법마다선호하는주가의흐름이있기때문에쉽게이해하실수있도록정리해드리겠습니다.

(1) 주가가갤으로상승출발하는흐름에서음봉시가돌파패턴을활용하여매매할때

- 주가가개로상승출발하는흐름에서음봉시가돌파패턴매매를할때는랩의크기를보고매매할종목을선정합니다.

- 보통은 5% ~ 15% 정도의갱으로상승출발하는종목으로매매하며마음에드는종목이없다면 3 ~ 4% 의개로출발한종목도매매합니다. (1 순위)
- 간혹 16% ~ 이상의캡으로상승출발하는종목도있는데해당종목은원만하면매매를안하려고하는편입니다. (후순위)

16% 이상의갤으로상승출발하는종목들은주가변동성이너무크고, 잼미후하루종일하릭하는종목이많아서매매를피하는편입니다. 또개인적으로이런흐름이나타난종목들은리스크가크다고생각하기때문에매매를해도소액으로접근하거나 : 삼한가금깨료가발생했다고판단 ' 될때만매매하려고합니다.

추후상따관점의매매법을설명해드릴때관련된내용를한번더정리해드리겠습니다.

# 음봉시가돌파패턴매매 (매매방법)

※ 음봉시가돌파패턴을활용한매매법 - 매매시간필자는보통음봉시가돌파관점을활용한매매를오전 10 시정도까지하는편입니다.

매매를하다보면간혹음봉시가돌파관점이아닌다른관점으로매매를하고있는데다른종목에서 "음봉시가돌파관점 ' 으로매매할수있는종목이나타날때도있고, 매매할종목이너무없어서계속관심종목을돌려보고있는데 9 시 40 분쯤 ' 음봉시가돌파관점 ' 으로매매할수있는종목이나타날때도있습니다.

다만, 해당관점의매매는기본적으로비슷한패턴을활용하여매매하는투자자들의수급이동시에유입되어야우리가원하는상승흐름이나타날수있기때문에오전 10 시정도까지만매매해주시는게좋습니다.

물론찜상한가, 하한가, 신규상장주등과같이 " 주가가언제든가파르게상승할수있는종목 ' 들은시간과관계없이 11 시 ~ 12 시정도에도음봉시가돌파패턴이확인된다면매매를해볼수있습니다. ( 툴론시간이너무오래지나면형성된캔들의개수가많아져서음봉시가돌파패턴이아니라주가의흐름을보고시가를톨파할때매매를해야할것입니다.
