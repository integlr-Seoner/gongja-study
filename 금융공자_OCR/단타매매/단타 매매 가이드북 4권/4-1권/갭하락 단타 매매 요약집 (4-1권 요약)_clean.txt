# 개락단타매매 ( 요약집 )

개락단타매매요약집에서는하락단타매매를할때기본적으로기억하고있어야하는이론적인내용, 각흐름별매매방법 ( 타점, 손절,
매도기준 ), 매매할때주의해야하는사항, 독자분들이공부를하실때궁금해하실만한내용등을깔끔하게요약정리했습니다.

개락단타매매와관련된전체적인내용을빠르게복습하면서공부하실수있도록제작한자료집입니다. 단타매매가이드북에서는이론적인내용에만집중했기때문에정리된느낌을받지못하셨을수도있습니다.

요약집에서는독자분들이관련된내용을한눈에보고쉽게공부하실수있도록정리해두었으니여러번읽어보시면서관련된내용을공부해주시기바랍니다. 필자가소개해드린예시자료집을공부하시기전에해당요약집을읽으신다면조금더효뮬적으로공부를하실수있을것입니다.

또관련된내용을정리하면서 ' 단타매매가이드북에서설명이부족했다고판단되는내용 ' 도몇가지추가하여자세하게정리해두었으니그부분도참고해주시기바랍니다.

1-3. 만약특정테마주의주가가전부그로하락출발하면보통다음과같은흐름이나타나게됩니다.

1 등주 : -5% 정도의그로하락출발
2 등주 : -79% ~ -10% 정도의으로하락출발
3 등주 : -109% ~ 15% 정도의개로하락출발만약테마주에편입된종목들의주가가전부개로하락출발하면이때는독자분들이개별적으로매매할종목을선택해주시면됩니다. 일반적인상황에서는대장주를매매하는것이더좋다고볼수있지만 2 ~ 3 등주의주가하락폭이클경우 2 ~ 3 등주를매매하는것도좋은방법이될수있습니다.

여기서필자가설명드리고싶은것은 2 ~ 3 등주가 -10% 이상의그로하락출발했고, 1 등주가 -10% 보다높은가격에서하락출발했다고하여 1 등주를매매하지못하는것은아니라는것입니다. 이런상황에서는독자분들이어떤종목을매매하실지그흐름을보면서결정해주시면됩니다.

비중을크게실어서매매하시는분들은호가창의두께나평소큰거래대금이발생했던종목을우선순위로생각해주시면되고, 투자금을작게매수하시는분들은주가변동성이큰종목이나시가총액이작은종목을우선순위로생각해주시면됩니다.

1-1 ~ 1-3 에서설명드린내용들은개락단타관점으로계속매매를하시다보면자연스럽게본인만의기준이정해지는내용들이니최대한다양한경험을쌓도록노력해주시고, 매매를하지않았더라도매매를할수있었던종목이나타났나면흐름을찾아서살펴보시기바랍니다.

4. 시간외단일가하한가종목

- 정규장마감후악재가발생하거나재료가소멸되면시간외단일가에서하한가에도달하곤합니다. 이런종목들은다음날 -10% 이상의그로하락출발할가능성이높으정리를해두시는게좋습니다. 다만, 재료가소멸되면서주가가하락출발하는것이라면썸하한가를제외한나머지종목들은매매관심종목에서제외시켜주셔야합니다.

※ 지금까지설명드린내용들중 ' 재료소멸 ', ' 하한가 ' 등과같은부분만잘체크해주시면어려운부분은없을것이라생각합니다. 처음에는조금복잡해보이실수도있지만며칠정도만반복해서종목을정리하고다음날주가흐름을살펴보시면금방익숙해지실것입니다.

1. 매매시간엄수, 항상이론적인내용을기억할것시초에유입되는수급을이용하여단타매매를하는것이기때문에오랜시간동안종목을보유하지않도록하고 ' 시초에만매매 ' 해주셔야합니다.

2. 호가배열을보면서비중조절필자가유일하게거래대금의크기를무시한채로매매하는관점은개락단타매매입니다. 다만, 이렇게거래대금의크기를무시한채매매를하기위해서는반드시종목을매수하기전에 ' 호가배열을보고비중을조절 ' 할수있어야합니다.

평소수십만원 ~ 수백만원정도로매매하시는분들은괜찮지만수천만원이상의투자금으로단타매매를하시는분들은각호가에쌓인물량의크기를보고비중을조절해주셔야합니다. 만약비중을조절하는것이어렵다면평소큰거래대금이발생했던종목으로만매매하시는것도좋은방법입니다.

3. 그로하락출발한종목을매매하는관점으로하락출발한종목들은시초에반등하는흐름이나타날수도있고, 장중에반등하는흐름이나타날수도있습니다. 물론이두가지흐름모두단타관점으로매매를할수는있지만필자는 " 시초에주가가반등하는흐름 ' 에서만매매를하려고합니다.

필자가시초에만매매하려고하는이유는지금까지설명드렸던기본적인이론을전제로매매를하기때문입니다. ( 시조에유입되는수급을바탕으로매매 )
