## 1. ABCD 매매 패턴 (책의 최핵심)

### 1.1 ABCD의 진짜 정의 (p.1216~1234)

> "ABCD 패턴은 ABCD 구간을 거친 후 상승을 하는 모습을 표현한 것이다.  
> 돈이 들어온 자리 즉 **기준봉**이나, 수요가 폭발하여 급등이 나온 후 자리를 잡아가는 과정에서 ABCD 타점을 찾고 매매를 하는 것이다."  
> — p.1216

| 구간 | 책의 정의 | 의미 |
|---|---|---|
| **A** | **작은 양봉으로 시작 → 장대양봉** | 급등 시작 (=기준봉) |
| **B** | 상승에서 눌림으로 보합 | 차익실현 매물 → 눌림 |
| **C** | 더 이상 빠지지 않고 **지지받고 매수세 유입** | **매집 + 개미털기** |
| **D** | **본격 상승 = 진입 후 보유 구간 = 큰 수익** | **목표 X, 진입 후 보유 O** |

**핵심**: D는 **매매 종료점이 아니라 매수 진입점**. 그 이후 큰 수익을 실현하는 구간.

### 1.2 타임프레임 (p.1216, 1218, 1231, 1235)

| 타임프레임 | 용도 |
|---|---|
| **15분봉** (주력) | 1일~4일 ABCD 사이클 |
| **30분봉** | 더 긴 호흡 |
| **3분봉** | W패턴(이중바닥) 매집 구간 발견 |
| **1분봉** | 스캘핑 진입 |
| **일봉** | 중장기 ABCD (스마트머니 유입 확인) |

### 1.3 ABCD 패턴 종류 (p.1217)

1. **중장기 ABCD** — 일봉 기준, 이평선 우상향 종목, 분할매수
2. **스윙 ABCD** — 15분봉, 1~4일 보유
3. **단기 ABCD** — 데이트레이딩

### 1.4 매수 전략 (p.1216, 1221, 1229)

#### 직장인 전략 (장중 매매 불가)
- **B 구간**: 장대양봉(A) 다음에 **분할매수 진입**
- **D 구간 시작**: 우상향 확인되면 **분할 추가매수**
- **상승 못하고 빠질 경우**: 지지받을 때까지 기다림
- **다시 A 구간까지 빠지면 작은 양봉 출현 시**: 비중 담아 매수 (장대양봉 가능성 큼)

#### 스윙 전략
- B-C 구간에서 분할매집
- D 구간에서 상승 시 큰 수익 실현

#### 일봉 ABCD 진입 (p.1233-1234)
- A 구간 매집 + B 추가매집 + C 추가매집 + **D 구간 거래대금 급증 + 장대양봉 = 진입**
- 1일=A, 2일=B, 3일=C, 4일=D 패턴

### 1.5 손절 기준 (p.1229)

> "지지선이 깨지고 추세가 꺾이는 상황이 온다면 미련을 갖지 말고 빠르게 손절"

- B/C 구간 지지선 이탈 시 손절
- A 구간 시작점 하향 이탈 시 손절

### 1.6 종목 선정 메뉴 (키움증권 화면번호, p.1224~1226)

| 화면번호 | 내용 |
|---|---|
| **0184** | 장중 당일 거래상위 거래량/거래대금 1~15위 |
| **0198** | 장중 실시간 조회순위 1~10위 |
| **0162** | 장중 상승/상한가 10% 이상 종목 |

## 2. 스캘핑 (p.261~272)

### 2.1 정의
- 보유 시간: **2~3분**
- 회당 수익: **0.5~1%** (많아야 2~3%)
- 회당 거래 수: 하루 수십~수백 회

### 2.2 핵심 원칙
1. 매수 후 주가가 바로 안 가면 **즉시 매도** (1~3분 이내 판단)
2. 익절/본절/손절 미련 없이
3. 절대 **장기 보유 X**
4. 50% 승률만 되면 +수익 (작은 손절 + 작은 익절 누적)

### 2.3 시간대 (p.268, 271)
- **오전 9~10시** = 골든타임 (수급 활발, 거래량 급증)
- 그 외 시간대는 기회 적음

### 2.4 종목 선정 조건 (p.270)
- 수급 활발
- 시장 자금 집중
- 거래대금 풍부
- 호가 체결 빠르고 매끄러움
- 즉각적 상승 관성

### 2.5 시스템 구현 — 11년 BT 결과와 일치
- 단기 매매 = 음의 알파 (이미 검증)
- 와디즈 자체도 "거래 시간/수급 활발" 조건 강조 = 시스템 게이트 필요

## 3. 급등주 시황 매매 (p.501~513)

### 3.1 기본 공식 (p.501)
1. **1분봉 강력한 매수세 확인** (대량거래 장대양봉)
2. **주가 상승폭 5% 미만일 때** 진입 타이밍
3. 강력한 재료/이슈 확인
4. 단기 급등 후 조정 파동 관찰
5. **일봉, 중기 분봉, 단기 분봉 지지선 확인**되면서 마감 → 종가매수 또는 다음날 시가매수 후보
6. 지지자리에서 뉴스 발생 시 상승 가능성 증가

### 3.2 시스템 설정 (p.502~511)
- 키움증권 "신호대기" 메뉴
- 신호관리자 → 뉴스 설정
- 매수 키워드 / 매도 키워드 등록
- 매수 조건 = 주황색, 매도 조건 = 파란색
- 종목 필터링 (특정 종목/섹터만)

### 3.3 매수 타이밍 (p.508, 511)
- **5% 미만으로 급등 시작** 시 진입
- 능숙해지면 10% 이상도 가능
- 1~3% 상승 + 눌림 지지 + 뉴스 = 매수

### 3.4 매도 (p.511)
- 15% 정도 수익 시 매도

### 3.5 시스템 구현 가능성
- **DART API + 키워드 매칭** → 뉴스 신호
- **현재 `news_collector.py`는 FMP 미국 뉴스만** = 한국 뉴스 수집기 필요
- 5% 미만 상승 + 1분봉 장대양봉 + 거래량 확인 = 검색식

### 우선순위 2 — 와디즈 ABCD 재구현 (1주 작업)

#### 알고리즘 (15분봉 기준, 1~4일 사이클 = 26~104봉)
```python
def find_wadiz_abcd_15min(df_15min, days=4):
    봉_수 = days * 26  # 4일 = 104봉
    
    # A: 장대양봉 탐지 (몸통 비율 > 70%, 거래량 5봉평균의 2배+, 상승률 5% 이상)
    # B: A 이후 26봉(1일) 이내 차익실현 눌림 (저점이 A의 50% 이하 또는 38.2~61.8% 되돌림)
    # C: B 이후 횡보 (저점 유지, 거래량 감소, 매수세 유입 신호)
    # D: C 이후 상승 시작 (장대양봉 + 거래량 급증 + 신고가 돌파)
    
    if A and B and C and D_starting:
        return Signal('BUY', 'wadiz_ABCD_15min', strength=high)
```

#### 매매 정책
- 진입: B 구간 + C 구간 분할매수
- 본격 매수: D 구간 시작 (장대양봉 + 거래량 급증) 시 비중 확대
- 손절: A 구간 시작점 하향 이탈
- 익절: D 구간에서 추세 꺾임 (거래량 감소 + 종가 음봉)
