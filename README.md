## 무결성 도구

```bash
python _check_gspine.py        # G-번호 연속성·중복·결번 (~1.5초)
python _check_gspine.py --full # + 페이지 커버리지 (차트매매 노트 수정 시에만)
python _check_grefs.py         # 본문 G 참조가 실재 헤더를 가리키는지
python _batch.py <G번호>       # 참조검증 → append → spine검증 (포그라운드 전용)
```

★배치 실행은 **항상 포그라운드**. `&` 백그라운드 금지 — 종료 코드가 은폐된다.
