## G3425. S11 섹션3-② 단타 매매 주의점·마무리 — 기존 정리 종목을 너무 늦게 발견해 이미 고점 상승 시 단기 조정 흐름까지 대기하거나 유동적 보류, ★손절 대응 예정이면 큰 비중 세팅 OK / 데이트~스윙 연결 예정이면 비중 줄여 평단 관리 예수금 보유 필수(강조) (p.183)
- ★★★***"단타 매매 주의 = 다른 종목 보다가 '기존에 정리해둔 종목'을 너무 늦게 발견하여 이미 고점까지 상승했다면 '단기 조정 흐름 나타날 때까지 기다리거나 유동적으로 매매 보류'"*** → ★고점 상승 종목은 조정 대기/보류(추격 금지).
- ★★★★★***"단타 매매 시 '손절로 대응할 예정이면 비중 크게 세팅해도 괜찮지만, 데이트레이딩~스윙 관점으로 연결하는 매매를 할 예정이면 비중을 줄여서 평균 단가를 관리할 수 있는 예수금을 꼭 보유'"*** → ★★비중: 손절 예정=큰 비중 OK / 데이트~스윙 연결=비중 줄여 예수금 보유(강조하고 또 강조).
- ★***"단타 관점 매매 방법 설명 마치고, 데이트레이딩 관점 매매 방법 설명 예정"*** → ▸단타 매매 완결.

## G3426. S11 섹션3-② 「데이트레이딩 매매 접근 방법」 — ★가장 중요한 것='일봉 차트의 흐름'(기준봉 패턴·고점 횡보 패턴 등 캔들 패턴 흐름 안에서 매매), ★손절 라인 먼저 설정 후 매수(단타=빠른 매수·매도 / 데이트레이딩=여유 갖고 손절 라인 먼저 체크 후 매수) (p.184)
- ▸[본문 소제목 = 「데이트레이딩 매매 접근 방법」.]
- ★★★★***"큰 거래대금+급등 후 2차 상승 파동 예측과 함께 데이트레이딩 관점 매매 시 가장 중요한 것 = '일봉 차트의 흐름' → 거래대금에 무게 두고 분석해도 기준봉 패턴·고점 횡보 패턴 등이 자연스럽게 나타나 '이런 캔들 패턴 흐름 안에서 매매'"*** → ★데이트레이딩 = 일봉 흐름(기준봉·고점 횡보 패턴) 중요(G3327 거래대금⊇캔들 패턴).
- ★★★★★***"데이트레이딩 관점 = 일봉 흐름 분석하여 '만약 주가가 상승하지 않고 하락한다면 어느 구간에서 손절해야 하는지' 그 손절 라인을 먼저 설정한 뒤에 매매"*** → **★★데이트레이딩 매매 = 손절 라인 먼저 설정 후 매수.**
- ★★★***"단타 = 단기 변동성 보고 빠르게 매수·매도 / 데이트레이딩 = 여유 갖고 매매(손절 라인 먼저 체크 후 매수) → (일봉에서 기준봉 패턴·고점 횡보 패턴 등 스윙 매매 가능 판단 흐름 확인+손절 라인 설정 후 매수)"*** → ★단타 vs 데이트레이딩 차이 = 손절 라인 사전 설정 여부.
