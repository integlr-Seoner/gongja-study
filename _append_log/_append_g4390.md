## G4390. 수식관리자 기본편 — 신호검색 표시(원/다이아몬드/화살표, 매수=캔들 아래/매도=캔들 위) — ★'신호검색은 이전에 화살표 한 가지로만 표현 가능했지만 지금은 원·다이아몬드·화살표 등 다양한 관점으로 설정 가능 — 색상 선택, 모양 선택 후 설정할 것은 「표시」', ★★'표시에서 「매수」로 설정하면 캔들 아래에 화살표가 표현되며, 반대로 「매도」로 설정하면 캔들 위에서 화살표가 나타남 — 사용하는 화살표의 위치를 설정', ★'신호검색 화살표도 기술적지표와 같이 설명란에 어떻게 제작되었고 어떤 부분에서 화살표가 포착되는지 적어두면 활용·변형 시 도움' (01_기본편 p.42, 신호검색)
- ★★★★**[★신호검색 표시 = 모양(원/다이아/화살표) + 위치(매수=아래/매도=위)]** **★모양**: 원·다이아몬드·화살표 등 다양(색상·모양 선택). **★★표시(위치)**: **「매수」 = 캔들 아래** 화살표 / **「매도」 = 캔들 위** 화살표. **★설명란**: 제작 방법·포착 조건 기록(활용/변형 도움). **→신호검색 = [모양 + 색상 + 표시(매수 아래/매도 위)] 설정, 포착 조건은 설명란 기록.**

## G4391. 수식관리자 기본편 데이터 함수 — 시/고/종/저·거래대금·거래량 등 예약어(대소문자·한글 가능, 지표변수 불가) — ★★'[PDF 대조] 데이터 함수(소문자·대문자·한글 모두 사용 가능): 시가=`O, o`(OPEN) / 고가=`H, h`(HIGH) / 저가=`L, l`(LOW) / 종가=`C, c`(CLOSE) / 거래대금=`AMOUNT, amount` / 거래량=`V, v`(VOLUME) / 미체결약정=`OI, oi` / 일자=`DATE, date` / 시간=`TIME, time`', ★'데이터 함수는 모든 함수에 들어가는 가장 기본 함수 — 시가부터 거래량까지는 매번 제작 시 들어가고, 미체결약정·일자·시간 등은 자주 쓰지 않음', ★★'데이터 함수는 이미 수식관리자에서 의미를 부여한 함수(예약어)이기 때문에 앞의 지표변수로는 활용 불가 — 지표변수를 종가·O 등으로 설정하면 인식할 수 없는 함수라고 나타남', ★'주가가 상승할 때·하락할 때·일정 퍼센트 이상 상승 등 여러 관점으로 사용하는 방법은 뒤에서 자세히' (01_기본편 p.43~45, 데이터 함수)

## G4392. 수식관리자 기본편 산수 및 연산자 — 사칙/대입/비교/논리 연산자 — ★★'[PDF 대조] 산수 및 연산자: 더하기 `+`(H+L) / 빼기 `-`(H-L) / 곱하기 `*`(V*100) / 나누기 `/`((C+O)/2) / 대입 `=`(K=C+O) / 논리적으로 같다 `==`(C==O) / 비교 `<, <=, >, >=`(C>O) / 부정 `!, Not`(Date(1)!=Date) / 혹은·그리고 `And(&&), Or`(C && O)', ★'산수 및 연산자 함수는 함수끼리 비교하거나 계산할 때 사용 — 특정 함수를 더하거나 빼는 경우, 함수와 수치를 곱하고 나누는 경우 모두 사용', ★'함수끼리 더하고 빼는 경우가 많지 않다고 생각할 수도 있으나 기술적지표·신호검색 화살표 제작 시 굉장히 많이 사용 (자주 쓰면 자연스럽게 암기)' (01_기본편 p.46~48, 산수 및 연산자)
- ★★★★★***[★★산수·연산자 = 사칙(+-*/)·대입(=)·비교(<>==)·논리(&&/Or/!)]*** **★★연산자 표**(PDF 확정): **사칙** `+`(H+L)·`-`(H-L)·`*`(V*100)·`/`((C+O)/2). **대입** `=`(K=C+O, 변수 대입). **★★논리 비교**: **같다 `==`**(C==O, 대입 `=`와 구별) / **비교 `<, <=, >, >=`**(C>O) / **부정 `!, Not`**(Date(1)!=Date) / **논리곱·합 `And(&&), Or`**(C && O). **★용도**: 함수끼리 비교·계산 — 기술적지표·신호검색 화살표 제작에 다용. **→산수/연산자 = 사칙+대입(=)+비교(==,<,>)+논리(&&,Or,!), `=`(대입)과 `==`(비교) 구별이 핵심(조건문 IF의 재료).**

## G4393. 수식관리자 기본편 조건문 함수 IF(만일) — `IF(조건, 참값, 거짓값);` (V(1)=전일, 거래량 10배 예시) + ▸배치 소결 — ★'앞의 함수를 제외하고 조건문 함수가 따로 한 가지 있음 — 조건문 함수는 한 가지밖에 없음. 조건문 함수 = 「만일(IF)」 함수 — 조건을 정한 후 조건을 만족하면 1, 만족하지 않으면 0으로 표현', ★★'[PDF 대조] 예시 함수 = `IF(V > V(1)*Period, V, 0);` — Period는 숫자를 의미하는 보조지표이며 이 숫자가 10이라는 가정을 하고 해석하면 「만약 금일 거래량이 전일 거래량의 10배보다 크면 거래량으로 표현하고 아니면 0으로 표기하라」는 의미', ★★'특정 조건을 설정한 다음 조건에 만족하면 설정된 값이 표현되고, 조건에 만족하지 못하면 표현하지 않거나 다른 함수로 표현되도록 설정 가능 (기본 함수 중 많이 어려워하는 부분, 사용할 일 많지 않아 방법 잊기 쉬움 → 뒤에서 예시로 설명)', ★'앞 예시 이미지에서 거래량이 크게 터진 부분만 빨간색으로 거래량이 표현' (01_기본편 p.49~50, 조건문)
- ★★★★★***[★★★조건문 IF = `IF(조건, 참값, 거짓값);` (유일한 조건문)]*** **★★유일 조건문**: 수식관리자 조건문 함수 = **`IF`(만일)** 하나뿐. 조건 만족 시 1(or 지정값), 불만족 시 0. **★★문법**(PDF 확정): **`IF(V > V(1)*Period, V, 0);`** — 구조 = `IF(조건, 참값, 거짓값)`. **★★해석**(Period=10): **"금일 거래량 V가 전일 거래량 V(1)의 10배보다 크면 거래량 V로 표현, 아니면 0"**. **★★핵심 문법 포인트**: **`V(1)` = 전일 거래량**(함수(N) = **N봉 전 참조**), `*Period` = 지표변수 곱, 세미콜론 종결. **★결과**: 거래량 크게 터진 부분만 빨간색 표현(거래량 10배 필터). **→IF(조건,참,거짓);가 유일 조건문, 함수(N)=N봉 전 참조, 조건 미충족 시 0/다른 함수로 분기 → 신호검색·필터의 핵심. [OCR 오류: IF(V>V(1)*Period,V,0)→부(#>보(1)*2608,\,-0) 오인 → PDF 채택]**
- ▸★★**[배치 소결 — 01 기본편 데이터/산수/조건문 함수(수식 코드 본격)]** ①**신호검색 표시**(원/다이아/화살표, 매수 아래/매도 위). ②**데이터 함수**: OHLC(`O/H/L/C`)+거래량 `V`·거래대금 `AMOUNT`·미체결 `OI`·일자 `DATE`·시간 `TIME`(대소문자/한글 등가, 예약어=치환 불가). ③**산수·연산자**: 사칙+대입 `=`+비교 `==,<,>`+논리 `&&,Or,!`. ④**조건문 `IF(조건,참,거짓);`**(유일, `V(1)`=N봉 전 참조, 거래량 10배 필터). **★수식 코드 전량 PDF 이미지 대조 확정, OCR 오인 다수 기록. 통계 함수·기타 함수는 다음 배치.**
- ▸교차: IF 조건=`==,>,<`(G4392). V(1)=함수(N) N봉 전(Date(1) G4392). Period=지표변수(G4381). 거래량 10배 필터=거래량 10배 응용(G4378 챕터 예고). 불일치 없음.
