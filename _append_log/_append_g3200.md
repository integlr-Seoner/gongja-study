## G3200. S11 「1. 적정 거래대금 기초 이론 (기초 이론 공부)」 — 기초 이론 마무리(보충 자료집 일부 발췌 완료→차트·매매 사례로 거래대금 디테일 분석 관점 예고) (p.28)
- ▸[원문 헤더 = **「1. 적정 거래대금 기초 이론 / (기초 이론 공부) 적정 거래대금이란 무엇인가?」**(녹색). p.20~27 「2.적정 거래대금 공부」(주황) 뒤 다시 녹색 「1.기초 이론」으로 복귀 — 원문 상단 챕터 번호가 녹색(1)/주황(2) 교차 배치됨(정밀 인용 유의, [[g-note-reference-precision]]).]
- ★★***"지금까지 '종목의 적정 거래대금 보충 자료집에서 설명한 내용을 일부 발췌'하여 기초 이론 설명 완료 — 뒤 내용 이해·실전 활용 위해 지금까지 이론 꼭 이해하고 넘어갈 것"***.
- ★★★***"이번 자료집 = '적정 거래대금을 조금 더 디테일하게 분석하여 매매에 활용하는 관점' 설명 → 앞 내용 여러 번 읽고 공부. 적정 거래대금 기초 이론 마치고 '거래대금 이해 돕는 몇 가지 차트 + 필자 매매 사례' 살펴본 뒤 '거래대금 디테일 분석 관점' 설명 예정"***.

## G3201. S11 「1. 기초 이론 (기초 이론 복습) 적정 거래대금 공부용 차트 살펴보기」 — 도입(보충 자료집 예시 일부 재현, 적정 거래대금=주가 가파른 상승 시 평균적 거래대금≠특정 기간 평균, 차트를 있는 그대로 분석) (p.29)
- ▸[원문 헤더 = **「1. 적정 거래대금 기초 이론 / (기초 이론 복습) 적정 거래대금 공부용 차트 살펴보기」**(녹색). = INDEX(G3173) 섹션1 (기초 이론 복습).]
- ★★★***"공부용 차트 살펴보기 = '적정 거래대금 이론 보충 자료집에서 소개했던 예시 중 일부'를 보여주며 '적정 거래대금이 어떤 것 의미하는지' 이해 도움"*** → **★재진술 명시(차트매매 「적정 거래대금 보충 자료」=G458~G496 예시 재현).**
- ★★★★***"적정 거래대금 = '주가가 가파르게 상승할 때 발생하는 평균적인 거래대금'을 의미 ('특정 기간 동안의 평균 거래대금'과는 의미가 다름)"*** → **▸교차: 차트매매 G486·G493(과거 큰 상승 구간 평균) 정합 — 단순 기간 평균 아님을 명확히.**
- ★★***"적정 거래대금 발생해도 무조건 급등하는 것 아님 → 어떤 관점·해석으로 분석해야 하는지 사례 소개. '규칙·정답 미리 정하고 분석하면 손실 지름길' → '차트를 있는 그대로 분석'하는 습관 필요"***.
