## G3245. S11 「1. 적정 거래대금 기초 이론 / (기초 이론 응용) 적정 거래대금 이론을 활용한 사례」 — 도입(적정 거래대금 초점 매매 사례, 이번 주제 마지막으로 보충 자료집 발췌 마무리, 디테일 분석 관점은 뒤에서) (p.63)
- ▸[원문 상단 헤더 = 「1. 적정 거래대금 기초 이론 / (기초 이론 응용) 적정 거래대금 이론을 활용한 사례」(녹색) = INDEX(G3173) 섹션1 (기초 이론 응용).]
- ★★***"이 주제 = '필자가 적정 거래대금에 초점 맞춰 차트 분석하여 매매했던 사례' 소개 — 종목 분석 시 적정 거래대금뿐 아니라 '기준봉, 수급이 유입되는 시기, 재료 등 여러 가지를 복합적 관점으로 체크'해야 하나 지금은 적정 거래대금 초점"***.
- ★★★***"이 사례들도 '적정 거래대금 이론 보충 자료집'에서 설명한 내용이며 '이번 주제를 마지막으로 적정 거래대금 이론 보충 자료집을 발췌한 내용은 마무리'"*** → **★차트매매 G458~G496 재진술 구간 종료 지점(이후는 신규 심화 예상).**
- ★★***"데이트레이딩~스윙 관점 매매 가능한 흐름이 어떤 흐름인지 '디테일한 분석 관점'은 뒤에서 자세히 설명 → 지금은 적정 거래대금 분석 관점에 무게"***.

## G3246. S11 「3. 적정 거래대금 활용 / 적정 거래대금을 활용한 매매 사례」 — 인디에프(적정 거래대금 발생+주가 2번 상한가, ★매매 타점=장대양봉 후 조정 대기→기준봉 중심~시가 조정 시 스윙 진입, 단 바로 상승해 전량 매도) (p.64)
- ▸[원문 상단 헤더 = 「3. 적정 거래대금 활용」(주황).]
- [일봉 = 인디에프(2022/11~2023/07. 최고 2,025(11/25) / 최저 839(05/16). 동그라미 = 적정 거래대금 발생 구간, S=매도 표기, 거래대금 노란 원 2곳.).]
- ★★★***"인디에프 = 동그라미 구간에서 '적정 거래대금 발생' 확인 + 적정 거래대금 발생 때 '주가가 2번이나 상한가에 도달'"***.
- ★★★★***"필자 매매 = '적정 거래대금 발생하면서 장대양봉 캔들 출현한 이후 주가가 조정 받을 때까지 기다렸고, 주가가 기준봉의 중심~시가까지 조정 받았을 때 스윙 매매 관점으로 진입'"*** → ★실전 타점: 적정 거래대금+장대양봉(기준봉) → 조정 대기 → **기준봉 중심~시가 조정 시 스윙 진입.**
- ★★***"단 인디에프 주가는 예상과 조금 다르게 움직여 '스윙 관점 여러 번 매수하려 했으나 주가가 바로 상승하는 탓에 전량 매도한 뒤 매매 마무리' → 이어서 분봉 차트 살펴볼 예정"***.

## G3247. S11 「3. 적정 거래대금 활용」 — ▸★★배치 소결 겸 교차 참조 — S11 p.63~64 (활용 사례 도입 + 인디에프 스윙 진입 타점)
- **커버**: (기초 이론 응용) 활용 사례 도입·보충 자료집 발췌 마무리(G3245) + 인디에프 매매 사례(G3246).
- ★★★★★**[실전 매매 타점 정립]** 적정 거래대금 + 장대양봉(기준봉) 출현 → **조정 대기** → 주가가 **기준봉 중심~시가까지 조정** 받으면 **스윙 진입**. (인디에프는 바로 상승해 여러 번 매수 못 하고 전량 매도.)
- ★★★★**[챕터 전환]** 「1.기초 이론 (기초 이론 응용)」(G3245, 녹색) = 보충 자료집(차트매매 G458~G496) 발췌 재진술의 **마지막** 지점. 이후 「3. 적정 거래대금 활용」(주황) 실전 매매 사례 + 디테일 분석 관점(섹션2)은 신규 심화 예상.
- ▸★★★**[교차 참조 판정 — 차트매매 G458~G496 대조]**
  - **재진술 종료 선언**: 저자가 '이번 주제 마지막으로 보충 자료집 발췌 마무리' 명시(G3245) → 섹션1까지가 차트매매 재진술 구간, 이후는 S11 고유 심화.
  - **신규 심화**: 매매 타점(기준봉 중심~시가 조정 시 스윙 진입) = 차트매매 산출 이론에 없던 실전 진입 규칙. 5-1권 매매 원칙(기준봉·조정 타점)과 정합.
  - **불일치 0**: 인디에프 = 신규 사례(수치 상충 없음).
