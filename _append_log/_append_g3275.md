## G3275. S11 섹션2 「장중 거래대금 확인 방법」 — 유료 플랫폼 '호가 플레이'(과거 데이터 복기, 블로그 링크) vs 무료 기능([0609], 미리 저장한 데이터만), 무료 기능 활용법 설명 예고 (p.83)
- ★★***"과거 데이터 살펴보며 공부하려면 '개인적으로 데이터를 저장하는 것에 시간 투자'해야 함 → 시간 어려우면 유료 플랫폼 활용 가능"***.
- ★★★***"필자가 말한 유료 플랫폼 = **'호가 플레이'**(과거 블로그 포스팅으로 전달, 링크 제공) → 이번 자료집은 호가 플레이 아닌 '무료 기능 활용법' 설명"***.
- ★★***"유료 활용해도 되지만 '익숙하지 않은 화면', '키움증권 HTS에서 바로 볼 수 없다는 점' 등 이유로 편한 기능 활용 권장"***.
- ★★★***"'무료 기능 활용 시에는 미리 저장해둔 데이터만 볼 수 있음' → '과거 데이터를 복기하려면 호가 플레이'를 활용해야 함 → 본론: 무료 기능 활용법·데이터 저장·활용법 설명"*** → ★유료(호가 플레이)=과거 복기 / 무료([0609])=미리 저장분만.
