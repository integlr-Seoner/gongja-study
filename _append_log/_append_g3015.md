## G3015. 5-2권 대주제17 하위③(매매 원칙과 기준) — [본론] ## 01. 거래원 분석(이베스트 거래원의 특징) 도입 (p.76)
- ★★**## 01. 거래원 분석 (이베스트 거래원의 특징)** — ***"평소 단타·데이트레이딩 매매 시 '거래원 분석'은 안 하나, 적정 거래대금 데이트레이딩 시엔 '특정 거래원의 흐름'을 꼭 참고"***.
- ★★★***"특정 거래원 흐름 참고하는 이유 = '종목을 매수한 뒤 당일에 수익을 기대하는 매매이기 때문'"***.
- ★★***"큰 수급 유입 보고 2차 상승 기대한 채 '종가에 매수하거나 1~3거래일 뒤에 매수'한다면 거래원 흐름 분석 불필요 / 단 '당일에 2차 상승 흐름을 기대한 채 종목을 매수한다면 반드시 특정 거래원의 흐름을 분석'해야"***.
- ★***"이번 내용 = 다수 블로그·카페에 알려진 이론이나 '예시 포함 콘텐츠 적어' 이론 공부해도 매매 시 실수하는 상황 잦음 → 예시와 함께 설명"***.

## G3016. 5-2권 대주제17 하위③(매매 원칙과 기준) — ## 01 엘엠에스 방향성 예측 도입(윗꼬리 음봉=장중 상승 폭 반납 하락) (p.77)
- [일봉 = 엘엠에스(최고 10,620 12/19 / 최저 5,600 11/01. 네모 박스=긴 윗꼬리 음봉 구간, 거래대금 급증).]
- ★***"첫 예시 = '엘엠에스라는 종목의 주가 방향성을 예측했던 것' — 지인과 엘엠에스 주가 방향성 대화한 적 있음"***.
- ★★***"일봉 네모 박스 = '긴 윗꼬리 음봉 캔들 출현' → '장중 주가가 가파르게 상승했지만 상승 폭을 모두 반납한 채 하락했구나' 생각 가능"***.

## G3017. 5-2권 대주제17 하위③(매매 원칙과 기준) — ## 01 엘엠에스 vs 상보 분봉(같은 초전도체 흑연 재료, 상승 모습 완전 다름) (p.78)
- [분봉 = 엘엠에스(01/26, 최고 9,200 10:58 / 최저 6,600 15:30. 연녹색 박스=10:58 고점 후 하루 종일 하락) / 상보(01/26, 최고 2,415 09:13 / 최저 1,803 15:18. 정상적 상승 흐름).]
- ★★***"첫 차트 = 엘엠에스 분봉(앞 네모 박스 캔들) / 두 번째 = 당일 같은 재료 발생하며 상승한 상보 분봉"***.
- ★***"당시 엘엠에스·상보 = '초전도체 흑연 재료' 발생하며 시간 외 단일가부터 큰 폭 상승, 다음 날 장중에도 가파른 상승"***.

## G3018. 5-2권 대주제17 하위③(매매 원칙과 기준) — ## 01 엘엠에스=비정상 상승=절대 매수 금지, 필터=특정 거래원(이베스트) (p.79)
- ★★***"두 차트 비교 = 같은 재료지만 '주가가 상승하는 모습'은 완전히 다름 — 상보는 정상적, 엘엠에스는 '뭔가 비정상적인 흐름'"***.
- ★★★***"데이트레이딩 관점 매매 시 '엘엠에스와 같은 흐름이 나타나는 종목은 절대로 매수하면 안 되는 종목' — 비정상적으로 상승하는 흐름 나타나면 '주가가 장중에 언제든지 가파르게 하락할 수도 있기 때문'"***.
- ★★★***"이런 흐름 필터링 기준 = '특정 거래원의 흐름'으로 판단 가능 → 우리가 매매할 때 주의 깊게 살펴봐야 하는 거래원은 '이베스트'"***.

## G3019. 5-2권 대주제17 하위③(매매 원칙과 기준) — ★★## 01 이베스트 거래원 1~2위 필터 + HTS 키움 0254 당일 주요 거래원 (p.80)
- ★***"분봉 캔들 윗꼬리/아래꼬리로 비정상 판단도 가능하나 투자자마다 해석 다르고 '그래도 큰 수급 유입 상승이니 버텨볼 수 있겠다' 합리화 위험 → 보다 명확한 기준 제시"***.
- ★★★***"주가가 비정상적으로 상승하는 흐름 나타나면 반드시 '이베스트 거래원의 매매 순위가 1~2위인가?'를 확인할 것"***.
- [거래원 화면 = 당일 주요 거래원(엘엠에스, 매매상위 5개사 추정치). **매도상위 이베스트 688,243 / 매수상위 이베스트 766,760**(둘 다 1위), 이하 키움증권·삼성·미래에셋·NH투자증권.]
- ★★★***"키움증권 기준 '0254 - 당일 주요 거래원' 메뉴에서 각 종목별 상위 거래원 확인 가능 — 보통 이베스트 거래원이 주요 거래원 1위에 위치해 있을 때 엘엠에스와 같은 비정상적인 상승 흐름이 나타남"***.
- ▸★★[정량/HTS 필터]: **이베스트 거래원 매매 순위 1~2위(특히 1위) = 비정상 상승 흐름 → 데이트레이딩 배제**. HTS 메뉴 = 키움 **0254 당일 주요 거래원**.
