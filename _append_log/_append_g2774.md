## G2774. 5-1권 대주제16 하위①-1 — 이월드 재부각 호재 판단(이랜드 토스뱅크 지분 + 토스 이슈) (p.126)
- ★***"이월드 뉴스 본문 공통 = '이월드 계열사 이랜드가 토스뱅크 지분 7.5% 보유하고 있어서 수혜 기대감에 주가 상승한 것으로 풀이된다' → 과거부터 여러 번 부각됐던 '이랜드가 토스뱅크 지분 보유' 사실이 한번 더 부각+주가 상승"***.
- ★★**이월드 vs 이삭엔지니어링 차이**: 이삭엔지니어링 = 두 뉴스 모두 ***"삼성엔지니어링과 독점 계약 체결"*** 내용만(재탕) / 이월드 = ***"토스 기업가치 20조 원 평가 소식, 토스 구주 매각 모집 물량 2배 육박.."*** 등 **특정 이슈 발생** 포함.
- ★★***"'이랜드가 토스 지분 보유' 사실은 과거 부각됐지만 '토스와 관련된 재료 발생 뒤 이월드 상승 이유'를 설명 위해 기재된 내용이라 재탕 재료로 안 보고 매매 활용 가능"***.

## G2775. 5-1권 대주제16 하위①-1 — 재료 해석 관점 정리(A재료/B이슈 모식도) + 매매 복기 (p.127)
- ★***"지금까지 = '뉴스를 통해 재료 발생했을 때 필자가 재료를 해석하는 관점' — 처음엔 익숙하지 않을 수 있으나, 상승 이유인 재료 찾는 것 습관화 + 손절 후 '매매를 복기하는 과정' 여러 번 반복하면 익숙해짐"***.
- ★★[모식도]: **[A 재료 발생 + 특별한 이슈 없이 A 재료 부각] → 매매 X**(재탕) / **[A 재료 발생 + B 이슈 발생, 과거 A 재료 있어 관련주라는 설명과 함께 동일 내용 뉴스 보도] → 매매 O**(재부각 호재).

## G2776. 5-1권 대주제16 하위①-1 — 재료 해석 정리 + 처음 새롭게 부각 재료 도입 (p.128)
- ★★***"'특정 이슈와 함께 과거 재료가 재부각되었을 때는 재탕 재료로 보지 않기 때문에 매매' O / '특정 이슈 없이 재료만 재부각되었을 경우에는 재탕 재료가 발생한 것이니 주가 상승해도 매매 X'"***.
- ★***"마지막 = '주식시장에서 처음으로 새롭게 부각되는 내용' 포함 뉴스 사례 — 처음 부각 재료는 당연히 매매 활용 가능. 단 '우리가 접하는 대부분 재료들은 이미 과거 부각됐던 내용 포함'이라 처음 부각 뉴스 찾기 어려움(굉장히 가끔)"***.
