## G3323. S11 섹션2 「거래대금 분석 중간 점검 / 돌파 매매 이론」 — 이론을 일봉으로만 보면 다른 관점 해석 가능, 스윙 매매 가이드북 발췌 재소개, 돌파 매매=이전 고점 돌파(or 돌파 확인) 시 매수(미리 예측은 돌파 매매 아님, 이전 고점 물량·악성 매물 강하게 돌파=매물 소화 판단 시 매수) (p.115)
- ★★***"지금까지 이론을 '일봉 차트로만 살펴보면 다른 관점으로도 해석 가능' → 필자가 '스윙 매매 가이드북'에서 설명한 돌파 매매·고점 횡보 패턴 매매 이론을 발췌하여 재소개(뒤 이론과 연관, 이미 공부한 내용)"*** → ▸[출처: 스윙 매매 가이드북 발췌 = 차트매매 G458~G496과 별개 원본, 교차 참조 대상 아님.]
- ★★★★**[돌파 매매 이론]** ***"돌파 매매 = '일봉 차트에서 이전 고점을 돌파할 때, 혹은 돌파한 것을 확인한 뒤에 매수하는 것'이 가장 기본 기준"***.
- ★★★***"'미리 돌파를 예측하고 매매하는 것은 돌파 매매가 아니라 다른 기준으로 매수하는 것' → 돌파 매매 = '이전 고점에 쌓인 물량·악성 매물 등으로 확률적으로 돌파하기 힘든 구간을 강하게 돌파할 때 매매' → 이전 고점에 물린 투자자 매물을 소화했다고 판단할 때 매수"*** → ★돌파 매매 = 이전 고점 강한 돌파(매물 소화 판단) 시 매수.

## G3324. S11 섹션2 「거래대금 분석 중간 점검 / 고점 횡보 패턴 매매 이론」 — 기준봉 출현 후 가격 조정 없이 고점(기준봉 종가 부근) 횡보=차익 실현 물량에도 하락 안 함=특별한 의미(세력 큰돈 투자 개입), 호재 시 큰 상승·급락도 가능(양방향 변동성) (p.116)
- ★★★★**[고점 횡보 패턴]** ***"고점 횡보 패턴 = '기준봉이 출현한 뒤 주가가 가격 조정을 받지 않은 채로 고점에서 횡보하는 흐름' — 단기간 큰 폭 상승하면 보통 차익 실현 물량 나와 조정·하락해야 하는데 하락하지 않고 '기준봉의 종가 부근에서 횡보'하는 것이 특징"***.
- ★★★★***"조정 받아야 하는 흐름에서 조정 안 받고 횡보 = 특별한 의미 → 필자: '고점 횡보 패턴 = 주가 상승하다 잠깐 멈추고 쉬어가는 구간이며 동시에 고점 횡보 시 언제든 호재 발생하면서 주가 큰 폭 상승 가능'"***.
- ★★★***"즉 고점 횡보 중 '갑자기 급락해도 이상하지 않고(차익 실현 물량 쏟아지며 하락 가능), 갑자기 가파르게 상승해도 이상하지 않음' → '기준봉 종가 부근 위치 = 세력들이 큰돈 투자하여 주가 등락에 개입하겠다는 의미'라 어떤 변동성 나타나도 이상하지 않음"*** → ★고점 횡보 = 세력 개입(양방향 변동성, 호재 시 큰 상승).
- ★***"돌파 매매·고점 횡보 패턴 이론 재소개 완료 → 앞 흐름을 분봉 아닌 일봉으로만 해석하면 다른 관점, 지금부터 그 부분 설명 예정"***.
