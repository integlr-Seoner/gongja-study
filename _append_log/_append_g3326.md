## G3326. S11 섹션2 「거래대금 분석 중간 점검」 — 서남 일봉에 고점 횡보 패턴+돌파 패턴 동시 출현(1번→조정→2번을 일봉·캔들 관점으로 재해석), 큰 거래대금+급등 후 어느 정도 기간 조정→2차 상승 (p.117)
- ★★★***"지금까지 '큰 거래대금 발생+주가 가파른 상승하면 이후 어느 정도 기간 동안 조정 받는 흐름 나타나다가 2차 상승 파동 나타난다'는 사례 소개"***.
- ★★★★***"서남 일봉 차트에서는 필자가 언급한 '고점 횡보 패턴과 돌파 패턴이 모두 나타남'"*** → ★서남 일봉 = 고점 횡보 패턴(G3324) + 돌파 패턴(G3323) 동시(1번→조정→2번의 일봉 관점).
- [일봉 = 서남(2022/08~2023/04. 노란 원=고점 횡보 구간, 초록 박스=돌파+2차 상승, 거래대금 급증).]

## G3327. S11 섹션2 「거래대금 분석 중간 점검」 — ★★★핵심 통찰(기준봉 종가 부근 조정 없이 횡보=언제 어떤 모습 상승해도 이상하지 않음, 큰 거래대금+급등 캔들=기준봉, 거래대금 분석=캔들 패턴 분석 본질 동일=재료→관심→수급 유입→주가 가파른 상승) (p.118)
- ★★★***"서남 차트 = '기준봉 출현 이후 주가가 기준봉 종가 부근에서 일정 기간 횡보하다 다시 가파르게 상승한 흐름' → 필자(스윙 매매 가이드북): '기준봉 출현 뒤 조정 안 받고 기준봉 종가 부근 횡보하면 언제 어떤 모습으로 상승해도 이상하지 않은 흐름'"***.
- ★★★★***"처음엔 서남 상한가 캔들을 '큰 거래대금 발생+주가 가파른 상승 흐름' 또는 '높은 확률로 2차 상승 파동 예측 흐름'으로 설명 → '기준봉'이란 단어 안 써서 큰 거래대금+급등에 집중한 분들은 일봉에서 고점 횡보 패턴 확인 못 했을 것"*** → ★큰 거래대금+급등 캔들 = 기준봉(같은 것을 다른 관점으로 명명).
- ★★★★★***"핵심: 우리가 '거래대금을 기준으로 차트 분석하든, 캔들 패턴으로 차트 분석하든 결국은 재료가 발생한 뒤에 투자자들이 관심을 갖는다는 것, 또 투자자들의 관심이 수급의 유입으로 연결되면서 주가가 가파르게 상승한다는 것'이 중요"*** → **★★★거래대금 분석 = 캔들 패턴 분석 = 동일 본질: 재료 발생 → 투자자 관심 → 수급 유입 → 주가 가파른 상승.**
