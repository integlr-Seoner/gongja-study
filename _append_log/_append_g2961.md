## G2961. 5-2권 대주제17 하위②(버릴 건 과감히) — ★★★★# 03 단기 과열 종목 지정 공시 화살표 HTS 수식(A/B/D/화살표 조건식 원문) (p.31)
- ★★★★[단기 과열 종목 지정 공시 화살표 수식 — HTS 조건식 원문. ※예고 공시(G2959)와 다른 '지정' 공시용 = A에 신고가 조건 포함]:
- **A 치환 함수** (가장 뒤에 세미콜론 표기 주의):
```
A = Avg(C, 40, 1) * 1.3 <= C
&&
Avg(거래대금/C, 40, 1) * 6 <= Avg(거래대금/C, 2)
&&
Avg(((H-L)/((H+L)/2)), 40, 1) * 1.5 <= Avg(((H-L)/((H+L)/2)), 2)
&&
C > C(1)
&&
C > Highest(C, 10, 1);
```
- **B 치환 함수** (가장 뒤에 세미콜론 표기 주의):
```
B = IF(A==1,1,0) + IF(A(1)==1,1,0) + IF(A(2)==1,1,0) + IF(A(3)==1,1,0)
+ IF(A(4)==1,1,0) + IF(A(5)==1,1,0) + IF(A(6)==1,1,0) + IF(A(7)==1,1,0)
+ IF(A(8)==1,1,0) + IF(A(9)==1,1,0) + IF(A(10)==1,1,0) == 2;
```
- **D 치환 함수** (가장 뒤에 세미콜론 표기 주의):
```
D = IF(B-B(1)==1, 1, 0);
```
- **단기 과열 종목 지정 공시 화살표 수식**:
```
IF(A==1,1,0) * (IF(D(1)==1,1,0) + IF(D(2)==1,1,0) + IF(D(3)==1,1,0)
+ IF(D(4)==1,1,0) + IF(D(5)==1,1,0) + IF(D(6)==1,1,0)+ IF(D(7)==1,1,0)
+ IF(D(8)==1,1,0) + IF(D(9)==1,1,0) + IF(D(10)==1,1,0))
```
- ▸★★[예고 vs 지정 차이]: **예고 화살표(G2959)** = A(신고가 조건 분리) → B(==2) → `IF(B-B(1)==1)&&C>Highest(C,10,1)` / **지정 화살표(본 항)** = A에 `C>Highest(C,10,1)` 포함 → D=예고 트리거(B-B(1)==1) → 화살표 = `A==1 × (과거 1~10일 내 D 발생)` = 예고 후 10거래일 내 재차 A 충족 시 지정.
