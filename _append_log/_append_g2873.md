## G2873. S09 — # 매도 기준(손절): 개별 설정 + # 01 매매 기간 최대 5거래일(2~3거래일 보통) + ※예수금 없이 버티기 금지 (p.21)
- ★★**# 매도 기준 (손절 기준)** — ***"손절 라인 설정 기준은 명확히 정의 X → 필자 기준 참고하여 독자 개별 설정"***.
- ★★**# 01. 매매 기간 (최대 5 거래일까지만 보유)** — ***"데이트레이딩 매수 시 늦어도 '5 거래일까지는 주가가 추가적으로 상승하는 흐름이 나타나야 한다'"*** (보통 2~3거래일 내 수익, 지루하면 5거래일까지 대기).
- ★***"5거래일 이후부터는 포지션 따라 손절 고려 — 데이트레이딩은 단기 수익 기대 매수라 5거래일 지나면 '데이트레이딩 아닌 스윙 관점'에 가까움"***.
- ★★**※ 주의사항**: ***"큰 비중 실었는데 '주가 며칠 내 상승 안 하거나 손실 구간 들어가 추가 매수할 예수금 없는 상태'에서 스윙 관점 연결하는 행위는 지양 — 단기 매수 뒤 미상승에 원칙 어기고 버티는 매매(정상 스윙 아님) → 한두 번의 잘못된 판단으로 손절 안 한 채 버티다 한 달~두 달 수익금 모두 잃을 수도"***.

## G2874. S09 — # 02 매매 기간(10일선 이탈 시 손절, 5거래일+10일선 병행) + # 03 본인만의 기준(심리, 버티기는 부적절) (p.22)
- ★★**# 02. 매매 기간 (10일선 이탈 시 손절 고려)** — ***"버티는 마지막 가격 = '주가가 10일선을 이탈한 날' — 이탈 뒤 바로 다음 날 10일선 회복해주면 추가 매수로 평단 관리하며 조금 더 버티고, 이탈한 다음 날 회복 안 해주면 손절로 대응"***.
- ★★★***"손절 시 '5 거래일 조건도 필수 병행 — 둘 중 하나만 보고가 아니라 두 가지를 모두 체크하며 대응'"*** (10일선 이탈 후 재상승도 스윙에 가까움).
- ★★**# 03. 본인만의 기준 (심리적 요인)** — ***"# 01·02의 '마지막까지 버텨볼 수 있는 기준'은 사실 데이트레이딩 관점 '적절한 대응 방법 아님' — 단기 수익 기대인데 마지막 가격까지 버티는 건 이상적 매매 아님"***.

## G2875. S09 — # 03 이상적 대응(즉시 손절+종목 교체, 회전율↑) + # 04 포지션 설정(매수 전 데이트 종결 vs 스윙 연결) (p.23)
- ★★★***"데이트레이딩 '가장 이상적인 대응 방법' = '본인이 정해둔 손절 기준을 이탈했을 때 바로 손절로 대응하고, 다른 종목으로 교체해서 매매하는 것'"***.
- ★[예시 손절 기준]: ***"- 저점 매수했으니 2거래일 이내 미상승 시 매도 / - 2~3번 매수해 평단 대비 -5~-7%면 매도 / - 다음 날 장중 미상승 시 종가 매도 / - 5일선 이탈하면 추세 무너질 수 있으니 매도"***.
- ★★***"'끝까지 버텨보자!'보다 '빨리 잘라내고 다른 종목으로 수익 내야겠다' 생각으로 회전율 높이길 권장"***.
- ★★**# 04. 포지션 설정하기 (손절 OR 대응) / ## 매수하기 전에 포지션 설정하기** — ***"매수 전 항상 '매매 포지션에 대해 생각' — '이 종목 매수 뒤 단타·데이트레이딩으로 끝낼 것인가?' 아니면 '주가 미상승 시 스윙 매매까지 연결할 것인가?'"***.

## G2876. S09 — ## 포지션 별 대응 방법 [모식도] 데이트레이딩 vs 데이트~스윙 (p.24)
- ★★[모식도 ## 포지션 별 대응 방법]:
  - **[공통]** 본인 매매 성향 점검 후 매매 포지션 설정 → 재료 발생+다수 관심+큰 수급 유입 가파른 상승 종목.
  - ★★**[데이트레이딩 매매]** ①눌림목~횡보 구간 매수 → ②2차 상승 없이 바로 하락 시 **본인 설정 손절 기준에 맞춰 대응**.
  - ★★**[데이트레이딩~스윙 매매]** ①눌림목~횡보 매수(추가 매수 가능성→**예수금 고려 비중 조절**) → ②2차 상승 없이 하락 시 **스윙 관점 연결** → ③**기준봉의 시가·의미 있는 가격을 손절 라인**으로 설정·대응(중심~시가 바닥 추가 매수).
