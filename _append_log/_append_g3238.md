## G3238. S11 「2. 적정 거래대금 공부 / 적정 거래대금보다 재료가 중요한 종목」 — [새 소주제] 풋 성격 종목(글로벌·뉴스 악재 수혜, 시장 하락 시 상승)은 거래대금보다 재료가 훨씬 중요(악재 해소 시 하루 만에 하한가) (p.58)
- ★★***"주가 상승 종목 대부분 = 호재 발생+투자자 관심+큰 수급 연결. 단 간혹 호재 아닌 '글로벌 악재', '특정 뉴스로 인한 악재'로 인한 수혜 기대감으로 상승하는 종목도 있음 — 보통 '주식시장 전체 하락 때 주가 상승'하는 특징, 시장에서 '풋 성격을 가진 종목'이라 부름"***.
- ★★★★***"풋 성격 종목 = 적정 거래대금이 중요할 때도 있지만 '주가가 상승했던 근본적인 이유인 재료가 훨씬 더 중요' (거래대금 크기보다 재료가 더 중요한 종목)"***.
- ★★★***"아무리 적정 거래대금만큼 발생해도 '주가 상승 흐름 만들었던 악재가 해소되면 풋 성격 종목 주가는 하루 만에 하한가 기록할 만큼 큰 폭 하락' → 무작정 적정 거래대금·주가 등락률만 보고 매매하면 리스크 큼"***.

## G3239. S11 (재료 우선) 예시 — 흥구석유 차트 흐름(유가 관련 풋 성격 종목, 적정 거래대금 약 1150억) (p.59)
- [일봉 2분할 = 흥구석유(상단 2021/03~2022/01 / 하단 2020/11~2022/05. 거래대금 기준선 115,000백만=1150억, 초록 박스 여러 구간).]
- ★★★***"흥구석유 = 유가·글로벌 악재(전쟁 등) 수혜 풋 성격 종목. 적정 거래대금 대역 = 약 1150억(기준선). 앞서 나눠 보여준 두 차트."*** [흥구석유 = crossref 실예시 목록에 없는 신규 예시.]

## G3240. S11 (재료 우선) 흥구석유 연결 차트 — 적정 거래대금 크기는 정해졌으나 주가 등락 흐름 비정상적(불규칙)해 거래대금 분석만으로 매매 어려움, 재료를 최우선 체크 (p.60)
- [일봉 = 흥구석유 연결(2019~2022. 거래대금 기준선 115,000백만=1150억, 초록 박스 다수. 앞 두 차트 연결).]
- ★★★***"흥구석유 = '주가 큰 폭 상승할 때 발생하는 적정 거래대금 크기는 어느 정도 정해져 있지만 다른 종목에 비해 주가 등락 흐름이 비정상적인 경우가 많음' → 적정 거래대금 분석만으로는 매매하기 어려움"***.
- ★★★★***"풋 성격 종목 매매 시 = '적정 거래대금 분석도 중요하지만 재료를 가장 우선순위로 체크하고 매매해야 함'"*** → ★풋 성격 종목 매매 우선순위: 재료 > 적정 거래대금.
