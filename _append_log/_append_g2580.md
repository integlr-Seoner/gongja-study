## G2580. S07 매매 이론 — 상한가 단타 = 다음 날 -5%↑ 갭 하락 종목(전일 상한가 반등) (p.21)
- ★★***"상한가 단타/데이트레이딩 매매 관점 = '주가가 다음 날 -5% 이상 갭 하락 출발한 종목 매매' — 상한가 종목 대부분 갭 상승 출발이나 간혹 하락 출발"***.
- ★***"전날 상한가 종목 다음 날 갭 하락 출발 → 시초부터 '갭 상승 기대 매수한 투자자 손절 물량' 쏟아지며 잠깐 하락 → '추가 매수 물량, 갭하락 단타 목적 매수 물량, 평균 단가 조정해 손실 만회하려는 특정 집단 매수 물량' 등에 높은 확률 반등"***.
- ★★***"반등 시 '전일 상한가 가격까지 상승하는 경우' 굉장히 많음 → 그 흐름 이용 단타 — 단 '주가 하락한 이유 반드시 체크'(재료 소멸/대장주 약세/재탕 배제 조건, 개장 전 확인)"*** (G2408·G2410 정합, 4-2권 흐름1의 상한가 종목 버전).

## G2581. S07 — 반등 흐름 모식도(장중 반등 / 종가 흐름) (p.22)
- ★***"재료 소멸/대장주 약세/재탕 제외한 이유로 하락 출발 시 보통 반등 — 전일 상한가 부근까지 상승 or 전일 상한가 돌파 or 상승 폭 반납 윗꼬리 or 종가까지 유지 장대양봉"***.
- ★***"정확 예측 불가하나 그 흐름에서 2~3%↑ 수익 기대 단타"***. [모식도 = 장중 주가 반등 흐름 / 종가 흐름.]

## G2582. S07 — 반등 이유(특정 집단 물량 정리) + 목표가(전일 상한가) (p.23)
- ★***"상승 이유 = 추가 매수/갭하락 단타 목적/손실 만회 특정 집단 수급 유입(100% 정답 아님)"***.
- ★★***"분명한 것 = '전날 수급 밀어 넣으며 상한가까지 상승시킨 특정 집단이 보유 물량을 본전~수익권/약손실 구간에 정리하려면 주가를 한 번 정도는 가파르게 상승시켜야 한다'"*** (⚠️저자 해석, G2411 정합).
- ★★***"목표가 = '전일 상한가 가격까지 상승할 확률 높다 판단 → 전날 상한가 가격을 1차 목표가로 설정 매매' — 시초부터 바로 상승 시 패턴 단타 / 바로 상승 못한 채 하락~횡보 시 손절 라인 설정 후 데이트레이딩 분할 매수"***.

## G2583. S07 매매 방법 (1) — 5%↑ 갭 하락 후 급등 (단타) + 매수 2관점 (p.24)
- ★★**매매 방법 (1)** = ***"주가가 5% 이상의 갭으로 하락 출발한 뒤 급등하는 흐름 (단타)"***.
- ★**매수가(시초 상승 시 2관점)**: (a) ***"3% 미만 상승 흐름에서 추격 매수"*** (b) ***"음봉 시가 돌파 시점에서 매수(음봉 시가 돌파 패턴 → 4-1권 내용 응용)"*** (G2412 정합). [모식도 = 3% 미만 상승 캔들 / 음봉+양봉.]

## G2584. S07 — 3% 미만 추격 매수 상세(손절=시초가) + 씨씨에스 실물 (p.25)
- ★***"첫 매매 방법 = 시초부터 상승 출발 시 3% 미만 상승 흐름 바로 매수 — '손절 라인이 시초가'이기 때문에 시초가 대비 3%↑ 매수 시 손절 라인 너무 길어져 3% 미만에서만 매수 권장"***.
- ★***"3%↑ 추격 매수 = 손절 라인 길고 목표 수익률 짧아 비효율 → '항상 리스크 최소화하고 매매하는 것' 중요"***.
- [차트 = 씨씨에스(066790) 1분봉, 2023/11/06(월): **시가 3,050(-15.04%) / 고가 4,095(+14.07%) / 저가 2,915(-18.80%) / 종가 3,425(-4.60%)**, 거래대금 145,053백만. 최고 4,095(09:37) / 최저 2,915(09:03). 노란 원=3% 미만 매수 지점.] (G2411 씨씨에스 정합.)

## G2585. S07 — 음봉 시가 돌파 매수(한국석유 실물) (p.26)
- ★***"두 번째 매매 방법 = 시초부터 하락 출발 시 다시 반등하여 음봉 시가 돌파 시점 매수 — 호가창 분석 시 4-1권처럼 촘촘히 쌓인 호가 돌파 시점 매수"***.
- ★***"단 갭 하락 종목보다 전일 시간외 단일가에서 강했던 종목에 수급 몰리면 호가 얇을 수도 → 단순 패턴만 보고 매매도 OK — 매수 후 하락 시 음봉 시가 이탈 구간 손절, '음봉 시가 재돌파 시 재매수'(일봉 양봉일 때만 보유)"*** (G2414·G2415 정합).
- [차트 = 한국석유(004090) 1분봉, 2023/10/11(수): **시가 11,710(-6.99%) / 고가 15,410(+22.40%) / 저가 11,500(-8.66%) / 종가 14,300(+13.58%)**, 거래대금 196,189백만. 최고 14,980(09:22) / 최저 11,500(09:01). 노란 원=음봉 시가 돌파 매수.]

## G2586. S07 — 매도가(전일 상한가부터 분할, -10~-15% 갭 하락은 2~5%부터) (p.27)
- ★***"-5% 갭 하락 시 = 전일 상한가 가격부터 분할 매도 — 3% 미만 상승/음봉 시가 돌파 매수 시 2~4% 수익부터 1차 매도"***.
- ★***"전일 상한가까지 항상 반등 아니라 흐름 보며 유동 대응(전일 상한가 터치 후 하락/미터치 하락 시 빠르게 시장가 매도) — 강한 수급 상한가 돌파할 것 같으면 전일 상한가 부근 일부 매도+큰 수익 기대(단 상한가 부근 상승 꺾이면 빠르게 정리)"***.
- ★★***"-10~-15%↑ 갭 하락 시 = 전일 상한가까지 거리 10%↑ → 2~5% 수익권부터 조금씩 수익(큰 폭 갭 하락은 목표 못 미쳐 다시 하락 가능)"***.

## G2587. S07 — 손절가(음봉 시가 이탈, 양봉일 때만 보유) + 지지부진한 흐름 (p.28)
- ★***"손절가: 두 관점 모두 '일봉 캔들 양봉 유지 시만 보유' — 상승 출발=3% 미만 매수+시초가 손절 / 하락 출발=음봉 시가 돌파 매수+음봉 시가 이탈 손절"***.
- ★★***"지지부진한 흐름: 음봉 시가 돌파했다 이탈, 다시 돌파했다 이탈 반복 → 계속 손절+재매수 시 약손절 누적 손실 커짐 → '손실 1~2% 정도면 주가 방향 정해질 때까지 조금 기다리는 것도 좋은 방법'(재료 소멸 안 됐으면 장중 급등 가능)"***.
- ★***"세력은 상한가 위에서만 매도하면 수익권 정리 가능 → 시간 무관 장중 언제든 급등 가능(특히 대장주 없는 조용한 시점 후속 매수세 강하게 유입)"*** (G2387 상한가 위 매도 정합).

## G2588. S07 — 지지부진 흐름 예시(이트론) (p.29)
- [차트 = 이트론(096040) 1분봉, 2023/04/20(목): **시가 382(-9.26%) / 고가 490(+16.39%) / 저가 365(-13.30%) / 종가 418(-0.71%)**, 거래대금 268,554백만. 최고 490(09:47). 노란 원=음봉 시가 돌파했다 이탈 반복.]
- ★***"이트론 = 시초 음봉 시가 돌파했다 이탈, 다시 돌파했다 이탈 반복 → 한 번 손절 후 재매수, 동일 패턴 반복 시 손실 안 커지는 가정 하 조금 더 지켜봄 — 지지부진했다 갑자기 급등"*** (G2415 이트론 정합).

## G2589. S07 매매 방법 (2) — 5%↑ 갭 하락 후 횡보~하락 (데이트레이딩) (p.30)
- ★★**매매 방법 (2)** = ***"주가가 5% 이상의 갭으로 하락 출발한 뒤 횡보~하락하는 흐름 (데이트레이딩)"***. [모식도 = 계단식 하락 1차/2차/3차 매수.]
- ★***"상한가 종목 -5%↑ 갭 하락인데 재료 소멸/2·3등주 약세/재탕 아닌데 '바로 반등 못한 채 하락~횡보' 종목 → 특정 집단 물량 정리 위해 한 번은 단기간 상승 만들 것 → 데이트레이딩 천천히 분할 매수 — '단기간' = 이론 정의 없으나 필자 경험상 당일~최대 2거래일"*** (G2416 정합).

## G2590. S07 — ▸★★배치 소결 — S07 상한가단타 요약집 p.21~30 (매매 방법 (1) 단타 + (2) 데이트레이딩)
- **커버**: 매매 이론·반등 논리(G2580~G2582) + 매매 방법 (1) 단타(매수·매도·손절·실물, G2583~G2588) + 매매 방법 (2) 데이트레이딩 도입(G2589).
- ★★★★★**[매매 방법 (1) = 5%↑ 갭 하락 후 급등 단타]** 상한가 종목 다음 날 -5%↑ 갭 하락 → 시초 손절 물량 후 반등(특정 집단이 물량 정리 위해 한 번은 가파른 상승) → **목표 = 전일 상한가(1차)**. **매수** = ①3% 미만 상승 추격(손절=시초가) ②음봉 시가 돌파(손절=음봉 시가 이탈). **매도** = 전일 상한가부터 분할(2~4%부터 1차, **-10~-15% 갭 하락은 2~5%부터**). **손절** = 일봉 양봉 유지 시만 보유. 실물: 씨씨에스(-15.04%→+14.07%)·한국석유(-6.99%→+22.40%).
- ★★★★★**[지지부진한 흐름]** 음봉 시가 돌파↔이탈 반복 시 손절+재매수 누적 손실 → **손실 1~2%면 방향 정해질 때까지 대기**(재료 소멸 안 됐으면 급등 가능, 이트론 실물). 세력 상한가 위 매도로 시간 무관 급등 가능(조용한 시점 후속 매수세).
- ★★★★**[매매 방법 (2) = 5%↑ 갭 하락 후 횡보~하락 데이트레이딩]** 재료 소멸/약세/재탕 아닌데 반등 못한 채 하락~횡보 → 계단식 1~3차 분할 매수, **단기간=당일~최대 2거래일**(G2589).
