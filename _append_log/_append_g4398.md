## G4398. 수식관리자 기본편 응용① — 함수(N)=N봉 전 참조 + 캔들 조건(양봉 C>O, ★양봉≠상승) — ★★'함수를 표현할 때 금일 캔들·전일 캔들·2~3거래일 전 캔들을 모두 기준으로 잡고 입력 가능 — 금일이 아니라 전일 캔들을 입력할 때는 함수 뒤에 숫자를 붙임: 2일 전 종가 = `C(2)`, 3일 전 시가 = `O(3)`', ★★'[PDF 대조] 캔들 조건: 종가>시가(양봉, 갭하락 시 하락양봉 가능) `C > O` / 종가>=시가(양봉 OR 도지·쩜상·쩜하) `C >= O` / 종가=시가(도지·쩜상·쩜하) `C = O` / 종가<시가(음봉, 갭상승 시 상승음봉 가능) `C < O` / 종가<=시가 `C <= O` / 전일 종가=금일 종가(등락률 없는 도지) `C = C(1)` / 전일<금일 종가(주가 상승) `C > C(1)` / 전일>금일 종가(주가 하락) `C < C(1)` / 고가=저가(쩜상·쩜하) `H = L`', ★★'양봉(C>O)이 무조건 상승은 아님 — -10% 갭하락 출발 후 -5%까지 상승하면 결국 하락이지만 캔들만 양봉(하락양봉). 반대로 +20% 시작해 +5%까지 하락하면 장중 -15% 하락했으나 전일보다 오른 상승음봉. 주가 상승/하락은 종가 기준(C>C(1)/C<C(1))으로 설정하는 것이 좋음', ★'※부등호: `=` 함수는 항상 오른쪽에 붙임 → `>=`, `<=`' (01_기본편 p.61~63, 응용)
- ★★★★★***[★★★함수(N)=N봉 전 참조 + 캔들 조건(양봉≠상승)]*** **★★함수(N) 규칙**: 함수 뒤 숫자 = **N봉(거래일) 전** — `C(2)`=2일 전 종가, `O(3)`=3일 전 시가(금일=인자 없음, 전일=`(1)`). **★★캔들 조건**: 양봉 `C>O`·음봉 `C<O`·도지 `C=O`·쩜상/쩜하(고가=저가) `H=L`. **★★상승/하락(종가 기준)**: 주가 상승 `C > C(1)`·하락 `C < C(1)`·보합 `C = C(1)`. **★★★양봉≠상승 주의**: 갭하락 출발 후 반등하면 **하락양봉**(C>O이나 C<C(1)), 갭상승 후 하락하면 **상승음봉**(C<O이나 C>C(1)) → **주가 방향은 종가 기준(C vs C(1))**, 캔들 색(C vs O) 아님. **★부등호**: `=`는 오른쪽 → `>=`, `<=`. **→N봉 전=함수(N), 양봉(C>O)과 상승(C>C(1))을 구별(갭으로 하락양봉/상승음봉 발생) → 방향 판별은 종가 대 전일 종가.**
- ▸교차: ★함수(N)=V(1) 전일(G4393)·Shift(A,N)(G4396). C>C(1)=주가 상승. 양봉≠상승=갭 하락/상승(상따 갭 G4267). H=L=쩜상한가(G4271). `=` 오른쪽=문법 규칙.

## G4399. 수식관리자 기본편 응용② 상승/하락률·상한가·갭 조건 — ★★'[PDF 대조] 전일 종가 대비 상승/하락률: 10% 이상 상승 `C >= C(1) * 1.1` / 20% 초과 상승 `C > C(1) * 1.2` / 10% 이하로 상승 `C <= C(1) * 1.1` / -20% 이상 하락 `C <= C(1)*0.8`', ★★'[PDF 대조] 상한가 캔들 `C(1) * 1.3`(=전일 종가 +30%) / 하한가 캔들 `C(1) * 0.7`(-30%) / 갭상승 10% 이상 캔들 `O >= C(1) * 1.1` / 갭하락 -10% 이상 캔들 `O <= C(1) * 0.9`', ★'보통 주가 상승 시 `C > C(1)*가수*100`처럼 표현하여 배수 값을 지표변수로 설정하여 사용 — 지표변수는 기본 정의된 함수(V, C 등)가 아니면 어떤 단어·알파벳도 사용 가능(예시는 숫자로 설명)' (01_기본편 p.64·66, 응용)

## G4400. 수식관리자 기본편 응용③ 거래량/거래대금 조건 — ★★'[PDF 대조] 거래대금 증가 `거래대금 > 거래대금(1)` / 거래대금 감소 `거래대금 < 거래대금(1)` / 거래량 증가 `V > V(1)` / 거래량 감소 `V < V(1)` / 거래량 동일 `V = V(1)`(실 사례 드묾)', ★★'[PDF 대조] 특정 기간 평균 거래량 `Avg(V, 기간)` / 평균 거래량이 N(10000)주 이상 `Avg(V, 기간) > N(10000)` / 금일 거래량이 특정 기간 평균 거래량의 N배 이상 `V > Avg(V, 기간) * N` / 전일보다 거래량 N(10)배 이상 증가 `V > V(1) * N(10)` / 당일 거래 없는 캔들 `V == 0`' (01_기본편 p.64·66, 응용)
