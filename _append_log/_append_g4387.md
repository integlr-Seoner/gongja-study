## G4387. 수식관리자 기본편 — 3가지 지표 종류(기술적지표/신호검색/강세약세) + 암호설정 — ★★'수식관리자에서는 주로 세 가지 종류의 지표를 제작 — ①기술적지표 = 차트 위 캔들과 같이 표현되는 지표(이동평균선이 대표) ②신호검색 = 차트 위에 표현하는 화살표 ③강세약세 = 차트 뒷배경 — 매매 유리 구간=강세, 불리 구간=약세, 전체 색상으로 표현', ★'암호설정 = 다른 사용자에게 본인 지표 제작 방법을 숨기기 위함(외부 매매·동영상 촬영 시 함수 노출 방지) — 잘 사용하지는 않음', ★★'지표 선택 후 암호설정 → 암호 2번 입력 후 확인 → ★암호 설정 후 「작업저장」을 꼭 눌러야 저장 (암호 잊으면 해제 어려우니 자주 쓰는 것으로 설정·메모)', ★'암호화 시 「이 수식은 암호화되었습니다. 수식관리자를 통해 확인하세요.」 표시 → 우측 상단 「비밀번호」 버튼으로 암호 입력해 함수 확인/해제(해제도 작업저장 필요, 암호설정→비밀번호로 라벨 변경)' (01_기본편 p.32~36, 지표 종류·암호설정)
- ★★★★★***[★★3가지 지표 종류 = 캔들 위 / 화살표 / 뒷배경]*** **★★지표 종류 3**: ①**기술적지표** = 차트 위 **캔들처럼 표현**(이동평균선 대표) ②**신호검색** = 차트 위 **화살표** ③**강세약세** = 차트 **뒷배경 색상**(강세=매매 유리 구간, 약세=불리 구간). **★암호설정**: 지표 함수 노출 방지(외부 매매/동영상). 지표 선택 → 암호 2번 입력 → **작업저장 필수**(안 하면 저장 X). 암호 잊으면 해제 난망(메모). 확인/해제는 「비밀번호」 버튼(해제도 작업저장). **→수식관리자 산출물 3형태(캔들형 지표·화살표·배경 색상), 암호설정은 함수 은닉(작업저장 필수).**
- ▸교차: 신호검색 화살표=대표 기능(G4378). 기술적지표(이평선)=보조지표 후행성(G4379). 강세약세 배경=매매 유리/불리 구간 시각화. 작업저장 필수(G4386).

## G4388. 수식관리자 기본편 — 지표 제작 순서(지표 종류→새로만들기→지표명/수식이름/함수) + 지표조건설정(지표변수 정의) — ★'지표를 제작할 때 입력 순서 — 가장 먼저 제작 원하는 지표의 종류 선택(기술적지표/신호검색 화살표) → 새로만들기 → 새창 → 이때부터 지표명·수식이름·함수 입력', ★★'수식이름은 의무가 아니지만 일목균형표처럼 5개 수식이 들어가는 경우 갈릴 수 있으니 1개 지표 안에 2개 이상 수식을 제작하는 경우에는 사용하는 것이 좋다', ★★'지표조건설정 = 함수 입력 시 지표변수를 입력했다면 각 지표변수에 대한 정의를 내려주는 곳 — 이동평균선에서 기간·가격·이평 종류 등도 지표조건설정을 통해 이루어짐', ★'지표조건설정이 제대로 되지 않으면 수식검증을 눌렀을 때 설정하라는 메시지가 나옴' (01_기본편 p.37~38, 지표 제작 순서)
- ★★★★**[★지표 제작 순서 = 종류→새로만들기→지표명/수식/조건설정]** **★순서**: ①**지표 종류 선택**(기술적지표/신호검색) → 새로만들기 → 새창 → ②**지표명·수식이름·함수 입력**. **★수식이름**: 의무 아님, 단 **1개 지표에 2개 이상 수식**(일목균형표=5수식)이면 구분용으로 사용 권장. **★★지표조건설정**: 함수에 **지표변수를 썼으면 각 지표변수 정의** — 이동평균선의 **기간·가격·이평 종류**도 여기서 설정. 미설정 시 수식검증에서 설정 요구 메시지. **→지표 제작 = [종류 선택 → 지표명/수식/함수 → 지표변수를 지표조건설정에서 정의], 지표변수 정의 누락은 검증에서 잡힘.**
- ▸교차: 지표변수 정의=지표변수(G4381 Period/D1). 지표조건설정=수치값(G4381). 수식이름=다중 수식 구분(일목균형표). 수식검증 메시지(G4386).

## G4389. 수식관리자 기본편 — 라인설정 + ★스케일설정(하면=거래량 아래/가격=캔들 위) + 설명란 + ▸배치 소결 — ★'라인설정 = 직접 제작한 수식들의 색상·굵기·유형을 변형하는 설정 메뉴 — 각 지표(0, 1 등 숫자)를 눌러서 설정(선택 안 하면 수정 안 됨)', ★★'스케일설정 = 수식관리자 설정 중 가장 많이 실수하는 것 — 스케일이 「하면」이라는 것은 거래량과 같이 차트 아래쪽에 지표가 표현되도록 설정하는 것, 반대로 캔들 위에 표현되는 이동평균선 같은 지표는 「가격」을 체크', ★★'지표를 만들고 차트 위에 나타나지 않는다는 경우의 거의 20~30% 정도는 스케일 설정이 되지 않아 표현되지 않거나 잘못 표현되는 경우', ★'설명란 = 제작한 지표의 특징을 기록(한글·영어 텍스트) 후 작업저장 — 지표가 너무 많아지면 모두 기억하기 어려우니 본인 제작 지표의 특징을 최소 몇 가지라도 기록 권장' (01_기본편 p.39~41, 지표 제작 순서)
- ★★★★★***[★★스케일설정 = 하면(거래량 아래) vs 가격(캔들 위), 미표현의 20~30% 원인]*** **★라인설정**: 수식의 **색상·굵기·유형** 변경(각 지표 숫자 선택 후). **★★스케일설정(최다 실수)**: **「하면」 = 차트 아래(거래량처럼)** / **「가격」 = 캔들 위(이동평균선처럼)**. **★★핵심**: 지표가 **차트에 안 나타나는 경우 20~30%는 스케일설정 오류**(위치 지표를 아래로/아래 지표를 위로 잘못 설정). **★설명란**: 지표 특징 기록(한/영, 작업저장) — 지표 많아지면 기억 어려워 필수. **→스케일설정이 지표 표시 위치(가격=오버레이/하면=서브패널)를 결정, 미표현 시 최우선 점검 대상.**
- ▸★★**[배치 소결 — 01 기본편 지표 종류·제작 순서]** ①**지표 종류 3**: 기술적지표(캔들 위)/신호검색(화살표)/강세약세(배경 색상). ②**암호설정**(함수 은닉, 작업저장 필수). ③**제작 순서**: 종류 선택→새로만들기→지표명/수식/함수→**지표조건설정**(지표변수 정의)→**라인설정**(색/굵기)→**스케일설정**(가격/하면, 표시 위치)→**설명란**(특징 기록)→수식검증→작업저장. **★스케일설정이 미표현 원인 20~30%.** **★데이터/산수/통계 함수(수식 코드)는 후속 챕터 — PDF 이미지 대조.**
- ▸교차: 스케일=표시 위치(가격 오버레이 vs 서브패널). 라인설정 색상=지표 시각화. 제작 순서 종합(G4385·G4388). 수식검증+작업저장(G4386). 불일치 없음.
