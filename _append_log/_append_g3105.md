## G3105. 5-2권 대주제18 하위②(조건검색기 세팅과 활용) — 무작정 매수 위험(단기 큰 손실·거래정지) + 검색 시 재료/수급 확인 + HTS 켠 채 매매 (p.151)
- ★★***"특별한 기준 없이 무작정 '가파르게 하락했으니 단기 반등 확률 높다' 생각으로 매수하면 '단기간에 큰 손실 발생하거나 장 마감 후 거래정지가 되는 상황' 발생할 수도"***.
- ★***"차트 완전히 망가진 종목, 사실무근 뉴스로 오전 발생 재료 소멸된 종목, 아무 호재 없이 급등 뒤 상한가 풀려버리는 종목 등 매매하다 큰 손실 가능"***.
- ★★★***"검색기로 종목 찾을 때도 '어떤 재료 발생하면서 상승?, 과거 or 당일 오전~오후 수급 유입?, 2차 상승 만들 만한 유의미한 수급 유입?' 확인하고 매매"***.
- ★★***"낙폭과대 데이트레이딩 = 실시간 대응 중요 → 'HTS 켠 채로 매매'해야 — HTS 켜두면 검색기 포착 종목의 '호재 뉴스·일봉·분봉' 분석에 오래 안 걸림. 장중 모니터링하면 상승 이유 미리 파악했을 가능성↑"***.

## G3106. 5-2권 대주제18 하위②(조건검색기 세팅과 활용) — 호재 종목 관심종목 정리 → 관심종목 포착+급락 시 바로 매매(미분석 종목은 일봉/분봉/재료 체크) (p.152)
- ★***"'이 종목은 호재 발생하면서 주가 가파르게 상승했네?' 판단 종목 발견 시 일봉·분봉·재료 분석 후 관심종목에 정리(모니터링 못하면 캡처)"***.
- ★★***"관심종목 편입 종목이 실시간 조회 순위 상위 메뉴·조건검색기에 포착되면서 급락하면 '이미 과거에 모든 흐름을 분석해 둔 상황'이라 바로 매매 활용"***.
- ★★***"'주가 가파르게 상승했던 종목 상승 이유 찾기 습관화'하면 검색기 포착 종목들 대부분 과거 분석해 둔 종목일 가능성↑"***.
- ★***"검색기 포착 종목이 '과거 분석 안 한 종목'이면 일봉 망가짐/거래대금 작음일 수도 → 처음 보는 종목이 급락 시 '일봉·분봉·재료'까지 체크 후 매매"***.

## G3107. 5-2권 대주제18 하위②(조건검색기 세팅과 활용) — ★★★★낙주 단타 5분 검색기 조건식 B·C(HTS 원문) (p.153)
- ★★★★[낙주 단타 5분 검색기 조건식 — HTS 원문. 조건식 = **B and C or (D and E)**]:
- **B 지표 = 주가등락률**: `[5분] 1봉전(중) 종가대비 0봉전 종가등락률 -6% 이하` (설정: 주기 5분 / 1봉전(중) 종가 대비 / 0봉전 종가 등락률 / ⊙ -6% 이하 [또는 5%~10% 범위 옵션]).
- **C 지표 = 캔들연속발생**: `[5분] 0봉전 2봉 연속 음봉 발생` (설정: 주기 5분 / 2봉 연속 / 음봉 발생 / 봉전기준 0).
- ★★***"'5분 주기, 종가 대비, 종가 등락률, 퍼센트'만 주의해서 입력하면 어려움 없음"***.
- ★***"C 조건식은 HTS에서 '캔들' 검색하면 쉽게 찾음(캔들 연속 발생). 대상변경 = 업종대상(전체)·제외없음·전체월결산"***.

## G3108. 5-2권 대주제18 하위②(조건검색기 세팅과 활용) — ★★★★낙주 단타 5분 검색기 조건식 D·E(HTS 원문) + 조건식 완성 (p.154)
- ★★★★[낙주 단타 5분 검색기 조건식 D·E — HTS 원문]:
- **D 지표 = 주가등락률**: `[1분] 1봉전(중) 종가대비 0봉전 종가등락률 -2% 이하` (설정: 주기 1분 / 1봉전(중) 종가 대비 / 0봉전 / -2% 이하).
- **E 지표 = 주가등락률**: `[1분] 2봉전(중) 종가대비 1봉전 종가등락률 -2% 이하` (설정: 주기 1분 / 2봉전(중) 종가 대비 / 1봉전 / -2% 이하).
- ★★★**[최종 조건식] `B and C or (D and E)`** (AND 더블클릭 → OR 변경).
- ★***"D·E도 주가 등락률 조건식 — '1봉전, 2봉전, 1분 주기' 주의. 파란 네모 박스 and·or 부분 체크"***.
- ★★***"해당 검색기에는 많은 종목이 포착되지 않음 — '3시부터 검색기 켜두고 매매할 종목 포착되는지 지켜보면 됨'"***.

## G3109. 5-2권 대주제18 하위②(조건검색기 세팅과 활용) — 검색기 운용(상한가 이탈 메인, 낙주 5분은 3시부터·예수금 여유 시만) + 실시간 조회 순위 상위 메뉴 도입 (p.155)

- ★★★***"필자는 보통 '상한가 이탈 검색기를 메인으로 사용'하며, 낙주 단타 5분 검색기는 '주식시장 흐름 모니터링 가능한 날만 3시 정도부터 켜두는 편'"***.
- ★★***"다른 종목 이미 매매 중이거나 여러 종목 매수 상태에서 예수금 조절해야 하는 경우엔 '낙폭과대 데이트레이딩 안 하니 안 켜둘 때'도 있음 — 낙폭과대 데이트레이딩 = 평소 비중 작게 활용하는 후순위 매매 → '매매할 종목 없거나 예수금 여유 있을 때만' 활용"***.
