## G4040. 6-1권 소주제3 ★종목 분석 데이터 도입(갭 예상 시 상따/불명 시 상한가 풀림·눌림 매수, 방향성 100% 예측 불가하나 데이터 분석으로 리스크↓) — ★'상한가에 도달한 이후 주가가 보합에서 출발할지, 추가적으로 상승할지, 하락할지를 정확하게 예측할 수 없기 때문에 갭이 뜰 것 같다 라고 판단할 수 있는 흐름에서만 상따 매매를 하고, 갭이 뜰지 안 뜰지 모르겠다 라고 판단되는 흐름에서는 상따 매매를 보류한 채 상한가가 풀리는 흐름을 이용하거나 이후 눌림목이 형성되었을 때 매매', ★'상한가에 도달한 종목의 주가가 추가적으로 상승할 것 같은지, 아니면 하락할 것 같은지를 판단할 때는 어떤 데이터를 분석해야 할까?', ★'상한가에 도달했던 종목들의 이후 주가 방향성을 100% 정확하게 예측하는 것은 어렵다', ★★'하지만 필자는 몇 가지 데이터를 분석한 뒤 매매 기준을 설정하여 매수할 경우 리스크를 줄이는 것은 어느 정도 가능하다' (6-1권 p.60)
- [그림 = 상한가 봉 3개(①상한가 봉 ②상한가 봉+위 점선 박스=갭상승 예상 ③상한가 봉+우측 점선 박스=보합/눌림 예상).]
- ★★★★★***[★종목 분석 데이터 도입] "상한가 이후 보합/상승/하락 정확 예측 불가→'갭 뜰 것 같다' 흐름에서만 상따, '갭 뜰지 안 뜰지 모르겠다' 흐름에서는 상따 보류하고 상한가 풀림 이용/이후 눌림목 매매. ★추가 상승 vs 하락 판단 시 어떤 데이터 분석? 방향성 100% 예측 어려우나 ★★몇 가지 데이터 분석+매매 기준 설정으로 리스크↓ 가능"*** → **★★★★★종목 분석 데이터 도입(소주제3): ★갭 예상 판단=갭 뜰 것 같으면 상따, 불명이면 상따 보류+상한가 풀림/눌림목 매수(소주제2 G4013). ★상한가 이후 방향성 100% 예측 불가하나 데이터 분석+매매 기준 설정으로 리스크↓. 데이터 기반 종목·포지션 선택(재료 크기 G4038의 데이터 분석 심화).**

## G4041. 6-1권 소주제3 ★★재료 분석 우선(차트<재료, 차트 좋아도 재료 없으면 갭 안 뜸/차트 망가져도 큰 재료면 갭 상승, 갭+상한가 확률 높은 종목만 상따) — ★'필자가 상따 매매를 할 때는 차트와 재료 두 가지를 모두 분석하며 이 중에서도 재료를 분석한 뒤 매매하는 것을 굉장히 중요하게 생각', ★'상따 기술적 관점 분석도 중요하나 필자는 기술적 분석만으로는 상한가에 도달한 종목의 주가가 다음 날 갭으로 상승 출발할지, 갭으로 하락 출발할지 예측하기가 어렵다는 견해', ★★'일봉 차트 흐름이 좋고 과거에 매집봉이 출현했다고 해도 시장에서 매매하는 투자자들에게 관심을 받을 만한 재료가 발생하지 않는다면 다음 날 갭이 뜨지 않은 채 하락할 수도 있기 때문', ★★'오히려 일봉 차트 흐름이 망가져 있고 매집봉이 하나도 출현하지 않았던 종목에 10:1 비율의 무상증자 공시가 발행되거나 글로벌 대기업과 협업한다는 뉴스가 보도되었을 때 해당 종목의 주가가 갭으로 상승 출발할 확률이 더 높기 때문에 재료 분석을 더 중요하게 생각', ★'정리하면 갭으로 상승 출발할 확률이 높고, 동시에 상한가까지 상승할 확률이 높은 종목만 상따 관점으로 매매하고 그 외 나머지 종목들은 포지션을 변경해서 매매할 필요가 있다' (6-1권 p.61)
- ★★★★★***[★★재료 분석 우선] "★상따=차트+재료 모두 분석하되 재료 분석 후 매매를 굉장히 중요시. 기술적 분석만으로는 다음 날 갭 상승/하락 예측 어려움. ★★차트 흐름 좋고 매집봉 있어도 관심 받을 재료 없으면 다음 날 갭 안 뜨고 하락할 수도. ★★오히려 차트 망가지고 매집봉 없던 종목에 '10:1 무상증자 공시 or 글로벌 대기업 협업 뉴스' 나오면 갭 상승 확률 더 높음→재료 분석 더 중요. ★정리=갭 상승+상한가 확률 높은 종목만 상따, 나머지 포지션 변경"*** → **★★★★★재료 분석 우선(차트<재료): ★★상따 판단에서 재료>차트=차트(일봉 흐름·매집봉) 좋아도 관심 받을 재료 없으면 다음 날 갭 안 뜨고 하락, 반대로 차트 망가져도 큰 재료(10:1 무상증자·글로벌 대기업 협업)면 갭 상승 확률↑. ★재료=갭 상승/상한가 확률의 핵심 결정 요인(재료 대원칙 G4001·재료+수급 S11 G3407 심화). ★정리=갭 상승+상한가 확률 높은 종목만 상따, 나머지는 포지션 변경(소주제2 눌림 매수 G4013·G4038).**
