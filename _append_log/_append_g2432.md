## G2432. 대주제13 하위② — 마녀공장 매매 불가(상한가 풀림 큰 거래대금=물량 정리) (p.191)
- ★***"큰 거래대금 발생하며 상한가 도달했어도 '상한가 풀릴 때 큰 거래대금 발생'했다면 '주가를 상한가까지 상승시킨 특정 집단이 보유 물량을 상한가에 정리'했을 수도 있다"***.
- ★***"큰 거래대금으로 상한가 풀린 뒤 다시 상한가 도달할 때 큰 거래대금 발생 안 하면 '당일 유입된 특정 집단 수급이 당일 바로 이탈했을 수도 있다' → 매매 보류"***.
- [차트 = 마녀공장 1분봉(10/25~10/26, 최고 27,950 13:08 / 최저 23,750 12:13). 연녹색 박스=13:08 상한가 + 노란 원 2개=14시·15시경 상한가 풀림 거래대금.] ★종가 부근 재상한가 시 "이전보다 훨씬 큰 거래대금"이면 재유입 해석 가능하나, 아주 작은 거래대금 상한가라 매매 불가.

## G2433. 대주제13 하위② — 마녀공장 정리(상한가 풀림=물량 정리, 다음날 상승 X) (p.192)
- ★***"마녀공장 = 넥스트아이와 비슷 — 네모 박스=상한가 도달 시 큰 거래대금 / 동그라미=상한가 풀릴 때 이전보다 훨씬 큰 거래대금 + 종가 부근 하락 시도 눈에 띄게 큰 거래대금"***.
- ★★***"즉 '주가를 상한가까지 상승시킨 특정 집단이 보유 물량을 상한가 부근에서 정리했을 수도 있겠다'는 흐름 — 마지막 동시호가에 갭 뜨며 상한가 마감했지만 넥스트아이처럼 큰 거래대금 발생 안 함"*** (⚠️저자 해석).
- ★★***"'상한가 도달했다가 큰 거래대금 발생하며 상한가 풀리는 흐름'이 나타나면 다음 날 상승 안 하는 경우 많아 매매 안 함"*** (배제 1st, G2399·G2403 정합).

## G2434. 대주제13 하위② — 남성 매매 불가(상한가 고정 못한 채 반복 하락 + 마지막 작은 거래대금) (p.193)
- [차트 = 남성 1분봉(09/25~09/26, 최고 2,780 09:21 / 최저 2,120 15:19). 연녹색 박스 여러 개=상한가 부근 도달했다 하락 반복 + 노란 원=마지막 작은 거래대금.]
- ★***"남성 = 처음부터 상한가 고정 못한 채 '상한가 부근까지 상승한 뒤 큰 거래대금 발생하며 하락하는 흐름'이 반복 → '상따 매매 투자자들에게 보유 물량 정리한 것'으로 해석"***(⚠️저자 해석).
- ★★***"남성 상한가 부근 상승 시 거래대금 = '큰 거래대금 발생하며 상한가 도달할 것 같은 흐름 나타났다 하락하는 흐름 반복 + 마지막엔 굉장히 작은 거래대금으로 상한가 도달'"*** → 이후 큰 폭 반등 못한 채 하락 지속.

## G2435. 대주제13 하위② — 폴라리스세원 매매 불가(테슬라 연동 2등주, 120억=300억 미만 배제) (p.194)
- [차트 = 폴라리스세원 일봉(최고 2,575 05/18 / 최저 1,630 10/05). 연녹색 박스=상한가 2,145(+30.00%), 거래대금 급증.]
- ★***"폴라리스세원 = '폴라리스오피스의 오피스 웹 서비스를 테슬라에 연동한다는 소식' 뉴스 보도 → 폴라리스오피스와 함께 상한가 도달 — 대장주=폴라리스오피스, 폴라리스세원=폴라리스오피스 급등 뒤 2등주로 부각되며 가파른 상승"***.
- ★★***"폴라리스세원 상한가 도달한 날 거래대금 = 120억 정도 → '300억 미만 거래대금 상한가 종목은 매매 안 함' 기준에 부합"*** (배제 2nd, G2405 정합).

## G2436. 대주제13 하위② — 매매 불가 마무리 + ★Q&A(-5% 기준=개인 경험) (p.195)
- ★***"300억 미만 거래대금 or '상한가 풀리면서 큰 거래대금 발생한 종목'들은 다음 날 가파른 상승 안 나타날 수도 있어 매매 보류 — 종가 기준 상한가 도달해도 '분봉 차트 흐름에 따라 매매 여부 결정'"***.
- ★**Q&A**: Q = 갭하락 출발 흐름 매매 시 기준을 -5%↑로 정한 이유? → ***"-5% 기준 = 필자가 상한가 종목 매매하며 자연스럽게 결정된 개인적 기준 — 독자는 -1%~-4% 갭하락 종목 매매해도 됨. 단 필자는 -1%~-4% 갭하락 종목 매매 시 좋은 결과 안 나와 -5%↑ 갭하락 종목만 매매"***. ★다수 종목 흐름 살펴보며 본인 기준 정립.

## G2437. 대주제13 하위② — ★★Q&A(상한가 이탈 안 된 채 큰 거래대금 = 2해석, 확정 불가) (p.196)
- ★**Q** = 상한가 도달 뒤 ***"상한가가 이탈되지 않은 채 큰 거래대금 발생하는 것"***은 어떤 의미?
- ★★**두 가지 해석 + "정확한 것은 이후 흐름 확인해야 알 수 있다"**:
  - **해석1** = ***"세력들이 상따 매매 투자자들을 털어내면서 매집하기 위해 작업하는 것"***.
  - **해석2** = ***"세력들이 보유 물량 중 일부를 상한가에 쌓인 매수 호가 잔량에 던지는 것"***.
- ★***"다음 날 개인 매수 어려울 정도로 가파른 상승 = 해석1(매집 작업) / 상한가 도달했음에도 하락 = 해석2(물량 던짐)"***.
- ★★***"단순히 큰 거래대금 발생 현상만 보고 '그 의도가 OOO이다'라고 확정 짓는 것은 어렵다"*** (⚠️저자 해석 원칙 = 관측≠의도 확정, G2332·G2437 세력 서사 신중론 집약).

## G2438. 대주제13 하위② — 상한가 매매 관점 마무리 + 추후 보충 자료 예고 (p.197)

## G2439. 대주제13 하위③ — 단타 매매를 할 수 있는 상한가 흐름(도입, 확률 높은 구간만) (p.198~199)
- [배너 = ①분봉 수급 유입 확인 ②상한가 이후 기대 흐름 ③**단타 매매를 할 수 있는 상한가 흐름**(진입).]
- ★***"상한가 종목 매매 관점 예시 많지 않아 추가 자료집으로 보충 — 단타/데이트레이딩은 최대한 많은 사례 공부·눈에 익혀야 → 이론 설명 시 예시 최소화, '필자가 중요하게 생각하는 포인트' 위주"***.
- ★★***"※ 상한가 이후 기대 흐름 굉장히 다양하나, 필자는 '-5%↑ 갭하락 출발 종목을 단타/데이트레이딩 관점 매매하는 방법'만 소개 — 이유 = '패턴 활용 매매 시 최대한 확률 높은 구간에서만 매매해야 한다'"***.
- ★***"패턴 활용 = 4권 매매법만 활용, 이외 추가 흐름 매매 관점은 5권부터 / 모든 흐름을 '패턴으로 공식화하는 것'은 불가능 → 매매 확률 높은 내용만 소개"***.

## G2440. 대주제 마무리 — ★★★단타 매매 4권 마무리(5단계 학습법) (p.200)
- ★★**「단타 매매 4권을 마무리하며…」** (4권 전체 마무리). ★시초가 패턴 활용 단타/데이트레이딩 매매법 소개 완료 — 여러 관점이라 헷갈리고 깔끔히 정리 안 된 느낌일 수도 → 개별 포인트(매수 타점·손절 라인·매매 이론) 압축 요약 자료집 공유.
- ★★★**5단계 학습법**: **Step 1)** 단타 매매 가이드북 1~4권 정독 / **Step 2)** 요약 자료집 정독 / **Step 3)** 1~4권 2차 정독 / **Step 4)** 요약 자료집 2차 정독 / **Step 5)** 각 매매법 관련 예시 자료집 여러 번 정독.
- ★***"필자도 과거엔 단순히 '주가가 oo까지 하락하면 매수', '주가가 oo를 돌파하면 매수' 관점으로 단타/데이트레이딩"***.

## G2441. 대주제 마무리 — 단순 패턴 한계 → 수급·주가 흐름(5~6권 예고, 4권 완독) (p.201)

- ★★***"단타 매매 4권 마무리, 5권부터 '수급의 유입과 이탈, 주가의 흐름' 분석 매매 관점 소개 예고"*** → **4권(4-1권+4-2권) 전체 완독.**
