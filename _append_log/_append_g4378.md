## G4378. 수식관리자 기본편 — 수식관리자 정의·의의(키움 차트 기술적 분석 도구, 함수 조합/변형, 신호검색 화살표) — ★'수식관리자는 키움증권에서 제공하고 있는 차트상 기술적 분석을 할 때 도움을 줄 수 있는 기능 중 하나 — 여러 가지 지표들을 조합하고 변경할 수 있으며 차트 위에 본인이 원하는 구간에 화살표로 표현할 수도 있다', ★'우리가 자주 보는 가격(시가·고가·종가·저가)과 거래량·거래대금, 이외로 이평선·볼린저밴드·엔벨로프 등 지표에 옷을 입혀 여러 시표(지표)를 제작하여 사용', ★★'가장 많이 사용하는 기능 = 신호검색 화살표 — 특정한 거래량을 발생시키는 캔들, 특정한 등락률을 보여주는 종목 차트 위에 화살표를 표현하여 더 빠른 분석과 판단을 할 수 있도록 도와주는 기능', ★'수식관리자 공부는 굉장히 시간이 오래 걸림 — 대부분은 직접 함수를 생각하고 만들어야 하며 배열·변형·조합을 수백 번~수천 번 거쳐야 원하는 함수 제작 가능, 하루 10분~1시간 꾸준히 공부 추천 (저자도 모든 수식을 다 제작하지는 못함)' (01_기본편 p.6~7·10, 머리말·활용과 의의)
- ★★★★**[★수식관리자 = 키움 차트 기술적 분석 함수 편집기]** **★정의**: 키움증권 차트 기술적 분석 도구 — **함수 조합/변형으로 보조지표 제작 + 차트 위 화살표 표현**. **★재료**: 가격(시/고/종/저)·거래량·거래대금·이평선·볼린저밴드·엔벨로프 등을 변형·조합·합성. **★★대표 기능 = 신호검색 화살표**: 특정 거래량 캔들/특정 등락률 종목 차트 위에 화살표 표시 → 빠른 분석·판단. **★학습 특성**: 정의된 함수도 있으나 **대부분 직접 함수를 생각·제작·배열·변형·조합**(수백~수천 번) → 오래 걸림, 하루 10분~1시간 꾸준히. 저자도 전부 제작 못 함. **→수식관리자 = 함수로 보조지표를 짓는 편집기, 핵심 산출물은 신호검색 화살표(조건 충족 시 차트 마킹), 학습은 직접 조립 반복.**
- ▸교차: 조건 충족 마킹=검색기/조건식(G4038 상따 검색기·G4276 8기준). 거래량·거래대금 재료=적정 거래대금(G4259)·거래량 10배(G4287). 시/고/종/저·이평선=데이터 함수(후속). ※OCR 머리말(p.6~7) 이미지 페이지라 일부 깨짐, 설명 취지는 명확(수식 코드 아님).

## G4379. 수식관리자 기본편 — ★보조지표 후행성 원칙(100% 수익 X, 캔들 제외 후행성, 분석 쉬운 지표 제작에 의의) — ★'이런 지표들의 함수들을 변형·조합·합성함으로써 다양한 보조지표를 차트 위에 구현할 수 있는데 이런 지표들이 100% 수익을 만들어 주지는 않는다', ★★'보조지표는 모두 후행성 지표이며 선행성은 존재하지 않는다 — 지표의 흐름을 보고 미래 주가 방향성을 예측해 볼 수 있고 그것이 맞다면 수익, 예측과 반대로 움직이면 손절이나 비중 축소 같은 빠른 대응으로 손실 최소화', ★★'캔들을 제외한 보조지표는 모두 후행성 지표이며 매매를 할 때 우리의 기술적 분석·차트 분석에 도움을 주는 역할만 하는 것', ★★'매매를 할 때 도움을 줄 수는 있지만 수익을 보장하는 보조지표는 없다 — 수식관리자를 통해 수익을 줄 수 있는 보조지표가 아니라 분석하기 쉬운 보조지표를 제작하는 것에 의의를 두고 활용' (01_기본편 p.10, 활용과 의의)
- ★★★★★***[★★★보조지표 후행성 원칙 = 수익 보장 X, 분석 보조에 한정]*** **★★핵심 명제**: **캔들 제외 모든 보조지표는 후행성**(선행성 없음). 지표 흐름으로 방향성 예측 → 맞으면 수익, 틀리면 손절/비중 축소로 손실 최소화. **★★수익 보장 X**: 수식관리자로 **수익을 주는 보조지표를 만드는 게 아니라 「분석하기 쉬운 보조지표」를 만드는 것에 의의**. **★함의**: 100% 수익 지표 없음 — 지표는 판단을 빠르게/쉽게 할 뿐, 진입·청산 판단(손절)은 여전히 매매자 몫. **→수식관리자 지표는 후행성 분석 보조 도구일 뿐, 수익 보장 없음 → 자동화 시에도 지표=판단 가속화, 리스크 관리(손절)는 별도.**
- ▸교차: ★후행성=관측≠예측(G2437 세력 서사 신중론). 예측 틀리면 손절/비중 축소=손절 최우선(G4277). 지표 도움만=재료·흐름 우선(G4041·G4255 흐름 암기 금지). 수익 보장 X=100% 아님(G4291).

## G4380. 수식관리자 기본편 — 제작 팁(함수 배열/조합/종류가 최난, 수백만 경우의 수) + 챕터01 구성 + ▸배치 소결 — ★'수식관리자를 사용해 본 분들이 가장 어렵게 느끼는 부분 = 함수의 배열과 조합, 함수의 종류', ★★'수식관리자로 만들 수 있는 보조지표의 종류는 나열할 수 없지만 나열 가능하다고 가정하면 정말 수백만 가지 이상 — 보조지표 종류가 많고, 좌우로 이동시킬 수 있으며, 각각의 수치값을 하나씩 조정할 수 있어 말도 안 될 만큼 많은 경우의 수', ★'저자도 모든 보조지표를 제작하지는 못하지만 과거 경험으로 요청 지표를 어느 정도 제작할 수 있는 경험치를 쌓음', ★'챕터 01 = 수식관리자의 기본 개념 + 기본 함수 소개 (외우기보다 활용하며 자연스럽게 기억): 활용과 의의 / 제작 팁 / 기능과 단어 소개 / 데이터 함수 / 산수 및 연산자 / 통계 함수 / 기타 함수' (01_기본편 p.8·12, 챕터01 도입·제작 팁)
- ★★★★**[★제작 팁 = 함수 배열/조합/수치 조정의 방대한 경우의 수]** **★최난 지점**: **함수의 배열·조합·종류**(사용자 공통 애로, 저자도 동일). **★★경우의 수**: 보조지표 종류 다수 + **좌우 이동 + 수치값 개별 조정** → 수백만 가지 이상. **★저자 역량**: 전부 제작은 불가하나 경험으로 요청 지표 어느 정도 제작. **★챕터01 구성**: 기본 개념 + 기본 함수 — ①활용과 의의 ②제작 팁 ③기능과 단어 소개 ④데이터 함수 ⑤산수 및 연산자 ⑥통계 함수 ⑦기타 함수(외우기보다 활용으로 체득). **→수식관리자 = [함수 선택 × 좌우 이동 × 수치 조정]의 조합 공간, 챕터01은 그 원자(기본 함수) 소개.**
- ▸★★**[배치 소결 — 01 기본편 서두(수식관리자 정의·후행성·제작 팁)]** 수식관리자 = 키움 차트 함수 편집기(신호검색 화살표 대표), **보조지표는 후행성·수익 보장 X → 분석 쉬운 지표 제작에 의의**, 제작 최난=함수 배열/조합(수백만 경우의 수). 챕터01 = 기본 함수 7항목. **★후속 데이터 함수/산수/통계 함수부터 수식 코드 등장 예상 → PDF 이미지 대조 필수.**
- ▸교차: 함수 조합=수식관리자 조합 공간. 수치 조정=정량 임계(재렌더링 정책 대상). 챕터01 기본 함수=후속 응용의 토대. 불일치 없음.
