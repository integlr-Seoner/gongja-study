## G4381. 수식관리자 기본편 기능·단어① 지표 변수 — 기본 미설정 함수의 이름 변경(수치값 같으면 동일 인식) — ★'지표 변수는 수식관리자로 여러 지표를 제작함에 있어 가장 기본적인 기능 중 하나 — 쉽게, 수식관리자에서 기본적으로 설정되어 있지 않은 함수를 본인이 원하는 대로 이름을 바꿀 수 있는 기능', ★★'[PDF 대조] 볼린저밴드 함수 = `BBandsUp`(상한선)·`BBandsC`(중심선)·`BBandsDown`(하한선), 뒤에 붙는 `(Period, D1)`이 지표 변수 — 예시 `BBandsC(Period, D1)`. 지표조건설정에서 Period=20·D1=2(표준편차)', ★★'지표 변수의 수치 값만 같다면 이름을 어떻게 변경해도 수식관리자에서는 동일한 함수로 인식 — 수치 값을 바꿔도 동일 함수로 인식하므로 기본 볼린저밴드 수치 (20, 2) 대신 (30, 2)로 바꿔 써도 됨', ★★'많은 커뮤니티에 돌아다니는 수식관리자 함수의 특정 단어·은어(세력·상따·하따·매집 등)는 모두 지표 변수로 이름만 바꾼 것 — 어떤 이름으로 바꿔도 동일한 기능(독자만 알아볼 수 있는 지표 제작에 사용)' (01_기본편 p.15~18, 기능과 단어 소개)
- ★★★★★***[★★지표 변수 = 함수 인자(Period/편차)의 이름 자유화, 수치값이 정체성]*** **★정의**: 기본 미설정 함수(인자)를 **원하는 이름으로 변경**하는 기능. **★★볼린저밴드 실체**(PDF 확정): `BBandsUp`(상)·`BBandsC`(중)·`BBandsDown`(하) + **`(Period, D1)`** 지표 변수, **Period=20·D1=2(표준편차)**. **★★인식 규칙**: **수치값만 같으면 이름 무관 = 동일 함수**(이름은 장식, 정체성은 수치). 수치 바꾸면 다른 함수 → (20,2)를 (30,2)로 조정 가능. **★★은어 함수의 정체**: 커뮤니티의 세력·상따·하따·매집 등 이름 = **지표 변수로 이름만 바꾼 것**(기능 동일, 독자 전용 지표 위장). **→지표 변수 = 함수 인자의 별칭, 수치값이 함수 정체성 → 은어 지표에 현혹 말 것(이름≠기능). ## G4382. 수식관리자 기본편 기능·단어② 치환 — 복잡 수식을 알파벳/단어로 간소화(세미콜론 필수) — ★'치환은 수학 시간에 배운 개념과 동일 — 복잡한 수식을 알파벳이나 단어 하나로 표현하여 수식 함수를 간소화할 수 있는 기능 (저자는 치환을 매우 중요하게 생각하며 실제 지표 제작 시 많이 사용)', ★★'[PDF 대조] 20일 이동평균선 = `Avg(C, 20)`(C=종가), 치환 = `A=Avg(C, 20);` → 이후 `A`만 입력하면 20일 이동평균선으로 인식', ★★'치환의 두 가지 장점: ①함수를 간소화하여 복잡하지 않게 표현 ②지표가 잘 만들어졌는지·함수 배열이 제대로 됐는지 수식 검증 과정에서 오류를 빠르게 발견(기존 지표에 새 함수 추가 시 오류도 빠르게 수정)', ★★'주의 2가지: ①수식관리자에서 이미 정의된 의미 있는 알파벳/단어(종가·거래량·거래대금 등)로는 치환 불가 — 치환 불가 함수는 녹색·파란색으로 표현 ②가장 뒤에 세미콜론(;)을 반드시 입력(없으면 치환 함수 인식 불가, 괄호 불필요·맨 뒤에만)' (01_기본편 p.19~21, 기능과 단어 소개)
- ★★★★★***[★★★치환 = 복잡 수식의 별칭화(A=…;), 세미콜론 필수]*** **★정의**: 복잡한 수식을 **알파벳/단어 하나로 표현해 간소화**(수학 치환과 동일), 저자 필수 사용. **★★문법**(PDF 확정): 20일 이평선 `Avg(C, 20)`(C=종가) → **치환 `A=Avg(C, 20);`** → 이후 `A`만 입력하면 인식. **★★장점 2**: ①함수 간소화 ②수식 검증 시 **오류 빠른 발견/수정**(모듈화). **★★주의 2**: ①**이미 정의된 함수(종가·거래량·거래대금 등)로 치환 불가** — 치환 불가 함수는 **녹색·파란색**으로 표시(예약어 색상). ②**맨 뒤 세미콜론(;) 필수**(없으면 인식 불가, 괄호 불필요, 여러 조합도 맨 뒤에만). **→치환 = `별칭=수식;` 형태의 모듈화(예약어는 치환 불가·색상 구분, 세미콜론 종결이 문법 핵심). - ▸교차: ★세미콜론 종결·예약어 색상=문법 규칙(정량·조건식 정독 대상). Avg(C,20)=이평선 함수(G4381 데이터 함수). 모듈화 오류 발견=수식 검증. 종가/거래량/거래대금=데이터 함수 예약어(후속).

## G4383. 수식관리자 기본편 기능·단어③ 화살표 겹치기 + 검색 기능 + ▸배치 소결 — ★'화살표 겹치기 = 신호검색 메뉴로 화살표를 제작한 후 여러 개의 화살표를 차트 위에 표현하는 경우 따로 설정해야 하는 기능 — 수식관리자를 많이 활용하는 사람은 서로 다른 함수를 조합해 여러 관점의 화살표를 색상을 다르게 설정해 사용', ★★'처음 사용 시 화살표를 여러 개 설정하면 차트 위에서 겹쳐 한 가지만 표현되는 경우가 있는데, 이는 수식관리자가 아니라 차트에서 직접 설정 — 키움 차트 열고 차트 위 우클릭 → 차트환경설정 → 아래쪽 「신호검색 화살표 겹치기」 체크 해제 (체크되면 겹침, 해제되어야 여러 개 구현)', ★'검색 기능 = 지표 만들 때 필요한 함수를 검색 (초기 전자책 집필 시엔 검색 메뉴 없었음) — 웬만한 함수는 바로 검색되지만 볼린저밴드·엔벨로프 등 몇 가지는 영어로 검색해야 찾을 수 있음' (01_기본편 p.22~24, 기능과 단어 소개)
