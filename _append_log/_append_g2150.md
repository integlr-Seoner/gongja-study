## G2150. 대주제10 하위① 이론 — 매수 직후 대응(1~2분 내 상승 없으면 본전 축소) + 하위① 마무리 (p.161)
- ★**조기 방어 대응(음봉 시가 이탈 손절보다 먼저)**: ***"주가가 음봉 시가를 이탈하며 큰 폭 하락하기 전에 먼저 손절로 대응하고 싶다면 '매도 호가에 쌓인 덩어리 물량을 돌파한 뒤 1~2분 이내에 추가 상승 흐름이 나타나지 않을 때 본전 부근에서 비중을 줄여주는 것'도 좋은 방법"***.
  - → ★**판정 시간 = 1~2분(5분봉 기준)** — 밀리의서재 갭하락 "1분 이내"(G2094)와 유사하나 음봉 시가 돌파는 1~2분. ***"상승이 멈췄다는 것은 하락 신호"*** → 비중 축소.
- ★평소 큰 비중 매매자는 매수 직후 미상승 시 비중 일부 축소 권장. ★**하위①(매매 이론) 마무리** — 이론+예시 반복 학습 권장.

## G2151. 대주제10 하위① Q&A ① — ★★★매매 시간 = 개장~오전 10시(특별 종목 11~12시) (p.162)
- ★**Q&A 파트 진입.**
- ★★★**Q: 음봉 시가 돌파 패턴 매매는 몇 시까지?** A: ***"보통 개장 직후부터 오전 10시까지만"***. 이유 = ***"다수 투자자들이 비슷한 타점에서 매수하여 강한 수급이 유입되는 흐름을 이용하는 매매라 오전 10시 정도까지만 권장"***.
- ★단, ***"신규 상장주·쩜 상한가·쩜 하한가 등 특별한 흐름이 나타난 종목의 분봉에서 음봉 시가를 돌파하는 흐름이 나타나면 11시~12시까지 매매할 때도 있다"*** (시초 아니어도 언제든 관심받는 종목).
  - → ★★**매매법별 시간창 상이**: **음봉 시가 돌파 = ~10:00** ↔ **갭하락 단타 패턴(1) = 09:10**(G1915). 특별 종목은 ~11-12시. **전역 종료 시각으로 묶지 말 것.**

## G2152. 대주제10 하위① Q&A ② — 호가창 없이 차트만 매매 가능(확률 향상용, 손절은 칼같이) (p.163)
- ★★**Q: 호가창 분석 안 하고 차트만 보고 매매해도 될까?** A: ***"음봉 시가 돌파 패턴은 대부분 시초에 큰 수급이 유입되는 특징을 이용한 매매라 호가창 분석 없이 차트만 봐도 높은 확률로 수익 가능"*** (과거 필자도 그랬고 지금도 그런 투자자 많음).
- ★단서: ***"차트만 분석해도 손절 라인은 칼같이 지켜야 한다 — 다수 투자자가 비슷한 가격에서 손절하므로 제때 손절 안 하면 손실 폭이 커진다"***. ★호가창 함께 분석 권장 이유 = ***"매매 확률을 조금이라도 더 높이기 위함"***이며 차트만으로도 수익 가능(G2137 재확인).

## G2153. 대주제10 하위① Q&A ③ — ★★★★상승 안 할 때 = 거래대금 크기로 해석(이탈 vs 매집) (p.164)
- ★★★★**Q: 음봉 시가 돌파 패턴이 나타났는데 상승하지 않으면?** A: ***"거래대금의 크기를 보고 해석"***:
  - **① 큰 거래대금**(전날 유입 수급이 모두 이탈했을 만큼) = ***"세력들이 보유 물량을 '음봉 시가 돌파될 때 유입된 개인 투자자들'에게 넘긴 것"*** → 하락(매매 불가·손절).
  - **② 작은 거래대금**(세력 이탈로 볼 수 없을 만큼) = ***"일부러 악성 매물이 많이 나오는 시간을 활용하여 물량을 매집한 것이고, 추후 저점에서 추가 매집 과정을 거친 뒤 상승시킬 가능성"*** → 유의미한 수급 유입 시 데이트레이딩·스윙, 급등 시 단타.
  - → ★**거래대금 = 실패 흐름 해석의 키**(G2002 재매수·G2094 수급 유입 관측과 정합). ★②는 **5권에서 상세**(G1894·G2097 예고).

## G2154. 대주제10 하위① Q&A ④ — ★★★음봉 시가 이탈 후 재돌파 대응(동일 관점 재진입) (p.165)
- ★★★**Q: 음봉 시가를 이탈했다가 반등하면?** A: 음봉 시가 이탈 = 다수 공통 손절 라인이라 빠르게 손절해야 하지만, ***"이탈한 뒤 다시 회복하는 흐름이 나타나면 이전과 동일한 관점(음봉 시가 돌파 패턴)으로 매매"***.
  - ★***"단순히 음봉 시가를 회복할 때 재매수하는 것이 아니라 '호가창 배열을 확인하고, 큰 수급이 유입되면서 덩어리 물량을 돌파할 때' 매매"*** — 호가 얇거나 특정 가격에만 물량이면 보류.
- ★**재돌파 논리**: 세력이 추가 상승 마음 있다면 ***"이전에 매수했다 손절 못한 투자자들의 악성 매물을 다시 소화하며 상승"***시켜야 함. ⚠️단 세력이 이미 물량 정리했으면 추가 상승 안 할 수도 → **재돌파도 호가창 재확인 필수**(무한 재진입 금지).

## G2155. 대주제10 하위① Q&A ⑤ — 20% 이상 갭 상승 = 상따(상한가 따라잡기) 영역 (p.166)
- ★**Q: 20% 이상 갭 상승 출발 뒤 음봉 시가 돌파 패턴이면 매매 금지?** A: ***"20% 이상 갭 상승 출발할 때도 음봉 시가 돌파 패턴 활용 매매 가능하나, 변동성이 굉장히 크고 하루 종일 하락할 수도 있어 원칙에 맞춰 칼같이 손절"***.
- ★***"'20% 이상 갭 상승 출발 종목'으로 매매하는 관점은 상따 매매 관련 내용을 다룰 때 한번 더 설명"*** → **20%+ = 상따(상한가 따라잡기) 영역, 별도 매매법**(대주제 14 상한가 종목 단타와 연결 추정). ★G2117(갭 상승 5~15% / 16~20% 배제)의 보충 — 20%+는 음봉 시가 돌파의 정규 유니버스가 아님.

## G2156. 소제목(하위)② 「음봉 시가 돌파 패턴 종목 정리하기」 진입 (p.167 구분)

## G2157. 대주제10 하위② 도입 — ★★★★종목 정리 도구 3종 + 상한가 종목 정리(정규장/시간외 구분) (p.168)
- ★★★★**관심종목 정리 도구 3종**: ***"① 전일 대비 주가 등락률 상위 메뉴 / ② 시간 외 단일가 등락률 상위 메뉴 / ③ 조건검색기"*** → **G1838·G1839 2단 파이프라인의 실제 구현 도구**(갭하락 단타의 [0183] 하락률 정리 G1954에 대응하는 음봉 시가 돌파 버전).
- ★**첫 번째 정리 = 상한가 도달 종목**(정규장 + 시간 외 단일가) — ***"둘 다 다음 날 갭 상승 출발 가능성이 높아 미리 관심종목에 정리"***.
  - **정규장 상한가**: ***"300억 미만 거래대금 상한가 종목은 매매하지 않으므로 거래대금 크기로 필터링"***(G2118 선정 기준 (2) 정합).
  - **시간 외 단일가 상한가**: ***"다음 날 거래대금 크기와 관계없이 매매 가능하므로 전부 관심종목에 정리"*** (300억 필터 면제).
  - → ★★**정규장 상한가 = 300억 필터 / 시간 외 단일가 상한가 = 필터 면제**(신규 구분). ⚠️**G2050(당일 단일가 거래 중 종목 = 매매 불가)와 혼동 금지** — 여기는 전일 시간 외 단일가에서 상한가 도달 → 다음 날 정규장 매매(시점이 다름).

## G2158. 대주제10 하위② — ★★★★★음봉 시가 돌파 검색기 [0150] 조건식 실물 (p.169)
- ★***"주가 등락률로 종목을 정리한 뒤, 다음 날 시초가에 조건검색기로 '음봉 시가 돌파 패턴이 나타날만한 종목'을 찾는다."*** ★**갭 하락 (2) 매매는 '전일 상한가 종목'만 모니터링하므로 조건검색기 불필요** — 조건검색기는 **갭 상승 (1) 매매용**.
- ★★★★★**[0150] 조건검색 「음봉 시가 돌파」 실물**(원문 그대로):
  - **대상변경**: `<업종대상(전체)>` / 제외 = `<우선주+거래정지+정리매매+ETF+SPAC>` (제외 대상, 뒷부분 SPAC로 판독).
  - **봉전기준** / **매수** 선택 / **일** 주기.
  - **조건 A** = `주가등락률: [일]1봉전(중) 종가대비 0봉전 시가등락률 5%이상`.
  - **조건 B** = `[일]거래대금(일:백만, 분:천) 10000이상 9999999990이하`.
  - **조건식** = `A and B`. 검색기명 = 「음봉 시가 돌파」.
  - → ★**당일 오전 음봉 시가 돌파 패턴 종목 포착용.**

## G2159. 대주제10 하위② — ★★★검색기 조건 설명(시가등락률 5% / 거래대금 100억) (p.170)
- ★★★**조건 값 설명**: ***"1봉 전 종가 대비 0봉전 시가 등락률을 5% 이상으로 설정"*** = **전일 종가 대비 당일 시가 5% 이상 갭 상승**(G2117 갭 상승 5~15%의 하한). ***"100억 이상 거래대금 발생 종목만 포착되도록 거래대금 기준 설정"*** = 조건 B의 `10000`(단위 **일:백만** → 10000백만 = **100억**, G1742 단위계 정합).

- ★***"음봉 시가 돌파 패턴은 시초에 쏟아지는 악성 매물을 소화한 뒤 상승할 때 나타나 보통 시초부터 큰 거래대금이 발생 → 100억 기준 설정"***.
- ★**검색기 포착 다수 종목 중 실제 음봉 시가 돌파 패턴은 1~3개** → 개별 필터링. ★***"갭 상승 출발 후 하루 종일 하락하는 종목도 포착되므로 자체 필터링 필요"*** (검색기 = 관찰 큐, 포착 ≠ 진입).
