## G2959. 5-2권 대주제17 하위②(버릴 건 과감히) — ★★★★# 03 단기 과열 지정 예고 공시 화살표 HTS 수식(A/B/화살표 조건식 원문) (p.30)
- ★★★★[단기 과열 종목 지정 예고 공시 화살표 수식 — HTS 조건식 원문]:
- **A 치환 함수** (가장 뒤에 세미콜론 표기 주의):
```
A = Avg(C, 40, 1) * 1.3 <= C
&&
Avg(거래대금/C, 40, 1) * 6 <= Avg(거래대금/C, 2)
&&
Avg(((H-L)/((H+L)/2)), 40, 1) * 1.5 <= Avg(((H-L)/((H+L)/2)), 2)
&&
C > C(1);
```
- **B 치환 함수** (가장 뒤에 세미콜론 표기 주의):
```
B = IF(A==1, 1, 0) + IF(A(1)==1, 1, 0) + IF(A(2)==1, 1, 0)
+ IF(A(3)==1,1,0) + IF(A(4)==1,1,0) + IF(A(5)==1,1,0)
+ IF(A(6)==1,1,0) + IF(A(7)==1,1,0) + IF(A(8)==1,1,0)
+ IF(A(9)==1,1,0) + IF(A(10)==1,1,0) == 2;
```
- **단기 과열 종목 지정 예고 공시 화살표 수식**:
```
IF(B-B(1)==1, 1 ,0)
&&
C > Highest(C, 10, 1)
```
- ▸★★[수식↔3요건 대응]: A = ①상승률 130%(×1.3, `Avg(C,40,1)*1.3<=C`) + ②거래회전율 600%(×6, 거래대금/C 프록시) + ③변동성 150%(×1.5, (H-L)/((H+L)/2)) + 종가 상승(`C>C(1)`). B = A가 최근 창에서 정확히 2회 성립(`==2`, 최근 2거래일). 화살표 = 새 트리거(`B-B(1)==1`) + 10일 신고가(`C>Highest(C,10,1)`).
- ★★***"화살표 포착되면 오후 4~5시쯤 단기 과열 지정 예고 공시 발행 → 단기 과열 지정 안 돼도 다음 날 하락 확률 높다 판단, 약손절·수익·본전에 매도 대응"***.
