## G4384. 수식관리자 기본편 상단 메뉴① 검색·복사 — 함수 탐색(bol/en) + 기본 함수 변형용 복사((2) 복사본) — ★'가장 기본적인 기능은 검색 기능 — 검색창에서 지표 제작에 필요한 함수를 검색, 웬만한 함수는 바로 검색되지만 볼린저밴드·엔벨로프 등은 영어로 검색', ★★'[PDF 대조] 볼린저밴드는 `bol`, 엔벨로프는 `en` 정도로 알파벳 입력 → 바로 검색 (본인이 만든 수식도 사용자지표 아닌 검색창으로 쉽게 찾기)', ★'[메뉴 구조] 기술적지표 하위 = 추세지표/변동성지표/모멘텀지표/시장강도지표/가격지표/거래량지표/선물옵션전용지표/사용자지표, 하단 = 신호검색/시스템트레이딩/강세약세/일반함수/다른 ID 지표 불러오기. 상단 버튼 = 복사·이름바꾸기·삭제·새로만들기·작업저장·수식검증·함수설명·암호설정·닫기. 탭 = 수식/지표조건설정/라인설정/기준선설정/스케일/설명(수식1~5)', ★'복사 기능 = 기본 설정된 함수를 변형·재배열하거나 본인 수식을 변형·수정할 때 사용 — 지표 선택 후 복사 누르면 `(2)` 복사본 생성 + 수정 화면으로 전환 (초기엔 기본 함수 변형용, 숙련자는 본인 수식 업그레이드용)' (01_기본편 p.24~26, 상단 메뉴)
- ★★★★**[★검색(bol/en) + 복사((2) 복사본)]** **★검색**: 함수 탐색 — 대부분 바로, **볼린저밴드=`bol`·엔벨로프=`en`**(영어 축약). 본인 수식도 검색창으로 찾기. **★★메뉴 구조**: 기술적지표(추세/변동성/모멘텀/시장강도/가격/거래량/선물옵션전용/사용자) + 신호검색/시스템트레이딩/강세약세/일반함수. 상단 버튼(복사·이름바꾸기·삭제·새로만들기·작업저장·수식검증·함수설명·암호설정). **★복사**: 기본 함수 변형/재배열 or 본인 수식 수정 시 → 지표 선택 후 복사 → **`(2)` 복사본 생성 + 수정 화면**(초기=함수 변형, 숙련=수식 업그레이드). **→검색(bol/en)으로 함수 찾고, 복사로 기존 함수 변형본((2)) 제작(원본 보존 편집).**

## G4385. 수식관리자 기본편 상단 메뉴② 이름바꾸기·삭제·새로만들기 — ★'이름바꾸기 = 지표의 이름을 바꾸는 기능 — 사용자지표에서 이름 바꿀 지표 선택 후 이름바꾸기 누르면 좌측에 이름 변경 활성화, 지표명 입력 후 엔터 (지표를 클릭한 후 이름바꾸기를 눌러야 함)', ★'삭제 = 지표를 삭제하는 기능 — 삭제할 지표 선택 후 삭제 버튼', ★★'새로만들기 = 지표를 새로 제작할 때 사용 — 복사 기능으로 기본 함수를 복사해 제작해도 되고, 새로만들기로 처음부터 제작해도 됨. 새로만들기 누른 후 지표명·수식·지표조건설정·라인설정·기준선설정·스케일 등을 입력한 다음 저장', ★'새로만들기 = 지표를 만들 때 가장 처음에 눌러야 하는 기능' (01_기본편 p.27~28, 상단 메뉴)
- ★★★★**[★이름바꾸기·삭제·새로만들기(지표 CRUD)]** **★이름바꾸기**: 사용자지표에서 지표 선택 → 이름바꾸기 → 좌측 이름 변경 활성화 → 지표명 입력+엔터(★반드시 지표 클릭 후 이름바꾸기). **★삭제**: 지표 선택 후 삭제 버튼. **★★새로만들기**: 지표 새 제작 시작 버튼(복사로 기존 함수 변형 vs 새로만들기로 백지 제작) → **지표명·수식·지표조건설정·라인설정·기준선설정·스케일 입력 후 저장**. **→지표 관리(CRUD) = 새로만들기(생성)·이름바꾸기(수정)·삭제, 지표는 [지표명+수식+조건설정+라인/기준선/스케일] 구성.**
- ▸교차: 지표 구성 요소(지표명/수식/지표조건설정/라인설정/기준선설정/스케일)=지표 제작 단위. 지표조건설정=지표변수 수치(G4381 Period/D1). 복사 vs 새로만들기(G4384).

## G4386. 수식관리자 기본편 상단 메뉴③ ★수식검증+작업저장(한 세트) + 함수설명 + ▸배치 소결 — ★★'수식검증과 작업저장은 한 세트로 사용 — 지표 저장 전 반드시 같이 눌러야 하는 기능', ★★'수식검증 = 본인이 작성한 함수가 제대로 배열되어 있는지, 지표변수가 제대로 정의되고 있는지 검증 — 배열·변형·조합이 제대로 안 됐다면 차트 위에 제대로 표현되지 않으므로 반드시 작업저장 전 수식검증. 검증 통과 시 「수식에 이상이 없습니다.」 문구 표시', ★★'수식 수정 과정에서 함수가 길게 나열되어 있는데 치환을 사용하지 않았다면 어디서 문제가 되는지 알 수 없으므로 치환을 꼭 사용 (저자는 보통 수식검증 후 작업저장, 순서는 무관)', ★'함수설명 = 수식관리자에서 기본 제공하는 여러 함수들의 사용 방법과 의미를 볼 수 있는 기능 (뒤에서 자세히, 직접 사용해봐야 이해)' (01_기본편 p.29~31, 상단 메뉴)
